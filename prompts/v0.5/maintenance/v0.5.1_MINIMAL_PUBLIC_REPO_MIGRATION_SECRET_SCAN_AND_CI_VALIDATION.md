## 4. Scan the complete reachable history

The scan scope is the union of all commits reachable from:

~~~text

~~~

Record reachable commit count and largest blobs.

### 4.1 Full-history secret scanner

Run Gitleaks over both refs with redaction.

Preferred equivalent:

~~~bash
gitleaks git . \
  --log-opts="v0.5-refactor v0.5-refactor-docs" \
  --redact \
  --report-format json \
  --report-path /tmp/gitleaks-public-history.json
~~~

Adapt syntax if the installed version differs.

A raw scanner report containing sensitive values must NOT be committed.

If Gitleaks is unavailable, use another reputable offline full-history scanner and clearly report the substitution.

### 4.2 Independent second scan

If available, run TruffleHog or another independent offline scanner against the same reachable history.

No credential validation against external services.

Record scanner name/version, exit code, finding count, confirmed count, and false-positive count.
