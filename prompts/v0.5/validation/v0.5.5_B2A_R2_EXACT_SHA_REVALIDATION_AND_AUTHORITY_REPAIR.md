## 7. Frozen B2A-R2 semantics to verify

Do not redesign these semantics.

### 7.1 Exit uncertainty authority

Filled terminal outcomes must carry:

- `exit_interval_start_ms`
- `exit_interval_end_ms`
- `exit_time_resolution`

Allowed resolution taxonomy:

- `ONE_MINUTE_TERMINAL_INTERVAL`
- `FIFTEEN_MINUTE_FALLBACK_INTERVAL`
- `HORIZON_TIMEOUT_BOUNDARY`

### 7.2 Funding causality

Classify settlement time relative to entry/exit uncertainty:

```text
f < fill_start
→ not applicable

fill_start <= f <= fill_end
→ AMBIGUOUS_FILL_BOUNDARY

fill_end < f < exit_start
→ provably held; settlement may be authoritative

exit_start <= f <= exit_end
→ AMBIGUOUS_EXIT_BOUNDARY

f > exit_end
→ not applicable
```

Any relevant fill or exit ambiguity must force:

```text
funding_pnl_r = None
funding_cash_total = None
net_r_after_funding = None
```

No partial authoritative sum.

### 7.3 TIMEOUT authority

For TIMEOUT:

```text
exit_interval_start_ms == evaluation_end_ms
exit_interval_end_ms == evaluation_end_ms
exit_time_ms == evaluation_end_ms
exit_time_resolution == HORIZON_TIMEOUT_BOUNDARY
```

### 7.4 Read-path identity

Authoritative reads must reject missing/tampered embedded `evaluation_id`.

### 7.5 Preserved earlier authority

R2 must not change:

- B0 policy precedence;
