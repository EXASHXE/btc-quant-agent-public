## Frozen semantics to validate
1. Source is immutable TacticalFeatureEvidenceV2.evidence_id; source identity verifies.
2. Natural key = (feature_evidence_id, GRID_OUTCOME_PROFILE_VERSION).
3. Identical replay is idempotent; divergent replay fails closed.
4. Versions equal:
   TACTICAL_GRID_SHADOW_EVALUATION_V1
   GRID_OUTCOME_PROFILE_V1
   GRID_1M_CONSERVATIVE_TWO_PATH_V1
   NORMALIZED_GRID_ACCOUNTING_V1
5. Horizon = exactly 24h / 86_400_000 ms; no outcome-guided extension.
6. N grid intervals produce N+1 arithmetic levels; anchor fixed; lower-index tie break.
7. Reference capital = 1.0; no leverage, Martingale, or dynamic sizing.
8. LONG_BIAS long-only; SHORT_BIAS short-only; NEUTRAL below-anchor long/above-anchor short; PAUSE has no fills/PnL.
9. Ascending crossings process low->high; descending high->low; no duplicate simultaneous slot lots; paired close re-arms.
10. Authoritative execution uses future 1m OHLC only. Incomplete 1m coverage cannot fabricate authoritative PnL.
11. For each 1m candle evaluate O-H-L-C and O-L-H-C; choose deterministic conservative state.
12. Normal fills use maker fee; terminal liquidation uses taker fee + adverse slippage; decision-time config is authoritative.
13. Funding uses realized public settlements only. Funding in an inventory-changing minute with unknown ordering => funding_pnl=None and net_pnl_after_funding=None.
14. Missing required settlement mark price => funding/net-after-funding unavailable.
15. Peak capital utilization cannot exceed normalized cap.
16. maximum_underwater and peak-to-trough drawdown remain distinct metrics.
17. Boundary touch is not breach; strict outside is breach.
18. Future grid/policy diagnostics cannot mutate frozen fills/bounds/anchor.
19. Incomplete future assessment coverage cannot become zero shifts.
20. Trend-transition information cannot leak backward into fill simulation.
21. Resolved authoritative evaluations are immutable; only pending rows may later resolve.
22. Directional B2A semantics/tables remain isolated.
