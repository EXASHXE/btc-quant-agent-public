# 3. Repaired Statistical Inference Methodology

### Point Estimator $\widehat{\mu}_i$
$$\widehat{\mu}_i = \frac{\sum_{t=0}^{T-1} Z[i, t]}{\sum_{t=0}^{T-1} A[i, t]}, \quad \text{for } N_i = \sum_t A[i, t] \ge 60$$

### Original Sample Standard Error $\widehat{SE}_i$ (Künsch 1989 Block Sums)
Let $S = T - L + 1$. For block starts $j \in \{0, \dots, S-1\}$:
$$Z_{\text{block}}[i, j] = \sum_{u=0}^{L-1} Z[i, j + u], \quad A_{\text{block}}[i, j] = \sum_{u=0}^{L-1} A[i, j + u]$$
$$e_{\text{block}}[i, j] = Z_{\text{block}}[i, j] - \widehat{\mu}_i A_{\text{block}}[i, j]$$
$$\widehat{\text{Var}}(\widehat{\mu}_i) = \frac{1}{\left(\sum_t A[i, t]\right)^2} \frac{T}{L \cdot S} \sum_{j=0}^{S-1} \left( e_{\text{block}}[i, j] - \bar{e}_{\text{block}}[i] \right)^2$$
$$\widehat{SE}_i = \sqrt{\widehat{\text{Var}}(\widehat{\mu}_i)}$$

### Shared-Clock Replicate Estimation & Studentization
For replicate $b \in \{1, \dots, B\}$, draw $k = \lceil T / L \rceil$ shared block starts $(s_{b, 1}, \dots, s_{b, k})$.
$$\mu^*_{i, b} = \frac{\sum_{m=1}^k Z_{\text{block}}[i, s_{b, m}]}{\sum_{m=1}^k A_{\text{block}}[i, s_{b, m}]}$$
$$\widehat{SE}^*_{i, b} = \frac{1}{A^*_b[i]} \sqrt{ \frac{k}{k - 1} \sum_{m=1}^k \left( Z_{\text{block}}[i, s_{b, m}] - \mu^*_{i, b} A_{\text{block}}[i, s_{b, m}] \right)^2 }$$
$$\text{center}_i = \frac{\sum_{j=0}^{S-1} Z_{\text{block}}[i, j]}{\sum_{j=0}^{S-1} A_{\text{block}}[i, j]}$$
$$T^*_{i, b} = \frac{\mu^*_{i, b} - \text{center}_i}{\widehat{SE}^*_{i, b}}$$
$$c_{95} = \text{percentile}_{95}\left( \max_{i \in \text{valid}} T^*_{i, b} \right)$$
$$LCB_i = \widehat{\mu}_i - c_{95} \cdot \widehat{SE}_i$$
