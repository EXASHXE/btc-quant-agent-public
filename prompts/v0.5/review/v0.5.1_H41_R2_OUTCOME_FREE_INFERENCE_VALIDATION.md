# 1. Purpose and Evidential Boundary

The purpose of Stage R2 is to establish empirical evidence that the **shared-clock, source-bundle, standardized single-step joint maximum inference procedure** provides:
1. Valid nominal familywise error rate (FWER) control ($\le 0.05$) under complex serial dependence, cross-asset correlation, and unequal event support;
2. Accurate simultaneous confidence coverage ($\ge 95\%$);
3. Adequate statistical power across a decision-relevant effect grid;
4. Numerical stability under sparse, clustered, and edge-case replicate samples.

# 2. Preregistered Block Length Candidate Set

In accordance with Controller adjudication, block length $L$ shall NOT be selected post-hoc from empirical H41 discovery LCBs. Instead, four candidate rules are preregistered for evaluation:

1. **$L = 48\text{ hours}$ (2 days)**:
   - Evaluates short-range dependence beyond individual horizon lengths ($h \le 12$);
   - Preserves 45.5 nominal blocks in a 91-day window ($T = 2,184$ hours).
2. **$L = 72\text{ hours}$ (3 days)**:
   - Aligns with the longest reference lookback window ($W = 72h$);
   - Preserves 30.3 nominal blocks in the 91-day window.
3. **$L = 120\text{ hours}$ (5 days)**:
   - Evaluates extended volatility persistence and multi-day clustering;
   - Yields 18.2 nominal blocks in the 91-day window.
4. **$L = 24\text{ hours}$ (1 day) — Baseline Diagnostic**:
   - Retained strictly as an explicitly expected-to-be-challenged baseline diagnostic.
   - Analytically shown in the Astra audit to introduce variance under-estimation ($83.4\%$ of true variance at $h=12$).
   - Must not automatically win simply because it is the shortest block length.

No additional block lengths may be evaluated without formal Controller amendment.

# 3. Required Synthetic Data Generating Processes (DGPs)

The synthetic validation study must evaluate the candidate block rules across **12 scenario classes**:

### Class 1: Independent Increments Baseline
- Hourly innovations $\epsilon_u \sim \mathcal{N}(0, \sigma^2)$ or Student-$t$ with finite variance.
- Establishes pure baseline behavior without autocorrelation.

### Class 2: Overlapping Moving-Sum Returns
- Overlapping horizon returns: $r_u^{(h)} = \sum_{k=0}^{h-1} \epsilon_{u+k}$ for $h \in \{4, 8, 12\}$.
- Evaluates moving-average induced covariance tapers.

### Class 3: Autoregressive (AR) Serial Dependence
- Innovations follow an AR(1) or AR(2) process: $\epsilon_u = \rho_1 \epsilon_{u-1} + \eta_u$ with $\rho_1 \in [0.15, 0.35]$.
- Evaluates persistence in raw returns.

### Class 4: Persistent Stochastic Volatility & GARCH Clustering
- Conditional variance follows GARCH(1,1): $\sigma_u^2 = \omega + \alpha \epsilon_{u-1}^2 + \beta \sigma_{u-1}^2$ with $\alpha + \beta \approx 0.95$.
- Evaluates non-constant volatility clustering common in crypto assets.

### Class 5: Clustered Sparse Event Masks
- Event eligibility masks $A[i, u]$ generated via Poisson burst or Hawkes-like clustering models.
- Mimics concentrated trade entries during market stress episodes.

### Class 6: Unequal Candidate Event Counts
- Synthetic candidate universe where Candidate 1-4 have $N \approx 400$ events (D1 analogue), Candidate 5-8 have $N \approx 180$ events (D2 analogue), and Candidate 9-12 have $N \approx 60-80$ events (D3 analogue).
- Evaluates studentization stability when denominators vary 5-fold across coordinates.

### Class 7: Correlated Bivariate Source Processes
- Synthetic bivariate process $(X_u^{\text{BTC}}, X_u^{\text{ETH}})$ with contemporaneous innovation correlation $\rho \in [0.70, 0.90]$.
- Evaluates cross-asset dependence preservation in joint block sampling.

### Class 8: Heavy-Tailed Finite-Variance Innovations
- Innovations drawn from standardized Student-$t$ with degrees of freedom $\nu \in \{4, 5\}$.
- Evaluates robustness of studentized test statistics against moderate outliers.

### Class 9: Near-Support-Threshold Candidates
- Candidate masks calibrated to yield event counts exactly on the boundary: $N \in [58, 65]$ and occupied days $D \in [28, 32]$.
- Tests screening stability and boundary classification.

### Class 10: Outcome-Correlated Missingness Stress
- Simulated data outages (1-6 consecutive hours missing) occurring with higher probability during high-volatility hours.
- Evaluates whether missing-data masking biases joint ratio estimation.

### Class 11: Degenerate / Zero-Count Replicate Stress
- Highly sparse candidate masks where bootstrap draws occasionally yield zero events ($\sum_u w_b[u] A[i, u] = 0$) or zero sample variance ($\widehat{SE}_i = 0$).
- Verifies that fail-closed exception handling operates cleanly without crashing or corrupting rankings.

### Class 12: Mixed True/False Null Family Configurations
- Global Null: All 20 candidates have true expectancy $\mu_i = 0$.
- Sparse Signal: 18 candidates with $\mu_i = 0$; 2 candidates with true $\mu_i = \delta > 0$.
- Dense Signal: 10 candidates with $\mu_i = 0$; 10 candidates with $\mu_i = \delta > 0$.
- Evaluates whether non-null coordinates inflate the critical value and suppress true signals.

# 6. Evaluation Metrics and Acceptance Thresholds

For each block length candidate $L \in \{24h, 48h, 72h, 120h\}$ across $M = 2,000$ Monte Carlo simulation runs (each with $B = 10,000$ joint bootstrap draws):

1. **Familywise Error Rate (FWER)**:
   $$\widehat{\text{FWER}} = \frac{1}{M} \sum_{m=1}^M \mathbb{I}\left(\max_{i \in \text{Null}} T_i^{*(m)} > c_{95}^{(m)}\right)$$
   *Target*: Empirical $\widehat{\text{FWER}} \le 0.05 + 1.96 \sqrt{\frac{0.05 \times 0.95}{M}} \approx 0.0595$.

2. **Simultaneous Coverage**:
   $$\widehat{\text{Cov}} = \frac{1}{M} \sum_{m=1}^M \mathbb{I}\left( \forall i : \mu_i \ge \text{LCB}_i^{(m)} \right)$$
   *Target*: $\widehat{\text{Cov}} \ge 0.940$.

3. **Marginal Coordinate Coverage**:
   Empirical coverage for each of the 20 individual coordinates: $\ge 0.945$.

4. **Monte Carlo Uncertainty**:
   Standard errors for all rejection rates must be reported.

5. **Empirical Power Curve**:
   Rejection probability plotted against effect size $\delta \in \{0, 5, 10, 20, 30, 40\}\text{ bps}$.

6. **Deterministic Replay**:
   Two independent runs with identical RNG seed must produce bit-for-bit identical outputs.

7. **Permutation / Coordinate Invariance**:
   Permuting the candidate rows in the data matrix must yield identical numerical critical values $c_{95}$ and invariant selection rankings.
