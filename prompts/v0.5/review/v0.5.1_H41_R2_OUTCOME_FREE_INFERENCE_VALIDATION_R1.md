# 1. Purpose and Strict Evidential Boundary

The purpose of Stage R2 is to evaluate the statistical properties of the **shared-clock, source-bundle, standardized single-step joint maximum inference procedure** before protocol freeze. Specifically, it tests:
1. Nominal familywise error rate (FWER) control ($\le 0.05$) under complex serial dependence, cross-asset correlation, and 24h moving-horizon return overlaps;
2. Accurate simultaneous confidence coverage ($\ge 95\%$);
3. Adequate statistical power across a decision-relevant effect grid;
4. Numerical stability under sparse, clustered, and edge-case replicate samples.

# 2. Preregistered Block Length Candidate Set (Amended for H24)

Under the amended R1.1 protocol, holding horizons span $h \in \{4\text{h}, 8\text{h}, 24\text{h}\}$. The candidate block lengths evaluated in Stage R2 are:

### Primary Candidate Set:
1. **$L = 48\text{ hours}$ (2 days)**:
   - Exactly twice the maximum holding horizon ($L = 2h_{\max}$);
   - Preserves 45.5 nominal blocks in a 91-day window ($T = 2,184$ hours).
2. **$L = 72\text{ hours}$ (3 days)**:
   - Aligns with the longest reference lookback window ($W = 72h$);
   - Preserves 30.3 nominal blocks in the 91-day window.
3. **$L = 120\text{ hours}$ (5 days)**:
   - Evaluates extended multi-day volatility clustering and persistence beyond 24h overlaps;
   - Yields 18.2 nominal blocks in the 91-day window.

### Diagnostic & Baseline Candidates:
4. **$L = 168\text{ hours}$ (7 days / 1 nominal week) — Extended Diagnostic**:
   - Added as an extended dependence stress diagnostic to evaluate full-week regime memory;
   - Yields 13.0 nominal blocks. Evaluated to test variance bias vs estimation stability trade-offs.
5. **$L = 24\text{ hours}$ (1 day) — Baseline Diagnostic**:
   - Retained strictly as an explicitly expected-to-be-challenged baseline diagnostic.
   - Analytically shown in the Astra audit to introduce variance under-estimation ($83.4\%$ of true variance even at $h=12$; further under-estimated at $h=24$).
   - Must not automatically win simply because $L = h_{\max}$.

The synthetic validation itself decides which block length provides the best FWER/coverage/power trade-off.

# 3. Required Synthetic Data Generating Processes (DGPs)

The 12 scenario classes are updated to incorporate $h=24$:

### Class 1: Independent Increments Baseline
- Hourly innovations $\epsilon_u \sim \mathcal{N}(0, \sigma^2)$ and Student-$t$ with finite variance.

### Class 2: Overlapping Moving-Sum Returns (Amended)
- Overlapping horizon returns: $r_u^{(h)} = \sum_{k=0}^{h-1} \epsilon_{u+k}$ for **$h \in \{4, 8, 24\}$**.
- Directly evaluates moving-average covariance tapers up to 24 hours of lag.

### Class 3: Autoregressive (AR) Serial Dependence
- Innovations follow an AR(1) or AR(2) process: $\epsilon_u = \rho_1 \epsilon_{u-1} + \eta_u$ with $\rho_1 \in [0.15, 0.35]$.
- Sufficient persistence to stress the 24h outcome horizon.

### Class 4: Persistent Stochastic Volatility & GARCH Clustering
- Conditional variance follows GARCH(1,1): $\sigma_u^2 = \omega + \alpha \epsilon_{u-1}^2 + \beta \sigma_{u-1}^2$ with $\alpha + \beta \approx 0.95$.
- Evaluates multi-day volatility clustering typical of crypto assets.

### Class 5: Clustered Sparse Event Masks
- Event eligibility masks $A[i, u]$ generated via Poisson burst or Hawkes-like clustering models.
- Tests 24h overlapping outcomes under concentrated entry episodes.

### Class 6: Unequal Candidate Event Counts
- Synthetic candidate universe with unequal coordinates: Candidate 1-4 ($N \approx 400$, D1), Candidate 5-8 ($N \approx 180$, D2), Candidate 9-12 ($N \approx 60-80$, D3), Candidate 13-20 ($N \approx 200$, D4).
- Tests studentization stability when denominators vary substantially across coordinates.

### Class 7: Correlated Bivariate Source Processes
- Bivariate process $(X_u^{\text{BTC}}, X_u^{\text{ETH}})$ with contemporaneous innovation correlation $\rho \in [0.70, 0.90]$.
- Preserves shared-clock cross-asset dependence with 24h source-anchored outcome bundles.

### Class 8: Heavy-Tailed Finite-Variance Innovations
- Innovations drawn from standardized Student-$t$ with degrees of freedom $\nu \in \{4, 5\}$.
- Tests robustness against moderate outliers.

### Class 9: Near-Support-Threshold Candidates
- Candidate masks calibrated to yield event counts exactly on the boundary: $N \in [58, 65]$ and occupied days $D \in [28, 32]$.
- Tests screening stability and boundary classification.

### Class 10: Outcome-Correlated Missingness Stress
- Simulated data outages (1-6 consecutive hours missing) occurring with higher probability during high-volatility hours.
- Evaluates whether missing-data masking biases joint ratio estimation.

### Class 11: Degenerate / Zero-Count Replicate Stress
- Highly sparse candidate masks where bootstrap draws occasionally yield zero events ($\sum_u w_b[u] A[i, u] = 0$) or zero sample variance ($\widehat{SE}_i = 0$).
- Verifies fail-closed exception handling.

### Class 12: Mixed True/False Null Family Configurations
- Global Null: All 20 candidates have true expectancy $\mu_i = 0$.
- Sparse Signal: 18 candidates with $\mu_i = 0$; 2 candidates with true $\mu_i = \delta > 0$.
- Dense Signal: 10 candidates with $\mu_i = 0$; 10 candidates with $\mu_i = \delta > 0$.

### Special Invariant: Partition-Edge Censoring Test
- Explicitly test that an event occurring at hour $T - 10$ with horizon $h=24$ is prospectively censored because $t + 24 > T$, and never enters the event denominator.

# 6. Evaluation Metrics and Acceptance Thresholds

For each block length candidate $L \in \{24h, 48h, 72h, 120h, 168h\}$ across $M = 2,000$ Monte Carlo simulation runs (each with $B = 10,000$ joint bootstrap draws):

1. **Familywise Error Rate (FWER)**:
   $$\widehat{\text{FWER}} = \frac{1}{M} \sum_{m=1}^M \mathbb{I}\left(\max_{i \in \text{Null}} T_i^{*(m)} > c_{95}^{(m)}\right) \le 0.05 + 1.96 \sqrt{\frac{0.05 \times 0.95}{M}} \approx 0.0595$$
2. **Simultaneous Coverage**: $\widehat{\text{Cov}} \ge 0.940$.
3. **Marginal Coordinate Coverage**: $\ge 0.945$ across each coordinate.
4. **Monte Carlo Uncertainty**: Binomial standard errors reported for all empirical rejection rates.
5. **Empirical Power Curve**: Evaluated across $\delta \in \{0, 5, 10, 20, 30, 40\}\text{ bps}$.
6. **Deterministic Replay**: Identical RNG seed yields bit-for-bit identical outputs.
7. **Coordinate Invariance**: Permuting candidate rows yields invariant $c_{95}$ and selection order.
