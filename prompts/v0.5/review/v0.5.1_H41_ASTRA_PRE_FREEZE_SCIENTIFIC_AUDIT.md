## 3.3 Candidate universe

Audit all 20 proposed candidates.

Determine whether:


## 3.4 Family support

Review D1/D2/D3/D4 eligibility definitions.

Assess whether removing universal volatility/opportunity filters creates a cleaner test of the directional information source or instead creates excessive unconditional noise.

If regime should be retained, determine whether it should be:

```text

or excluded from H41 V1
```

## 3.5 Primary endpoint

Audit:

```text

```

as the single Candidate-Lock primary endpoint.

Assess whether it is:

```text

```

Recommend a different primary endpoint only if clearly superior and prospectively definable.

## 3.6 Cost model

Audit 12 bps base round-trip and 24 bps stress.

Distinguish:

```text
scientific transaction-cost proxy
actual executable cost model
```

Determine whether base-cost positivity is enough at Discovery or whether stress-cost positivity should be a formal gate.

## 3.7 Dependence correction


## 3.8 Sparse-event power

```text

```

Determine whether these values provide a defensible lower bound for statistical inference.

If not, propose a prospective power/testability rule that does not depend on observed effect size from H40/H41.


Check whether selecting by the same lower bound used for pass testing is valid after simultaneous inference.

## 3.10 Calibration

Determine whether this cleanly separates:

```text

```
