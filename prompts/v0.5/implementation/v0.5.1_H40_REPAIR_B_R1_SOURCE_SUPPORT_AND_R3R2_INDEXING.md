# Repair 2 — exact R3R2 D2 Donchian window

R3R2 Section 2.2:

```text
Reference bars:
close_time < t
open_time in (t-W, t)

last closed signal bar is excluded
```

Therefore `open_time == t-W` is outside the reference set.

Current code incorrectly uses:

```python
range(2, W + 1)
```

which includes `t-W`.

Implement the semantic predicate exactly. Do not rely on a shifted integer range without proving
equivalence.

For hourly aligned data, the accepted reference set must satisfy all of:

```text
open_time > t-W
open_time < t
close_time < t
bar != last closed signal bar
```

Keep frozen rules unchanged:

```text
U = max(reference highs)
L = min(reference lows)
C > U => +1
C < L => -1
C == U or C == L => 0
minimum complete bars = (W/24)*6
missing/insufficient => fail closed / no trade
```

### Mandatory boundary regression

Use an extreme sentinel at exactly `t-W`.

Changing only that sentinel must not change D2 output.

Also add checks that an extreme bar at the nearest included left-side hour does affect the range,
proving the test distinguishes excluded vs included boundaries.
