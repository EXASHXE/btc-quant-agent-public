production runtime seal:

```text

 -> H40RuntimeSourceSplitAttestation
 -> active_required_source_ids

 -> H40SourceRecord
 -> H40SourceValidationReceipt
 -> exact local bytes at record.locator
```

Every production source used for economic reconstruction must already be an active required source
under the sealed REGISTERED roster and must be VERIFIED by the accepted runtime source/split
authority.

manifest and split attestation must remain mutually consistent.

## Exact economic extraction rules

For each required source:

1. require the canonical runtime `H40SourceRecord`;
2. require a VERIFIED `H40SourceValidationReceipt`;
3. require exact `source_record_hash` equality with runtime attestation evidence;
4. require exact `source_validation_receipt_hash` equality;
5. recompute file SHA-256 from exact source bytes and require equality;
6. use **the receipt's verified `timestamp_field`**;
7. require cadence = `1h` for the H40 economic adapter;
8. reconstruct unique UTC hourly rows, sorted ascending;
9. extract only:
   `open`, `high`, `low`, `close`;
10. require every economic value to be finite IEEE-754 binary64;
11. require positive OHLC and valid OHLC geometry;
12. canonical economic numeric representation for row hashing is exact
    `repr(float_value)`;
13. hash the ordered canonical economic rows;
14. bind exact economic row count;
15. compare both count and digest with V2 source-derivation evidence.

Accepted support interval:

```text
[2021-01-01T00:00:00Z, 2023-02-01T00:00:00Z)
```


enter the Discovery decision denominator.


