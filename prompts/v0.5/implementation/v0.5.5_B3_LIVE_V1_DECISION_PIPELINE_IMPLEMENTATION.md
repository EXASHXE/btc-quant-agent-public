## Required schemas

### CasePackageV1

Implement immutable Pydantic schema with canonical JSON + SHA-256 case hash.

Required categories:

- identity/timestamps/TTL;
- symbol, trigger, strategy/version, direction;
- source evidence/snapshot identity;
- price/entry/support/resistance/ATR/vol;
- 15m/1h/4h regime;
- funding/OI/OI 1h/4h/12h/basis/taker/ratios;
- spread/book imbalance/liquidity;
- reason/risk/entry-quality/grid state;
- accepted calibration only when authoritative;
- account context fields, nullable on Day 1;
- data quality/staleness/missing/source errors.

Secrets are forbidden.

### AnalysisResultV1

Strict Pydantic/JSON Schema output.

Action enum:

```text
NO_ACTION
OPEN_LONG
OPEN_SHORT
HOLD
REDUCE
CLOSE
ADD
MOVE_STOP
TAKE_PARTIAL
PAUSE_GRID
GRID_REVIEW
```

Include:

- backend/model/provider request;
- case ID/hash;
- confidence;
- entry quality;
- thesis strength;
- supporting/risk/invalidation factors;
- risk_modifier = BLOCK | REDUCE | STANDARD;
- secondary/manual review booleans;
- narrative.

Reject extra executable authority fields.

The model may not own:

- quantity;
- final notional;
- leverage;
- order type;
- executable price.

### TradeProposalV1

Deterministic output only:

- proposal ID/hash;
- case hash;
- analysis result hashes;
- risk policy hash;
- entry range;
- SL/TP1/TP2;
- risk budget;
- recommended notional;
- margin;
- deterministic leverage;
- fee/slippage/funding estimates;
- max loss;
- expiry;
- allowed price drift.
