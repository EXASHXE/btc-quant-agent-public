# v0.5.0 R01 — Repository Surface Reduction / Legacy Research Cleanup

## Mission

Perform the first v0.5 comprehensive simplification pass on `EXASHXE/btc-quant-agent`.

This round is **surface reduction, not semantic redesign**. Reduce the active repository/model-input surface by deleting dead historical research implementations, one-off runners, obsolete symbolic paths, duplicate historical documents/configs, and legacy consumer branches that are no longer authoritative after C-lite — while preserving the accepted formal economic kernel, scientific evidence boundaries, H39 blindness/freeze semantics, Final Holdout sealing, and execution-disabled defaults.

The objective is a materially smaller and clearer active code branch with one obvious current research path, not a prettier archive of the same historical material.

# 5. Legacy consumer/API/CLI reduction

C-lite established one current formal authority. R01 should reduce the user-facing ambiguity created by legacy diagnostic consumers.

Audit the CLI/API/service surface and simplify it under these rules:

1. `quantctl backtest`, `quantctl research`, and `quantctl replay` must remain current-formal consumers.
2. Do not reintroduce implicit CSV/legacy fallback behavior.
3. Historical `legacy-*` commands may be removed if no supported current use remains.
4. If a legacy command cannot yet be removed due to packaging/backward-compatibility constraints, replace the large path with the smallest explicit fail-closed diagnostic/deprecation stub practical; never silently dispatch it into current formal authority.
5. Remove dead imports, dispatcher branches, obsolete help text, and unused service wiring after deletion.
6. Keep operational execution commands/gates semantically unchanged and disabled by default.
7. Update README/current architecture documentation so a new agent/user can identify the current research path without reading historical narratives.

The desired visible shape is approximately:

```text
explicit formal job
  -> formal facade
  -> accepted P5/P6 economic kernel
  -> verified formal result / optional validated registry phase

H39
  -> separate protected frozen gates

execution
  -> separately gated, disabled by default
```

Historical research engines should not appear as peer current authorities.
