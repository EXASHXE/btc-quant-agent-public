## 10. Deterministic level construction

Let:

```text
L = lower_bound
U = upper_bound
N = grid_count
```

Construct exactly N+1 arithmetic levels:

```text
level[i] = L + i * (U - L) / N
i = 0..N
```

Use deterministic decimal arithmetic from canonical string inputs.

Persist the exact level list.

Decision-time `estimated_grid_pct` is diagnostic only.

No future respacing.

## 12. Normalized capital and sizing

Reference capital:

`1.0 normalized quote-capital unit`

No leverage.

No Martingale.

No variable size multiplier.

Per-slot opening notional:

`unit_notional = 1.0 / N`

Opening quantity:

`quantity = unit_notional / open_price`

One simultaneous lot maximum per slot.

Total simultaneously open opening notional must never exceed 1.0.

Capital utilization is measured against this 1.0 reference capital.

## 13. LONG_BIAS semantics

Long-only.

Downward crossing of eligible level i:

- if long slot i is free, open one long at level[i].

Close that lot only on a later upward crossing of:

`level[i+1]`

After close, re-arm slot i.

Never open short inventory.

---

## 14. SHORT_BIAS semantics

Short-only.

Upward crossing of eligible level i:

- if short slot i is free, open one short at level[i].

Close that lot only on a later downward crossing of:

`level[i-1]`

After close, re-arm slot i.

Never open long inventory.

---

## 15. NEUTRAL semantics

Use the fixed anchor.

Below anchor:

- downward crossings open long slots;
- next-higher level closes matching long lot.

Above anchor:

- upward crossings open short slots;
- next-lower level closes matching short lot.

Crossing the anchor itself does not create a new directional lot.

Do not re-anchor from future data.

---

## 16. Crossing order

A segment p0→p1 crosses each level in the segment.

Ascending:

lowest crossed → highest crossed.

Descending:

highest crossed → lowest crossed.

Touch counts as crossing.

Do not fill a slot twice from the same event.

## 18. 1m intrabar path model

For every 1m candle evaluate both admissible paths:

```text
PATH_A = OPEN → HIGH → LOW → CLOSE
PATH_B = OPEN → LOW → HIGH → CLOSE
```

Start both from identical entering state.

Process all level crossings in path order.

If resulting economic states differ, select a deterministic conservative state with precedence:

1. lower current total marked equity;
2. if tied, larger absolute inventory notional;
3. if tied, larger cumulative fees/costs;
4. if tied, lexicographically smaller path identity.

Persist divergent-minute selected path identities.

Version:

`GRID_1M_CONSERVATIVE_TWO_PATH_V1`

This is conservative shadow accounting, not exact tick reconstruction.

Reference capital is 1.0, so net PnL is numerically normalized return.

```text

```

```text

gross_pnl = qty * (open_price - close_price)
```

Maker fee:

`abs(qty * fill_price) * maker_fee_rate`

Terminal taker fee:

`abs(qty * terminal_execution_price) * taker_fee_rate`

## 25. Funding accounting


- positive funding debits longs;
- positive funding credits shorts;
