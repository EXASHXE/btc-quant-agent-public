# Required Fix 2 — exact O_RANGE standard true range, no fallback

Normative R3R2 Section 2.6:

```text
TR_k =
max(
  H_k - L_k,
  |H_k - C_{k-1}|,
  |L_k - C_{k-1}|
)
```

and:

```text
E(t) =
TR_last /
mean(TR over 24 reference bars strictly before t, excluding last bar)
```

The accepted TR-bearing population is:

```text
24 reference bars
+
1 last bar
=
25 TR-bearing bars
```

The preceding close required to calculate the first reference bar's standard TR is an input
dependency. It is not an additional reference observation and must not enter the 24-bar mean.

Current code silently falls back to:

```python
TR = H - L
```

when that preceding close is missing.

That fallback is forbidden.

## Required behavior

For the first reference TR:

```text
previous close MUST come from the immediately preceding complete PIT-valid source bar.
```

If unavailable:

```text
O_RANGE undefined
-> NO_TRADE / PIT_UNAVAILABLE
```

No H-L substitution.

All 25 TR-bearing bars must themselves remain complete and PIT-valid.

The immediately preceding close must also be PIT-valid.

## Mandatory tests

1. 25 TR-bearing bars + valid preceding close -> exact expected O_RANGE.
2. All 25 TR-bearing bars exist but preceding close missing -> undefined.
3. Preceding close present but PIT-invalid -> undefined.
4. Large overnight/hourly gap between earliest reference bar and preceding close materially changes
   the earliest reference TR according to the standard formula.
5. Sentinel before the required preceding close does not affect the result.
6. Last-bar TR remains the numerator and is excluded from the 24-reference mean.
7. denominator == 0 -> undefined.
8. fewer than 25 TR-bearing bars -> undefined.

Do not change O_RANGE thresholds or percentile boundaries.
