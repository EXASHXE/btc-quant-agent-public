## Kill switch

Implement deterministic local kill switch.

At minimum triggers:

- daily loss cap;
- account drawdown cap;
- unreconciled account state beyond timeout;
- repeated order-state conflict;
- wrong environment/credentials;
- mandatory protective order missing beyond grace period.

Kill switch blocks new risk-increasing intent.

Risk-reducing close path may remain separately authorized by deterministic policy,
but LIVE remains blocked in this task.
