# v0.5.0 R02 — Runtime / Orchestration Convergence (Gemini-Optimized Execution Contract)

## Mission

Continue the v0.5 simplification on `EXASHXE/btc-quant-agent` after accepted R01.

R02 is an **orchestration and entry-surface convergence round**. It is deliberately **not** an economic-kernel redesign, not a research-methodology redesign, and not a new abstraction/framework round.

The objective is simple:

> Make the current repository expose fewer ways to reach the same semantics, while preserving the already accepted formal research authority exactly.

This prompt is optimized for Gemini execution. When there is ambiguity, prefer **smaller, explicit, mechanically verifiable changes** over broad refactors.
