## 2. Exact candidate-lock coverage population

The candidate-lock scientific coverage gate is computed only on:

```text
WF1_CALIBRATION final emitted actions
```

Numerator:

```text
N_accept =
count of final LONG or SHORT actions on WF1_CALIBRATION
```

Denominator:

```text
N_base =
count of all base-eligible decision rows on WF1_CALIBRATION
within the candidate active asset scope
```

Coverage:

```text
coverage = N_accept / N_base
```

Do NOT compute candidate-lock coverage from WF1 Training proposed-side rows.

Do NOT require both Training and Calibration coverage gates.

---

## 3. Base-eligible denominator semantics

The denominator is fixed before candidate-specific downstream gates.

A row remains in `N_base` if it is otherwise an authoritative base-eligible WF1_CALIBRATION decision row, even when the candidate later emits NO_TRADE because of:

```text
regime rejection
opportunity rejection
no direction
geometry failure/insufficient cell
calibration abstention
confidence-threshold abstention
other candidate-specific downstream abstention
```

Candidate-specific filtering must not shrink its own coverage denominator.

Do not use:
- only regime-passing rows;
- only opportunity rows;
- only proposed-side rows;
- only calibrator input rows;
- only rows with final direction.

## 4. Asset-scope counting

### Single-product

Count base and accepted rows for the candidate's active product only.

### Pooled BTC+ETH

Each:

```text
(timestamp, product)
```

is one decision row.

Use:

```text
N_accept =
accepted BTC + accepted ETH

N_base =
base BTC + base ETH

coverage =
sum accepted / sum base
```

Do NOT:
- average BTC and ETH percentages;
- impose equal asset weighting;
- invent a per-asset coverage gate.

## 5. Exact hard-gate comparison

Accepted interval is inclusive:

```text
0.25% <= coverage <= 10.0%
```

Canonical exact integer comparison:

```python
lower_pass = 400 * N_accept >= N_base
upper_pass = 10 * N_accept <= N_base
coverage_pass = lower_pass and upper_pass
```

Do not rely on binary floating-point comparison for gate authority.

Persist `N_accept`, `N_base`, and the exact pass/fail components.

A decimal/display coverage value may be emitted for diagnostics but is not the authoritative comparator.

## 6. Edge cases

### N_base == 0

```text
NOT_TESTABLE
```

Do not emit an imputed coverage.

### N_base > 0 and N_accept == 0

```text

lower coverage hard gate = FAIL
```

This is a valid hard-gate failure, not missing evidence.

### Accepted action outside denominator universe

Fail closed.

The verifier must prove every accepted numerator row belongs to the authoritative candidate-active-scope base-eligible denominator universe.

## 9. New mandatory coverage tests

### COV01 final-action population

- WF1 Training proposed-side fraction;
- WF1 Calibration final-action coverage.

Require candidate-lock gate to follow Calibration final-action coverage only.

### COV02 training coverage ignored

Training proposed-side fraction outside [0.25%,10%] must not itself fail the candidate-lock coverage gate when all separate training support floors pass.

### COV03 NO_TRADE stays denominator

Candidate-specific final abstentions remain denominator rows.

### COV04 no opportunity-denominator shrinkage

A candidate with sparse opportunity gate cannot divide accepted actions only by opportunity rows.

Require all authoritative base-eligible rows as denominator.

### COV05 lower boundary inclusive

Choose counts satisfying exactly:

```text

```

### COV06 just below lower bound

Choose integer counts immediately below 1/400.

Require FAIL.

### COV07 upper boundary inclusive

```text

```

Require PASS.

### COV08 just above upper bound

Require FAIL.

### COV09 zero denominator

Require NOT_TESTABLE.

### COV10 zero numerator

Positive denominator + zero accepted -> hard-gate FAIL.

### COV11 pooled count weighting

Construct unequal BTC/ETH denominator sizes where:
- pooled-count ratio;
- average of per-asset percentages

produce different decisions.

Require pooled-count ratio.

### COV12 numerator subset proof

Require fail closed.
