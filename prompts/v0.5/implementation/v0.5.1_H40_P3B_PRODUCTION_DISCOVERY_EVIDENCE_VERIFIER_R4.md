## 2. Fundamental bootstrap interpretation

The moving-block bootstrap resamples:

```text
source-anchored decision/outcome observation bundles
```

It does NOT construct a new synthetic market-price path.

The concatenated bootstrap sequence controls only:

```text
which source decision hours appear
how many times they appear
their replicate order
which positions survive final H trimming
```

It does not control:
- feature lookups;
- candidate model execution;
- entry price lookup;
- fixed-horizon endpoint lookup;
- label construction;
- proxy return construction.

---

## 3. Source block core

Each sampled block core remains exactly:

```text
168 consecutive source decision hours
```

joint across BTC/ETH according to existing authority.

For each sampled source hour, use the candidate action already bound to that original source hour.

Do not re-run the candidate on the synthetic concatenation.

Do not recompute features across synthetic block boundaries.

## 4. Fixed-horizon source anchoring

For every retained sampled accepted trade:

```text
source decision time = t
candidate fixed primary horizon = h
```

use exactly the original source-timeline:

```text
P0(t)
C_h(t)
r_h(t)
label(t,h)
proxy r_net(t,h)
```

The endpoint `C_h(t)` must be independently verified from accepted source/split evidence.

Never use a price from the next sampled block as the exit of a trade from the previous block.

This prohibition applies even if the synthetic positions are adjacent after concatenation.

## 5. Outcome-support halo

A source-bound endpoint may lie beyond the 168-hour block core.

Example:

```text
source core hour 167
primary horizon = 12h
```

The source-local +12h endpoint is valid only when:
- it is authorized under the original split/purge/source contract;
- it is bound to the retained source decision identity;
- the required raw endpoint evidence is complete.

Those support hours:
- do not enlarge the 168-hour bootstrap core;
- do not become sampled decision hours;
- do not increase bootstrap multiplicity;
- do not permit any new candidate action.

If source-local support is unavailable, fail closed.

Do not use the next synthetic block.

## 6. Final H-position trim

After drawing B source blocks:

```text
concatenate 168 * B sampled core-hour positions
retain positions [0, H)
discard positions [H, 168*B)
```

### Retained tail decision

A retained accepted trade near synthetic position H remains included if its original source-bound outcome is authorized and complete.

Do NOT drop the last 4/8/12 hours merely because the source outcome extends past synthetic H.

### Discarded decision

A position at synthetic index >= H contributes nothing:
- no decision occurrence;
- no trade;
- no precision row;
- no net-return row.

There is no partially retained trade.

This is bootstrap multiplicity, not duplicate-data corruption.

Overlapping selected blocks behave analogously.

## 10. New mandatory boundary tests

Add to the inherited P3B adversarial suite:

### B01 last hour of block

Create block A whose source-hour 167 emits an accepted 12h trade.

Choose an unrelated block B next.

Require the trade uses A's original +12h source endpoint.

Changing B must not change A's trade label or r_net.

### B02 artificial jump rejection

Construct A and B with a deliberately huge price discontinuity at their synthetic concatenation boundary.

Prove no retained trade outcome is affected by that artificial jump.

### B03 source support beyond core

A retained trade may use source-local endpoint outside its 168h core if that endpoint is within accepted source/split/purge support.

Prove support rows create zero additional bootstrap decisions.

### B04 missing halo endpoint

Remove required source-local endpoint evidence.

Verifier must fail closed.

It must not:
- use block B;
- shorten horizon;
- drop only the trade;
- impute.

### B05 trimmed tail retained trade

Make the final retained synthetic core position an accepted 12h trade.

Require it remains in the replicate with its source-local outcome.

### B06 post-H position discarded

Make the first discarded synthetic position an accepted trade.

Require it contributes nothing.

### B07 duplicate source hour

Sample the same source hour twice.

Require two bootstrap occurrences with identical source-bound scientific values.

### B08 overlapping blocks

Select overlapping source blocks.

Require ordinary bootstrap multiplicity; no deduplication.

### B09 no model reexecution

Construct synthetic adjacent blocks whose feature continuity would change a model output if recomputed.

Require the sampled action remains the source-bound original action.

### B10 synthetic index not source locator

Mutate synthetic position/order while preserving sampled source identities.

Source P0/C_h lookups and trade outcomes must remain unchanged.

### B11 joint asset preservation

BTC/ETH rows for a sampled source hour remain jointly sampled as accepted.

No per-asset independent block start.
