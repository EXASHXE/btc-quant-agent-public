## 1. Mission

Close the remaining same-exact-type runtime substitution path in production Discovery verification.

The current lifecycle guard correctly requires:

```python
type(verifier) is H40ProductionDiscoveryEvidenceVerifier
```

This rejects foreign implementations, subclasses, and proxies.

It is still insufficient because an object with the exact accepted type can be constructed or mutated so that the scientific behavior executed is no longer the reviewed implementation.

The repository currently contains a concrete demonstration in lifecycle test setup:

```python
verifier = object.__new__(H40ProductionDiscoveryEvidenceVerifier)
setattr(verifier, "verify_discovery_manifest", ...)
setattr(verifier, "verify_candidate", ...)
setattr(verifier, "verify_wf_fold", ...)
```

That object passes the exact-type check while substituting all-pass behavior.

The production path must fail closed against this class of substitution.
