## Required implementation areas

- runtime authority snapshot.

### 2. Immutable configuration ledger

Implement exact 168-row ledger materialization:

- deterministic ordering;
- canonical serialization;
- transitive semantic hashes;
- append-only rejected rows;
- explicit NOT_TESTABLE handling.

No runtime grid expansion.

### 3. Feature contracts

Implement only frozen formulas:

- D1 trend;
- D2 mean reversion;
- D3 breakout;
- D4 funding;
- D5 imbalance;
- allowed combinations.

Every feature must enforce:

- closed-bar causality;
- PIT availability;
- deterministic indexing;
- no future information.

### 4. Calibration

Implement:

- Platt with non-negative slope constraint;
- isotonic clipped left-step prediction;

### 5. Statistical decision utilities

- p0 contexts;
- RANDOM_MATCHED baseline;

- candidate lock ordering.

Do not introduce alternative statistics.

### 6. Guards

- forged hashes;
- invalid source states;
- authority mismatch;
- outcome access;
- live execution paths.
