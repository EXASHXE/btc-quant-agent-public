### 4.6 `events.py` — Point-in-Time Event Processing & Censoring
- Decision cutoff: completed information through $B_0(t) = [t-1\text{h}, t)$.
- Event decision at $t$ occurs strictly before reference entry open at $t$.
- Entry mark: $P_{\text{entry}}(t) = Open(B_{\text{entry}}(t))$ where $open\_time == t$.
- Exit mark: $P_{\text{exit}}(t, h) = Open(B_{\text{exit}}(t, h))$ where $open\_time == t + h$.
- Cross-asset synchronization: D4 conditioning strictly compares synchronized timestamps $t$.
- Right-boundary censoring: If $t + h \ge T_{\text{end}}$, the event is right-censored and unavailable ($A_{i,t} = 0$).

### 4.8 `inference.py` — Ratified Stage R2 Inference Engine
Implement the exact repaired Stage R2 methodology:
- Moving-block Studentized bootstrap-t with $L = 120\text{ hours}$ and $B = 10,000$ draws.
- Shared-clock resampling: For each bootstrap draw $b$, a single sequence of block indices is generated and applied jointly across all 20 candidates and source assets.
- Point estimator: Ratio estimator $\hat{\mu}_i = \frac{\sum_t Z_{i,t}}{\sum_t A_{i,t}}$, where $Z_{i,t} = A_{i,t} \cdot (R_{i,t,h} - 0.0012)$.
- Künsch (1989) ratio-estimator block-sum standard error $SE_i$ and bootstrap replicate standard error $SE_{i}^{*(b)}$.
- Single-step joint maximum Studentized critical value $q_{1-\alpha}$ over null-centered bootstrap statistics:
  $$T_i^{*(b)} = \frac{\hat{\mu}_i^{*(b)} - \hat{\mu}_i}{SE_{i}^{*(b)}}$$
  $$T_{\max}^{*(b)} = \max_{i=1..K} T_i^{*(b)}$$
- Simultaneous Lower Confidence Bound:
  $$\text{LCB}_i = \hat{\mu}_i - q_{1-\alpha} \cdot SE_i$$
- Zero-event / zero-variance handling: Fail-closed with $\text{LCB}_i = -\infty$.

### 4.9 `evidence.py` — Content-Addressed Machine Evidence
