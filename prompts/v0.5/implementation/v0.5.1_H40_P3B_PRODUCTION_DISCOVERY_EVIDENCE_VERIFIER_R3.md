## 2. Exact per-trade proxy-return formula

BASE forward observation remains:

```text
r_h = log(C_h / P0)
```

with positive finite:

```text
P0
C_h
```

Accepted action sign:

```text
LONG  -> +1
SHORT -> -1
```

Exact proxy gross fractional return:

```python
gross = action_sign * math.expm1(r_h)
```

Equivalent:

```text
LONG:
gross = exp(r_h) - 1
      = C_h / P0 - 1

SHORT:
gross = 1 - exp(r_h)
      = 1 - C_h / P0
```

Exact proxy net return:

```python
r_net = gross - c_rt
```

Current H40 V1:

```text
c_rt = 0.0012
```

Therefore:

```text
LONG:
r_net = exp(r_h) - 1 - 0.0012

SHORT:
r_net = 1 - exp(r_h) - 0.0012
```

Use `math.expm1` rather than `math.exp(r_h) - 1` in implementation where practical.
