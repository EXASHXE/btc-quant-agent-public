## Repair 2 — Make HAC lag unit truly hourly

BASE authority requires Newey-West/HAC maximum lag 24 **hours**. R1's accepted-trade sequence index must not be treated as an hour.

For each metric series `z_i` over accepted trades with UTC entry timestamps `t_i`:

```text
N = number of accepted trades
z_bar = (1/N) * sum_i z_i

gamma_0 = (1/N) * sum_i (z_i - z_bar)^2

gamma_k = (1/N) * sum over ordered pairs (i,j)
          where t_j - t_i == k hours
          of (z_i-z_bar)(z_j-z_bar)
          for k = 1..24

rho_k = gamma_k / gamma_0 if gamma_0 > 0, else fail-closed rule
w_k = 1 - k/25
f(z) = 1 + 2*sum_{k=1..24}(w_k*rho_k)
```

Use the same two metric series from R1:

```text
y_i = directional correctness {0,1}
x_i = frozen-proxy net return
```

Then:

```text
n_HAC(z) = N / f(z)
```

with deterministic fail-closed handling for:

- `N < 2`;
- `gamma_0 <= 0`;
- non-finite values;
- `f(z) <= 0`;
- no observed accepted-trade pairs at one or more hourly lags.

Empty lag `k` contributes `gamma_k = 0`; it does not collapse the estimator.

Clip each valid `n_HAC(z)` to `[1,N]`, take the minimum across `y` and `x`, floor to integer, and retain the existing conservative outer minimum with:

```text
N
occupied UTC calendar-day count
HAC effective sample size
```

Clarify that simultaneous BTC/ETH accepted trades are separate observations at the same timestamp. They do not create artificial `k=1` adjacency. Cross-sectional dependence is handled additionally by the joint UTC moving-block bootstrap and occupied-day floor.

Persist all 24 `gamma_k`, `rho_k`, weights, pair counts per lag and final intermediate values so an independent implementation can reproduce `n_eff`.

## Repair 3 — Exact bootstrap / quantile / p-value / seed semantics

### 3A. Quantile convention

Use exactly the nearest-rank convention on `M=10000` sorted bootstrap values:

```text
r(alpha) = max(1, ceil(alpha*M))
quantile_alpha = v_(r(alpha))       # 1-based order statistic
array_index = r(alpha)-1            # 0-based implementation index
```

Therefore:

```text
95% one-sided LCB (alpha=.05)   = v_(500)  = array[499]
97.5% one-sided LCB (alpha=.025)= v_(250)  = array[249]
90% one-sided LCB (alpha=.10)   = v_(1000) = array[999]
```

For upper critical quantiles use:

```text
r_upper(alpha) = ceil((1-alpha)*M)
```

so at alpha=.05 the 95% upper critical order statistic is `v_(9500)` / `array[9499]`.

Delete/supersede any R1 prose implying zero-indexed `floor(M*alpha)` as the selected element.

### 3B. Exact marginal one-sided bootstrap p-values before Holm

