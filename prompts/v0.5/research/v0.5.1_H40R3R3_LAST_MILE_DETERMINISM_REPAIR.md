## 1. One canonical relative hourly-bar index — close R3R2-SOL-01/02/06

Replace the mixed open-time/close-time notation with this single convention.

```text

         [t-(j+1)h, t-jh)

open_time(B_j) = t-(j+1)h
```

```text

```

For consecutive-window contracts, every required hourly interval must exist exactly once. Any missing/duplicate/misaligned bar => `PIT_UNAVAILABLE -> NO_TRADE`.

Define:

```text

H_j = high(B_j)
L_j = low(B_j)
```

All active candle-derived formulas below MUST use this index. Remove/rewrite conflicting `C_X(t-W) = close of bar with open time t-W` wording.
