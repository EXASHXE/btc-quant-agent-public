## 1. Direction owner remains authoritative after calibration — R3R3-SOL-10

```text

```


## 2. Exact isotonic prediction map — R3R3-SOL-11

Preserve the R3R2 PAVA fit and tie pooling. Freeze the evaluation map exactly:

Let the fitted isotonic calibration have sorted distinct calibration score support:

```text
x_1 < x_2 < ... < x_m
```

with monotone fitted block values:

```text
p_1 <= p_2 <= ... <= p_m
```

For any query raw score `x`:

```text
if x <= x_1:
    p_up = p_1
elif x >= x_m:
    p_up = p_m
else:
    i = max{k : x_k <= x}
    p_up = p_i
```

Thus prediction is a **clipped left-step function**, no interpolation and no out-of-range failure.

Tie handling remains: identical calibration raw scores are one pooled support value before PAVA prediction.

Degenerate cases:

- no support / one-class target / otherwise invalid fit -> fail closed;
- an isotonic map may be constant, but the direction-owner rule in Section 1 prevents it from reversing side;
- no linear interpolation, nearest-neighbor choice, extrapolation slope, or library-default behavior is authorized.

## 3. Exact adaptive-bin ECE — R3R3-SOL-12

Freeze one deterministic equal-frequency adaptive-bin ECE algorithm.

Population is exactly the already-frozen binary `probability_diagnostic_population`.

```text

```

```text

```

where product canonical order is `BTCUSDT < ETHUSDT` and `(decision_t, product)` is unique within a candidate evaluation population.

Create `B` contiguous equal-frequency bins using exact integer boundaries:

```text

```

so every row is assigned exactly once and bin sizes differ by at most one. Since `B <= floor(N/20)`, every bin has at least 20 observations.


