## Frozen semantic model

### 1. Durable authority capsule

The authority consumed by external PositionCase analysis must be a canonical immutable capsule that
covers at least:

- event_id;
- event_hash;
- symbol;
- environment;
- credential_namespace;
- account_id;
- position_side;
- position_authority_key;
- frozen PositionCase id/hash;
- lease/dispatch identity required for ownership.

Represent this with either:
- explicit immutable dispatch columns plus canonical hash; or
- an equivalent canonical serialized authority receipt.

The canonical hash must be deterministic and independently recomputable.

### 2. Atomic analysis admission

Immediately before the external analysis side effect, mint a one-shot admission identity in a single
SQLite transaction.

That transaction must atomically prove:
- canonical PositionEvent still verifies and matches its persisted payload/hash;
- full event authority matches the dispatch capsule;
- dispatch lease owner is current;
- frozen PositionCase matches event and dispatch authority;
- the dispatch has not already consumed a conflicting admission.

Then persist an immutable:

`analysis_admission_hash`

or equivalent receipt.

Do not implement this as:
`SELECT/verify -> close connection -> ordinary boolean -> provider call`

with no durable admission state. That is the R6 defect shape.

### 3. Meaning of the admission receipt

Once atomically minted, the admission receipt is the one-shot authority for the exact frozen
PositionCase provider call.

A later mutation of the archival PositionEvent row must not be able to substitute a different case,
symbol, account or authority for that admitted call.

The provider call must use the already-frozen PositionCase associated with that exact admission.

### 4. Terminal DONE binding

DONE must be a guarded atomic transition that binds:

- current lease ownership;
- frozen PositionCase identity/hash;
- analysis_admission_hash;
- canonical dispatch authority hash;
- and canonical PositionEvent consistency.

Use one SQL UPDATE with EXISTS/join predicates or an equivalent single-transaction check+transition.

If canonical event authority diverged before DONE:
- DONE must not succeed;
- dispatch must fail closed / enter the existing safe non-DONE disposition;
- do not overwrite the divergence.

### 5. Admission mutation

Once minted, authority capsule/admission identity must be immutable.

DB-level UPDATE/DELETE fences are still required.

If a disposable validation fixture bypasses those fences:
- a changed dispatch authority/admission hash must not allow DONE;
- it must not substitute a different PositionCase into the already-authorized provider call.

### 6. Crash / retry semantics

Explicitly handle:

`admission persisted -> process crashes before provider completion is durably known`

Do not blindly issue a second external analysis call under a new lease.

Use one of:
- an already-existing authoritative provider idempotency key bound to the admission; or
- fail-closed/manual-recovery state for uncertain completion.

Do not invent a broad workflow engine.

Document the chosen behavior in tests/evidence.
