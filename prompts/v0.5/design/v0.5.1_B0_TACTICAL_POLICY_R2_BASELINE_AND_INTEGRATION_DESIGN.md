## 1. Executive Summary & Architectural Scope

The B0 Tactical Policy R2 Integration integrates the operational MarketWatch prototype into the scientific mainline codebase of `btc-quant-agent` under strict semantic sealing and B0-R1 semantic authority reconciliation.

### Key Design Pillars
1. **Scientific Non-Interference:** Strict scientific fence around H40/H41 research authority (`src/btc_quant_agent/h40/*`). Zero shared mutations, zero cross-talk.
2. **Execution Safety Fence:** MarketWatch is an informational scanner and tactical advisory layer with shadow forward evidence. It contains zero private trade execution capabilities, zero order placement endpoints, and zero position mutation APIs.
3. **Semantic Disambiguation & Integrity Seal:**
   - Separation of non-probabilistic heuristics (`RULE_SCORE_V1`, `HEURISTIC_RULE_QUALITY_BAND_V1`) from calibrated statistical probabilities.
   - Separation of closed-bar multi-horizon returns (`ELAPSED_TIME_RETURNS_V1`) from single-bar rate of change.
   - Separation of the canonical 8-symbol reference universe (`TACTICAL_RS_UNIVERSE_V1`) from ad-hoc symbol lists, with graceful degradation when universe data is incomplete.
   - Formal static playbook precedence (`STATIC_PRECEDENCE_V1`) across 5 active playbooks, reserving `RANGE_MEAN_REVERSION` as inactive.
   - Observational-only slow EMA (EMA200) strictly computed on closed bars with a 50-bar warmup margin.
   - Additive, idempotent SQLite schema evolution with strict exclusion of legacy unsealed records from modern tactical queries.
   - Preservation of high-value forward-evidence path evaluation (R2.3 intrabar 1m resolution, stop-first precedence).

## 3. Detailed Component Architecture

### 3.1 Multi-Horizon Elapsed Time Returns (`ELAPSED_TIME_RETURNS_V1`)
- **Horizons:** 1h (3,600,000 ms), 4h (14,400,000 ms), 12h (43,200,000 ms).
- **Base Interval:** Confirmed closed 15m candles.
- **Exact Horizon Anchoring:** An anchor candle is matched strictly at `latest_closed.close_time_ms - horizon_ms`. If the exact anchor is missing or span is insufficient, the status is set to `MISSING_HORIZON_ANCHOR` or `INSUFFICIENT_HISTORY` with return `None`. No nearest-neighbor fallback is permitted.
- **Forming Bar Isolation:** Forming candles (`closed=False`) are strictly filtered out before computing closed-bar elapsed returns.
- **Benchmark Volatility Shock:** Evaluated strictly on true 1h elapsed return (`return_1h`). Fails closed when `return_1h is None` with audit reason `BTC_RETURN_1H_UNAVAILABLE` / `ETH_RETURN_1H_UNAVAILABLE`. Legacy 12-bar ROC fallback is strictly prohibited.

### 3.2 Observational Slow EMA
- Configurable `ema_slow` (default: 200) located in `MarketWatchThresholdsConfig`.
- Computed strictly on closed bars.
- Requires deterministic warmup margin: `len(closed_candles) >= ema_slow + 50`. If insufficient, status is `EMA_SLOW_INSUFFICIENT_HISTORY` and value is `None`.
- Observational only: Does NOT affect playbook gating or directional decisions.
- Included in `compute_market_watch_config_hash` and `compute_required_fetch_bars`.

### 3.3 Playbook Registry & Static Precedence (`STATIC_PRECEDENCE_V1`)
- **Active Playbooks (5):**
  1. `TREND_PULLBACK`
  2. `BREAKOUT_RETEST`
  3. `FAILED_BREAKOUT`
  4. `FAILED_BREAKDOWN`
  5. `VOLATILITY_EXPANSION`
- **Reserved Inactive (1):**
  - `RANGE_MEAN_REVERSION` (retained in enum and registry, never evaluated or selected).
- **Candidate Evaluation:** `evaluate_all_playbook_candidates` evaluates all 5 active playbooks, returning a mapping of each playbook to `PlaybookCandidate(candidate_status, confidence_band, ...)`.
- **Selection Precedence:**
  `select_playbook_candidate` selects strictly in precedence order:
  `TREND_PULLBACK > BREAKOUT_RETEST > FAILED_BREAKOUT > FAILED_BREAKDOWN > VOLATILITY_EXPANSION`.
  The first present candidate in precedence order is selected (without promoting `ACTIONABLE` over earlier `WATCH` candidates).

### 3.4 Canonical Reference Universe (`TACTICAL_RS_UNIVERSE_V1`)
- **Canonical Membership:** Exactly 8 symbols in stable order:
  `("BTCUSDT", "ETHUSDT", "SOLUSDT", "LINKUSDT", "SUIUSDT", "XRPUSDT", "DOGEUSDT", "BNBUSDT")`.
- **Degraded Universe Rules:**
  If ANY symbol in the reference universe is missing from snapshots OR has incomplete returns (`return_1h`, `return_4h`, or `return_12h` is `None`):
  - `universe_status = "UNIVERSE_DEGRADED"`.
  - Incomplete return members listed in `incomplete_return_members`.
  - Missing snapshot members listed in `missing_members`.
  - Cross-sectional median return is set to `None` (neutral).
  - Cross-sectional percentile rank is set to `0` (disabled).
  - Un-renormalized RS weights: Missing factors drop out naturally without inflating other weights.
  - Pairwise relative performance against BTC and ETH remains active independently.
- **RelativePerformance Field Integrity:** Legacy `perf_15m` field is deprecated (`None`) and strictly never populated with 1h data.

### 3.5 Scanner Collection Semantics
- When `--symbols` is specified (e.g. `--symbols LINKUSDT`), the collection universe is computed as:
  `target_symbols UNION reference_universe UNION benchmark_symbols`.
- This ensures relative strength rankings, benchmark shocks, and cross-sectional metrics for target symbols are identical whether scanned alone or via `--all`.

### 3.6 Rule Score Semantics (`RULE_SCORE_V1`)
- Explicitly documented as a non-probabilistic deterministic heuristic rule score.
- Range: `[0.0, 100.0]`.
- Fatal vetoes force `rule_score = 0.0`.
- Direction-aware scoring:
  - LONG: rewards `HH_HL`, `HEALTHY_LONG_BUILD`, taker ratio > 1.
  - SHORT: rewards `LH_LL`, `HEALTHY_SHORT_BUILD`, taker ratio < 1.
  - WAIT: discounted/capped to prevent actionable opportunity misclassification.
- Legacy alias: `opportunity_score` mirrors `rule_score` exactly.
- Heuristic quality bands: `HEURISTIC_RULE_QUALITY_BAND_V1` (`LOW`, `MEDIUM`, `HIGH`).

### 3.7 Non-Destructive Idempotent Database Evolution
- Table migrations are strictly additive (`ALTER TABLE ADD COLUMN` inside `try...except`).
- All B0 semantic version columns added to `market_watch_assessments` and `market_watch_shadow_records`.
- `get_tactical_shadow_records(include_legacy=False)` excludes unsealed historical records (`policy_version != 'TACTICAL_POLICY_R2_B0'`).

### 3.8 Preservation of Forward Evidence Engine
- Retains R2.3 fill-anchored intrabar path resolution (`evaluate_intrabar_path`).
- Same-minute stop-first precedence preserved:
  - Within fill minute: touch entry + stop => `STOP` with `ONE_MINUTE_FILL_BAR_STOP_FIRST`.
  - Touch entry + TP1 (no stop) => fill succeeds, TP1 not credited same minute.
  - Subsequent 1m candles: dual touch => `STOP` with `FIFTEEN_MINUTE_STOP_FIRST`.
  - Terminal reasons: `STOP`, `TP1`, `TIMEOUT`, `INVALIDATED`.

### 3.9 DerivativesRegime Horizon & Fallback Reconciliation
- Evaluated strictly using true 1h elapsed return `return_1h` (computed before regime evaluation), not legacy 12-bar `tf_1h.roc`.
- When `price_change_1h_pct is None`:
  - Sharp deleveraging (`oi_1h <= -0.04` or `oi_4h <= -0.07`) yields `DerivativesRegime.DELEVERAGING` (never upgraded to `LONG_LIQUIDATION`).
  - Crowding checks without price yield `LONG_CROWDING` or `SHORT_CROWDING`.
  - Price-dependent states (`HEALTHY_LONG_BUILD`, `HEALTHY_SHORT_BUILD`, `SHORT_COVERING`, `LONG_LIQUIDATION`) are prohibited from firing.
  - Otherwise defaults safely to `DerivativesRegime.NEUTRAL`.
