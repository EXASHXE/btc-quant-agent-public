# 2. Scientific Objective and Narrowed Economic Claim

## 2.1 The Core Scientific Question

> Does a small, preregistered set of 20 PIT-valid BTC/ETH directional hypotheses exhibit positive net economic directional expectancy on the Discovery partition after a fixed friction proxy and multiplicity-adjusted simultaneous uncertainty?

## 2.2 Formal Numerical Primary Endpoint

For candidate $i$ evaluated across the Discovery partition, the sample mean net return is:

$$\mu[i] = \frac{\sum_u A[i, u] \cdot \left( s_{i,u} \cdot \left(\frac{P_{\text{exit}}(u)}{P_{\text{entry}}(u)} - 1\right) - c_{\text{rt}} \right)}{\sum_u A[i, u]}$$

where:
- $u$ indexes canonical hourly source epochs;
- $A[i, u] \in \{0, 1\}$ is the event eligibility indicator;
- $s_{i,u} \in \{-1, +1\}$ is the directional action sign;
- $P_{\text{entry}}(u)$ and $P_{\text{exit}}(u)$ are the causal reference price marks;
- $c_{\text{rt}} = 0.0012$ is `FIXED_FRICTION_PROXY_BASE` (12 bps round-trip).

A secondary diagnostic proxy evaluates:
- $c_{\text{rt,stress}} = 0.0024$ (`FIXED_FRICTION_PROXY_STRESS`, 24 bps round-trip).

## 2.3 Narrowed Scope of Claim (Resolving Astra H41-H04)

The scientific claim of H41 V1 is strictly narrowed to:

> **Equal-entry-notional, event-conditioned directional expectancy after a fixed friction proxy, before funding and portfolio constraints.**

This endpoint explicitly **DOES NOT** represent:
- an all-cost net execution P&L;
- a capital-normalized portfolio return or Sharpe ratio;
- a funded perpetual return (funding rates and borrow financing are excluded);
- an executable strategy (no position sizing, inventory limits, slippage modeling, or order-book queue dynamics are included).

The 24 bps stress calculation is strictly diagnostic and cannot rescue or reject the primary 12 bps gate. All portfolio, funding, liquidity, and execution constraints are deferred to subsequent Playbook qualification.

# 7. Normative Event/PIT Clock and Timestamp Table (Resolving Astra H41-H01)

All chronological ambiguity (such as `event_time < or == decision boundary` or bare `C[t]`) is eliminated.

### Normative Clock and Timestamp Specification

```text
Time Axis: UTC Hourly Grid: ... T_{k-1}, T_k, T_{k+1}, T_{k+2} ...
Interval:  B_0(t) = [t - 1h, t)     | B_{entry}(t) = [t, t + 1h)     | ... | B_{exit-1} = [t + h - 1h, t + h)
Events:    Bar Finalized at t       | Decision at t; Entry Mark P_entry| ... | Horizon Ends at t + h; Exit Mark P_exit
```

| Field | Normative Rule | Description |
|---|---|---|
| **Canonical Bar Interval** | $B_k = [T_k, T_{k+1})$ where $T_{k+1} - T_k = 3600\text{s}$ | Discrete 1-hour interval, labeled by open time $T_k$. |
| **Source Event Timestamp** | $T_{\text{open}}(B_k) = T_k$ | Beginning of the hourly trading interval. |
| **Finalization / Availability** | $t_{\text{avail}}(B_k) = T_{k+1}$ | The bar is finalized and available at UTC hour boundary $T_{k+1}$. |
| **Decision Boundary** | $t = T_{k+1}$ | The exact hourly boundary where features are evaluated. |
| **Relative Bar Index** | $B_j(t) = [t - (j+1)h, t - jh)$ for $j \ge 0$ | $B_0(t)$ is the last completed bar finalized at $t$. $B_1(t)$ closed at $t-1h$. |
| **Feature Information Cutoff** | Strictly $\le t$ | Features evaluated at $t$ use only $\{B_j(t) : j \ge 0\}$. Zero forward leakage. |
| **Reference Entry Timestamp** | $t_{\text{entry}} = t$ | Execution decision occurs at $t$; reference entry is immediate at $t$. |
| **Reference Entry Price** | $P_{\text{entry}}(t) = \text{Open}(B_{\text{entry}}(t))$ | Open price of bar $B_{\text{entry}}(t) = [t, t+1h)$. Causally follows $B_0(t)$ finalization. |
| **Reference Exit Timestamp** | $t_{\text{exit}} = t + h$ | Exactly $h$ hours after reference entry. |
| **Reference Exit Price** | $P_{\text{exit}}(t) = \text{Open}(B_{t+h}) \equiv \text{Close}(B_{t+h-1})$ | The reference exit price at the $h$-hour boundary. |
| **Horizon Return** | $r_{\text{gross}}(t) = s_t \cdot \left(\frac{P_{\text{exit}}(t)}{P_{\text{entry}}(t)} - 1\right)$ | Simple fractional return on equal entry notional. |
| **Right-Boundary Censoring** | $t + h \le T_{\text{partition\_end}}$ | If $t + h > T_{\text{partition\_end}}$, the event is censored; $A[i, t] = 0$. |
| **Synchronized Eligibility** | Valid BTC bar AND valid ETH bar at $t$ | Both asset bars must be finalized and consecutive. |

# 8. Mathematical Family Formulations

## 8.1 D1 Trend Continuation Family

For asset $X \in \{\text{BTC}, \text{ETH}\}$ and window $W \in \{4, 12\}$ at decision boundary $t$:

$$\text{score}_{D1}(t) = \log\left(\frac{\text{Close}(B_0(t))}{\text{Close}(B_W(t))}\right)$$

1. **Endpoint Requirements**: Requires all bars $B_0(t), \dots, B_W(t)$ complete and consecutive.
2. **Train-Only Q80 Calculation**:
   - Let $\mathcal{S}_{\text{TRAIN}} = \{|\text{score}_{D1}(t)| : t \in \text{WF1\_TRAIN}, \text{consecutive bars valid}\}$.
   - Threshold $Q80 = \text{Quantile}_{0.80}(\mathcal{S}_{\text{TRAIN}})$ computed via linear rank interpolation (`numpy.quantile(..., method='linear')`).
   - Minimum training support: $|\mathcal{S}_{\text{TRAIN}}| \ge 500$ valid bars.
3. **Decision & Side Mapping**:
   $$\text{side}(t) = \begin{cases} 
   +1 & \text{if } |\text{score}_{D1}(t)| \ge Q80 \text{ and } \text{score}_{D1}(t) > 0 \\ 
   -1 & \text{if } |\text{score}_{D1}(t)| \ge Q80 \text{ and } \text{score}_{D1}(t) < 0 \\ 
   0 & \text{if } |\text{score}_{D1}(t)| < Q80 \text{ or } \text{score}_{D1}(t) == 0 
   \end{cases}$$
4. **Abstention**: If $\text{side}(t) == 0$, $A[i, t] = 0$ (no trade emitted).

## 8.2 D2 Breakout Continuation Family

For asset $X \in \{\text{BTC}, \text{ETH}\}$ and window $W \in \{24, 72\}$ at decision boundary $t$:
- Signal bar: $B_0(t)$ (closed at $t$).
- Reference range: $B_1(t), \dots, B_W(t)$ (exactly $W$ closed bars; $B_0(t)$ is strictly excluded).
- Upper channel: $U_W(t) = \max_{j=1}^W \text{High}(B_j(t))$
- Lower channel: $L_W(t) = \min_{j=1}^W \text{Low}(B_j(t))$

$$\text{side}(t) = \begin{cases}
+1 & \text{if } \text{Close}(B_0(t)) > U_W(t) \\
-1 & \text{if } \text{Close}(B_0(t)) < L_W(t) \\
0 & \text{otherwise} \quad (\text{equality } \text{Close} == U_W \text{ or } L_W \implies 0)
\end{cases}$$

## 8.3 D3 Failed-Move Reversal Family

For asset $X \in \{\text{BTC}, \text{ETH}\}$ and window $W \in \{24, 72\}$ at decision boundary $t$:
- Close-back bar: $B_0(t)$ (closed at $t$).
- Break bar: $B_1(t)$ (closed at $t-1h$).
- Pre-break reference range: $B_2(t), \dots, B_{W+1}(t)$ (exactly $W$ closed bars preceding the break bar).
- Upper bound: $U_W(t) = \max_{j=2}^{W+1} \text{High}(B_j(t))$
- Lower bound: $L_W(t) = \min_{j=2}^{W+1} \text{Low}(B_j(t))$

Break and immediate close-back conditions:
$$\text{UpBreak}(t) \iff \text{Close}(B_1(t)) > U_W(t)$$
$$\text{DownBreak}(t) \iff \text{Close}(B_1(t)) < L_W(t)$$
$$\text{InsideBack}(t) \iff L_W(t) < \text{Close}(B_0(t)) < U_W(t)$$

$$\text{side}(t) = \begin{cases}
-1 & \text{if } \text{UpBreak}(t) \text{ and } \text{InsideBack}(t) \quad (\text{SHORT reversal}) \\
+1 & \text{if } \text{DownBreak}(t) \text{ and } \text{InsideBack}(t) \quad (\text{LONG reversal}) \\
0 & \text{otherwise}
\end{cases}$$

Strict Adjacency: The break must occur on $B_1$ and close-back on $B_0$. Stale breaks or multi-bar searches are strictly forbidden. Equality is not inside the bounds.

## 8.4 D4 Cross-Asset Modifier Family (Resolving Astra H41-M02)

D4 candidates partition the event population of a base candidate using the synchronized 4h return sign of the other asset:

$$\text{OTHER\_RET4\_SIGN}(t) = \text{sign}\left(\log\left(\frac{\text{Close}(B_0^{\text{other}}(t))}{\text{Close}(B_4^{\text{other}}(t))}\right)\right)$$

1. **Full Parent Inheritance**: D4 RET4 candidates inherit the exact $Q80$ thresholded event population of D1 RET4.
2. **Synchronized Availability**: Requires complete valid bars for both BTC and ETH at $t$.
3. **Partitioning Rules**:
   - If $\text{parent\_side}(t) == 0$ or $\text{OTHER\_RET4\_SIGN}(t) == 0$: Emit NO EVENT.
   - $\text{CONFIRM} \iff \text{parent\_side}(t) == \text{OTHER\_RET4\_SIGN}(t)$
   - $\text{DIVERGE} \iff \text{parent\_side}(t) == -\text{OTHER\_RET4\_SIGN}(t)$
4. **Action Side**: Inherits $\text{parent\_side}(t)$ unchanged.
5. **Epistemic Restriction**: Evaluates conditional subgroup expectancy only. No claim of incremental or independent cross-asset predictive power.

# 10. Testability Architecture and Outcome-Free Screening (Resolving Astra H41-B02, H41-H03)

## 10.1 Separation of Internal Reads from Designer Visibility

To ensure true outcome-independent screening without false claims of global byte non-existence:
1. **Causally Authorized Internal Processor**: The feature processor reads finalized OHLC bars strictly sequentially up to decision time $t$ to compute the event mask $A[i, u]$.
2. **Designer-Visible Testability Receipt**: Prior to reading any future returns $P_{\text{exit}}$, the system materializes:
   $$\text{H41\_TESTABILITY\_RECEIPT\_V1}$$
   which records strictly non-outcome metrics:
   - Candidate IDs, source hashes, split range;
   - Event count: $N_i = \sum_u A[i, u]$;
   - Occupied UTC calendar days: $D_i$;
   - Non-overlapping event packing count;
   - Concentration index: $C_i = N_i^2 / \sum_b n_{i,b}^2$;
   - Synchronized availability fraction.
   - Zero returns, zero signs, zero P&L, zero rankings.

## 10.2 Basic Support Floors vs Method Adequacy

- **Provisional Basic Support Floors**:
  $$N_i \ge 60 \quad \text{AND} \quad D_i \ge 30$$
  These are necessary operational floors, not sufficient certificates of asymptotic normality or statistical power.
- **Method Adequacy**: Requires that the event series does not suffer pathological concentration ($C_i > \text{threshold}$) or excessive missingness.
- Candidates failing support or adequacy are excluded from the testable set before outcomes are computed, and their failure reason is permanently recorded.

## 10.3 Discrete Testability State Taxonomy

1. `SOURCE_UNAVAILABLE`: Input bytes or row projection missing/invalid.
2. `BASIC_SUPPORT_UNAVAILABLE`: $N_i < 60$ or $D_i < 30$.
3. `INFERENCE_ADEQUACY_UNAVAILABLE`: Fails concentration or coverage checks.
4. `TESTABLE_EXPLORATORY`: Eligible for exploratory joint inference.
5. `INFERENCE_UNAVAILABLE`: Numerical bootstrap failure or degenerate variance.
6. `EDGE_FAIL`: Evaluated, but simultaneous LCB $\le 0$.
7. `EDGE_PASS`: Evaluated, simultaneous LCB $> 0$.

# 11. Joint Inference Contract (Resolving Astra H41-H02)

The inference procedure is frozen to a single unified methodology:

$$\text{\textbf{Shared-Clock, Source-Bundle, Standardized Single-Step Joint Maximum Inference}}$$

## 11.1 Shared Time Grid and Block Resampling

1. **Unified Hourly Axis**: Let $u \in \{1, \dots, T\}$ index all canonical hours in `WF1_CALIBRATION` ($T = 2,184$ hours for 91 days).
2. **Joint Data Bundles**: For each hour $u$, store the joint vector of candidate masks $A[i, u]$ and source-anchored net returns $Y[i, u]$:
   $$Z[i, u] = A[i, u] \cdot Y[i, u]$$
3. **Shared Block Draws**: Moving blocks of length $L$ are drawn from the hourly index $\{1, \dots, T\}$. The exact same resampled block indices are applied simultaneously across all candidates and both assets.
4. **Bundle Attachment**: The outcome $Y[i, u]$ remains attached to its entry hour $u$. Horizon returns are never artificially sliced across synthetic block boundaries.

## 11.2 Mathematical Estimators and Studentization

- **Sample Ratio Estimator**:
  $$\hat{\mu}_i = \frac{\sum_{u=1}^T Z[i, u]}{\sum_{u=1}^T A[i, u]}$$
- **Replicate Ratio Estimator** (for bootstrap draw $b \in \{1, \dots, B\}$ with weights $w_b[u]$):
  $$\mu_i^{*(b)} = \frac{\sum_{u=1}^T w_b[u] Z[i, u]}{\sum_{u=1}^T w_b[u] A[i, u]}$$
- **Influence Function and Long-Run SE**:
  The empirical influence series for the ratio estimator is:
  $$\psi_i[u] = \frac{Z[i, u] - \hat{\mu}_i \cdot A[i, u]}{\frac{1}{T} \sum_{v=1}^T A[i, v]}$$
  The standard error $\widehat{SE}_i$ is estimated using the plug-in block-bootstrap variance of $\psi_i$ or consistent HAC estimator.
- **Studentized Bootstrap Statistic**:
  $$T_i^{*(b)} = \frac{\mu_i^{*(b)} - \hat{\mu}_i}{\widehat{SE}_i}$$
- **Joint Maximum Statistic**:
  $$\max T^{*(b)} = \max_{i \in \text{TESTABLE}} T_i^{*(b)}$$
- **Simultaneous Critical Value**:
  $c_{95}$ is the empirical 95th percentile of $\{\max T^{*(b)} : b = 1, \dots, B\}$ (using rank $\lceil 0.95 B \rceil$).
- **Simultaneous Lower Confidence Bound**:
  $$\text{LCB}[i] = \hat{\mu}_i - c_{95} \cdot \widehat{SE}_i$$

## 11.3 Finite-Sample Invariants
- Replicate count: $B = 10,000$.
- Zero-count replicates ($\sum w_b A = 0$): Handled by fail-closed fallback or conservative imputation; no unbudgeted redraws.
- Random Number Generation: Pinned 64-bit seed derived deterministically from campaign identity; no reseeding on failure.
- Numeric Precision: 64-bit IEEE-754 floating point throughout.

## 11.4 Block Length Validation Mandate
Block length $L$ is not guessed. Pre-freeze validation in Stage R2 will evaluate:
$$L \in \{48h, 72h, 120h\}$$
against baseline diagnostic $L = 24h$ across 12 synthetic DGP classes.

# 12. Candidate Lock Contract

Deterministic selection operates strictly on candidates in state `EDGE_PASS` ($\text{LCB}[i] > 0$):

1. **Primary Key**: Largest simultaneous $\text{LCB}[i]$ in full floating-point precision.
2. **Secondary Key**: Larger event count $N_i$ on `WF1_CALIBRATION`.
3. **Tertiary Key**: Lower candidate ID lexicographically.

Outcomes:
- If zero candidates pass: $\text{H41\_EXPLORATORY\_NO\_GO}$.
- If $\ge 1$ candidate passes: Deterministically locks $\text{H41\_EXPLORATORY\_DIRECTIONAL\_CANDIDATE\_LOCK\_V1}$.

# 13. Removal of Probability Calibration (Resolving Astra H41-M03)

Probability calibration is completely removed from H41 V1.
- No Platt scaling, isotonic regression, or Beta-Binomial models are evaluated during Candidate Lock.
- Directional edge is evaluated on equal-notional returns.
- Probability calibration for position sizing belongs to a separate, downstream policy stage with its own independent data budget.
