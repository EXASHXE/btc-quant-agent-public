# 8. Mathematical Family Formulations

## 8.1 D1 Trend Continuation Family

For asset $X \in \{\text{BTC}, \text{ETH}\}$:
- Short trend: lookback window $W = 4$, holding horizon $h = 4$.
- Long trend: lookback window $W = 12$, holding horizon $h = 24$.

$$\text{score}_{D1}(t) = \log\left(\frac{\text{Close}(B_0(t))}{\text{Close}(B_W(t))}\right)$$

1. **Endpoint Requirements**: Requires all bars $B_0(t), \dots, B_W(t)$ complete and consecutive.
2. **Train-Only Q80 Calculation**:
   - $Q80$ is computed from $\{|\text{score}_{D1}(t)|\}$ across valid bars in `WF1_TRAIN` via linear interpolation (`numpy.quantile(..., method='linear')`).
   - Minimum training support: $\ge 500$ valid bars.
   - Permanently frozen prior to evaluating `WF1_CALIBRATION`.
3. **Decision & Side Mapping**:
   $$\text{side}(t) = \begin{cases} 
   +1 & \text{if } |\text{score}_{D1}(t)| \ge Q80 \text{ and } \text{score}_{D1}(t) > 0 \\ 
   -1 & \text{if } |\text{score}_{D1}(t)| \ge Q80 \text{ and } \text{score}_{D1}(t) < 0 \\ 
   0 & \text{if } |\text{score}_{D1}(t)| < Q80 \text{ or } \text{score}_{D1}(t) == 0 
   \end{cases}$$
4. **Abstention**: If $\text{side}(t) == 0$, $A[i, t] = 0$.

## 8.2 D2 Breakout Continuation Family

For asset $X \in \{\text{BTC}, \text{ETH}\}$:
- Short breakout: reference window $W = 24$, holding horizon $h = 4$.
- Long breakout: reference window $W = 72$, holding horizon $h = 24$.

Reference range evaluates $B_1(t), \dots, B_W(t)$ ($B_0(t)$ is strictly excluded from range determination):
- $U_W(t) = \max_{j=1}^W \text{High}(B_j(t))$
- $L_W(t) = \min_{j=1}^W \text{Low}(B_j(t))$

$$\text{side}(t) = \begin{cases}
+1 & \text{if } \text{Close}(B_0(t)) > U_W(t) \\
-1 & \text{if } \text{Close}(B_0(t)) < L_W(t) \\
0 & \text{otherwise} \quad (\text{equality } \implies 0)
\end{cases}$$

## 8.3 D3 Failed-Move Reversal Family

For asset $X \in \{\text{BTC}, \text{ETH}\}$:
- Short reversal: reference window $W = 24$, holding horizon $h = 4$.
- Medium reversal: reference window $W = 72$, holding horizon $h = 8$.

Pre-break reference range evaluates $B_2(t), \dots, B_{W+1}(t)$:
- $U_W(t) = \max_{j=2}^{W+1} \text{High}(B_j(t))$
- $L_W(t) = \min_{j=2}^{W+1} \text{Low}(B_j(t))$

Breakout on $B_1$ and immediate close-back on $B_0$:
$$\text{UpBreak}(t) \iff \text{Close}(B_1(t)) > U_W(t)$$
$$\text{DownBreak}(t) \iff \text{Close}(B_1(t)) < L_W(t)$$
$$\text{InsideBack}(t) \iff L_W(t) < \text{Close}(B_0(t)) < U_W(t)$$

$$\text{side}(t) = \begin{cases}
-1 & \text{if } \text{UpBreak}(t) \text{ and } \text{InsideBack}(t) \quad (\text{SHORT reversal}) \\
+1 & \text{if } \text{DownBreak}(t) \text{ and } \text{InsideBack}(t) \quad (\text{LONG reversal}) \\
0 & \text{otherwise}
\end{cases}$$

Strict adjacency enforced; equality is not inside the bounds.

# 11. Ratified Joint Inference Contract

## 11.1 Method Specification

- **Method**: Shared-clock, source-bundle preserving, non-circular moving-block Studentized bootstrap-$t$ single-step joint maximum inference.
- **Frozen Block Length**: **$L = 120\text{ hours}$ (5 days)**.
- **Bootstrap Replicates**: $B = 10,000$.
- **Clock Alignment**: One shared random block-index sequence $\tau_1, \dots, \tau_m \stackrel{\text{iid}}{\sim} \text{Uniform}(0, S-1)$ ($S = T - L + 1$, $m = \lceil T/L \rceil$) is applied jointly across all $K=20$ candidates and both assets for each replicate.

## 11.2 Mathematical Formulation

1. **Sample Ratio Estimator**:
   $$\widehat{\mu}_i = \frac{\sum_{t=1}^T Z_{i,t}}{\sum_{t=1}^T A_{i,t}}, \quad \bar{A}_i = \frac{1}{T} \sum_{t=1}^T A_{i,t}$$
   where $Z_{i,t} = A_{i,t} \cdot Y_{i,t}$ and $Y_{i,t} = s_{i,t} \cdot (P_{\text{exit}}(t)/P_{\text{entry}}(t) - 1) - 0.0012$.

2. **Sample Standard Error (Künsch 1989)**:
   $$\widehat{SE}_i = \frac{\sqrt{\frac{1}{L \cdot S} \sum_{s=1}^S \left( Z^{(L)}_{i,s} - \widehat{\mu}_i A^{(L)}_{i,s} \right)^2}}{\bar{A}_i}$$
   where $Z^{(L)}_{i,s} = \sum_{u=0}^{L-1} Z_{i, s+u}$ and $A^{(L)}_{i,s} = \sum_{u=0}^{L-1} A_{i, s+u}$.

3. **Bootstrap Centering & Studentization**:
   For bootstrap draw $b$, block sums are resampled via shared indices:
   $$Z^*_{i,b} = \sum_{j=1}^m Z^{(L)}_{i, \tau_{b,j}}, \quad A^*_{i,b} = \sum_{j=1}^m A^{(L)}_{i, \tau_{b,j}}$$
   $$\widehat{\mu}^*_{i,b} = \frac{Z^*_{i,b}}{A^*_{i,b}}, \quad \text{center}_i = \frac{\sum_{j=1}^m Z^{(L)}_{i, \tau_{b,j}}}{\sum_{j=1}^m A^{(L)}_{i, \tau_{b,j}}}$$
   $$T^*_{i,b} = \frac{\widehat{\mu}^*_{i,b} - \text{center}_i}{\widehat{SE}^*_{i,b}}$$
   where $\widehat{SE}^*_{i,b}$ is the Künsch ratio SE computed across the resampled block sums.

4. **Joint Maximum Statistic & Simultaneous LCB**:
   $$T^*_{\max, b} = \max_{i \in \{0, \dots, K-1\}} T^*_{i,b}$$
   $$c_{95} = \text{Quantile}_{0.95}\left(\{T^*_{\max, b}\}_{b=1}^B\right)$$
   $$\text{LCB}_i = \widehat{\mu}_i - c_{95} \cdot \widehat{SE}_i$$

5. **Selection Gate**: A candidate passes exploratory selection if and only if:
   $$\text{LCB}_i > 0$$
