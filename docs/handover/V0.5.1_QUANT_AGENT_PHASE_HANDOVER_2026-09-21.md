## 7. Accepted blocker/high findings

### ASTRA-B-01 — WF expected authority can shrink with evidence

Current `H40ExpectedSplitAuthority` allows a caller-selected fold set and validation contract map.

If both expectation and evidence are shrunk together, internal consistency can pass without proving complete accepted WF authority.

Required:

```text
expected WF authority =
derived from sealed run/split + accepted validation contracts
```

not caller declaration.

### ASTRA-B-02 — terminal absorption not durable

In-memory terminal state is absorbing.

Persisted receipt files do not define one authoritative durable run head.

Competing children of one predecessor can coexist and another process can restore a stale/sibling branch.

Required:

```text
one durable authoritative head per run
atomic compare-and-advance
terminal head has no successor
caller filename is not authority
```

### ASTRA-B-03 — cached descendants outlive source truth

Cold restore verifies the runtime seal/source truth.

In-memory Candidate/WF/Confirmation descendants can be revalidated using cached prior wrappers without recursively revalidating the root seal.

Required:

- define verified capability lifetime;
- either reverify current source truth at transition use;
- or bind an independently protected immutable run-input snapshot.

Cached and cold semantics must agree.

### ASTRA-B-04 — reconcile may cross TESTNET/LIVE environment

`ExecutionService.reconcile()` selects client from current config, not persisted plan environment.

No plan-mode/environment/account agreement is required before signed query/write.

Potential writes include:

- cancel order;
- STOP;
- TAKE_PROFIT;
- reduce-only failsafe MARKET.

This is not H40 science but is a repository-wide execution safety blocker.

### ASTRA-H-01 — receipt publication not crash atomic

Current store creates the final immutable path before writing all bytes.

Crash/failure can leave an empty or partial write-once artifact.

Repair must coordinate:

```text
receipt atomic publication
+
durable run-head transaction/recovery
```
