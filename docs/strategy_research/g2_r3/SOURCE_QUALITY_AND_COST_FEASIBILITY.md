## Decidable source contract proposed for separate dispatch

Allowlist exact BTCUSDT/ETHUSDT/SOLUSDT USDT-M PERPETUAL only. Do not query all-symbol endpoints unless a separately reviewed admission wrapper can avoid protected bodies; prefer explicit-symbol public reads. Never read RC2 sealed ZEC/HYPE/ORCA/PUMP/NMR/BR/RLC/QNT partitions, protected H40/H41/A-line outcomes or unknown caches. Public availability never removes exposure protection. No signed/private account, provider smoke, TESTNET or execution endpoint.

For each admitted source persist URL, publisher/version, archive/raw SHA256 and official checksum when offered, retrieval UTC, published clock, symbol/product, exclusive bar ends, source event time and missing/duplicate coverage. Require100% warm-up/signal trade-price coverage and complete active1m trade-price and minute mark paths; no synthetic filler, hidden forward-fill or dropped losing gaps. Missing any active trade-price or minute-MTM mark path hard-stops economic computation; absence of settlement-associated funding mark mapping alone permits only the explicitly frozen adverse funding proxy using validated minute mark highs; known unusable coverage is reported, not repaired with another window. Authentic historical filter/settlement histories may be unavailable: disclose proxy grade and prohibit stronger claims. Cache only in new task-specific /tmp, never publish raw archives.

Funding contract audit must specify: preserved archive calculation timestamp; settlement event identity from public rate history; publication/receipt availability unknown versus actually captured; observed/effective interval and cap; mark notional; position ownership around the documented settlement deviation. Missing mapping cannot be solved by treating all eight-hour records as exact settlements. Proposed conservative overlap rule uses an inclusive +/-15s settlement window: any possible exposure receives adverse charge, benefit only when ownership and actual rate are unambiguous. Rate-cap shocks need a separate full advertised-cap sensitivity, not an assertion that8bp bounds all funding. A strategy positive only with funding benefits is rejected from shortlist.

Availability fields: historical bars event_open, inclusive event_close, exclusive_end, reconstructed_available=end+60s; actual present receipt distinct. Decision=end+60s, entry=end+120s. For future receipts, require authenticated collection timestamp, monotonic clock/UTC checks, available_at=max(event closure, receipt)+frozen processing lag and next feasible minute fill. Indicator lineage contains only completed earlier available bars; missing late features are ineligible, not backdated. A separately dispatched method audit must challenge1m/1h/4h alignment, shift-by-one, gap stop, same-minute SL/TP, funding sign/window, tick rounding, equity ceilings, double charging and overlapping controls using hermetic tests. No such implementation or tests run in this design.

Proposed gate outcomes: verified historical semantics -> archival development reconstruction; incomplete cost/funding/filter proof -> proxy diagnostic only; unknown source identity/permission or causal time -> SOURCE_OR_METHOD_BLOCKED. Receipt-proven features still do not prove executable live fills or policy quality. No present feasibility gate is certified by this design.
