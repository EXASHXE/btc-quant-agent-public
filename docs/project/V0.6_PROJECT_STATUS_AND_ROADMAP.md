Run finite 27-cell Exit-aware R3 as development only, report ALL cells/negative results, freeze prior to score; if no support, stop, do not fish reserved 2024–2025 months.

Correct 2026 Binance /public and /market routing and explicit user-authorized Clash route remain necessary; no TLS disabling or provider restriction evasion.
4. **CI scalability:** scripts/ci/test_plan.py line 191–193 currently upgrades unmapped executable file changes to full; risk-map NORMAL task must preserve unknown-change fail-closed and historical weekly/manual all-tests. Do not delete or bypass H40/H41 scientific tests under a refactor pretext.
