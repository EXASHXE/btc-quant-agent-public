### C01 — Shadow denominator and immutable planned-slot roster

- **Pre-fix:** `e2e/shadow.py::denominator` inferred `scheduled_slots` from observed rows, masking a missing scheduled symbol; two BTC/ETH observations in a three-symbol schedule incorrectly yielded 2/2 and no missing slot.
- **Fix:** `e2e/shadow.py` and `win_capture/e1_five_tf_bridge.py` persist immutable `SCAN_SLOT_SCHEDULED` records keyed by `(cycle_id,symbol)` **before** per-symbol processing; denominator derives `scheduled_slots` independently, tracks `missing_or_unknown`, rejects out-of-roster/contradictory events, and preserves M1 legacy five-key shape.
- **Required independent challenge:** scheduled BTC/ETH/SOL with only BTC/ETH classified ⇒ scheduled=3, screened=2, missing=1, without inferring NO_SETUP for the absent SOL.

### C02 — Stable scan cycle identity

- **Pre-fix:** default `cycle_id` included processing `now_ms`, so replaying one immutable 3-symbol cycle 100ms later created six unique Shadow keys.
- **Fix:** `derive_scan_cycle_identity()` derives from a **closed 15m bar end boundary**, `source_epoch`, `source_generation`, `profile_id` and the canonical three-symbol roster. Empty/all-None, missing 15m boundary and intra-batch generation/profile/bar mismatch fail closed before Producer/Shadow.
- **Required independent challenge:** same frame evidence replayed with different processing time must be idempotent; contradictory frame replays on the same cycle must not silently overwrite observations.

### C03 — Producer-only authoritative Outbox transition

- **Pre-fix:** `q0f_adapter/scheduler.py::BoundedOfflineScheduler._expire_unrefreshable_queued` directly issued `UPDATE outbox` and `store.audit` despite Q0BC Producer being the single authoritative writer.
- **Fix:** `q0bc_v2/producer.py::Producer.expire_unattempted_outbox(outbox_id, reason_code="EVENT_TTL_EXPIRED")` now owns the transaction, owner-generation/state/deadline checks, eligible synchronized transition, idempotent audit and crash rollback. Scheduler delegates through this API and no longer writes Outbox SQL directly.
- **Required independent challenge:** reject `ATTEMPTED`, `PROVIDER_ACCEPTED`, `UNKNOWN_DELIVERY`, unrelated `FAILED`, wrong generation and attempts to expire before eligible TTL; no blind retry or double audit after restart.
