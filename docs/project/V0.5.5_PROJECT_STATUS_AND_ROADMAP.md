To reduce unnecessary serial delay while respecting the frozen holdout, **separate a runnable product preview from a policy-quality trading release**:

This is for configuration, runtime/Feishu integration, restart/recovery and operational debugging. Mark the current policy UNVALIDATED and prevent unapproved exchange writes. A preview is not RC2 PASS and not real-money authority.
- **Tactical-qualified Release:** protected holdout yields valid PASS, integrated code passes independent exact-SHA semantics and explicit Controller gate, followed by authorized TESTNET and qualified external smoke. A valid FAIL requires a new prospective policy, not a threshold relaxation.
- **Pre-live:** only a distinct safety/capability implementation and audit can authorize small manually approved real-funds canary; never inherit trading authority from a preview, code version or TESTNET.

Pre-PASS parallel work allowed: integration checklist, API/service mock wiring, deployment and env/runbook correctness, evidence exports, telemetry, non-protected deterministic regression and code-base migration. Forbidden: claiming policy edge, resolving new protected outcomes, bypassing approval or enabling LIVE.

## 6. Output and collaboration protocol

For **substantive** project responses:

**当前阶段性进展**
- A-line: √ / → / ○ (one relevant line).
- B-line: √ accepted capability → current gate ○ next gate.
- Performance/parallel: current issue or “无关键变化”.
- 本轮变化; Blocker; Key SHA (only decision-relevant); 下一步 (action + owner).

Then only what is needed:
1. **Verdict** — accepted/held/failed/planned, distinguish observation from authority.
2. **Evidence** — exact repository link(s), minimal machine proof/test result.
3. **Decision effect** — can/cannot proceed to protected result, RC, TESTNET or live.
4. **Action** — direct safe Controller work if available; otherwise one specific linked, frozen dispatch.

No long repeated historical repair chains, no gratuitous docs-only SHAs, no “验了 HEAD 因此进展完成”. Detailed forensic logs/fixtures stay in repository, no secrets. B-line priority goes to accurate strategy quality + runnable TESTNET + safe launch, not authority paperwork.
