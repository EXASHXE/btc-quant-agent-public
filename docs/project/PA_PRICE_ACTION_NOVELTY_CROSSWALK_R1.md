## 1. Executive Summary & Terminal Verdict

### Terminal Verdict: `PA_MECHANISMS_HISTORICALLY_OVERLAPPED`

This analytical crosswalk evaluates the technical architecture, mathematical formulations, heuristic rules, and prompt engineering corpus of the external repository `AipcCode/pa` at commit `41d096b87e1e4dd20e2f2d4642f0453fe73e5a88` against the historical B-line and v0.3.12 quantitative research corpus in `EXASHXE/btc-quant-agent-public`.

### Key Independent Findings

1. **Complete Absence of Algorithmic Pattern Extraction:** In `AipcCode/pa`, the core Python module `pa_agent/ai/decision_tree.py` (blob `0bc93e448d5cca4379957fd213ee21b0e7a2b2af`) contains **zero** algorithmic, mathematical, or deterministic price-action pattern recognition code. It acts strictly as an external schema validator and DAG ordering verifier for unstructured JSON generated by an external Large Language Model (`deepseek-v4-pro`).
2. **Restricted Closed-Bar Feature Basis:** The data pipeline in `pa_agent/data/snapshot.py` (blob `82a269e1cdc8dd9b6de5fd4ff177264250f4f459`) and `pa_agent/ai/prompt_assembler.py` (blob `82f95657b28709c770492dda7dc50d8776a23fbc`) formats only closed-bar OHLCV, standard `EMA20`, and `ATR14` into an ASCII text table. The system utilizes **no** order book depth (L2/L3), **no** taker buy/sell flow delta, **no** Spot/Perp basis, **no** funding rates, and **no** Point-In-Time (PIT) Open Interest (OI).
3. **100% Historical Mechanism Overlap:** All 11 evaluated Price Action (PA) mechanisms—Tight Channels, Broad Channels, Micro Channels, High1/High2, Low1/Low2, Wedges, Three Pushes, Spike/Climax, Failed Continuation, Trading Range Boundaries, and Barbwire—map directly onto previously implemented, backtested, and rejected B-line strategy families:
   - **Tactical R2:** `TREND_PULLBACK_LONG/SHORT_4H/12H` (all negative net-R under 22 bp BASE / 44 bp STRESS).
   - **v0.3.3 Geometry Excursion Audit:** Pullback depth, entry lag after reclaim (High1/High2), swing invalidation gaps, and excursion caps.
   - **Gemini Goal-A & Goal-B:** 48 prospective candidate arms across 35 months (2021–2023), including failed-breakout reclaims (`W2_C01`), range boundary fades (`W1_C02`), volume climax fades (`W2_C04`), and liquidity sweeps (`W4_C05`). All 48 failed the 44 bp STRESS promotion gate.
   - **Codex R1–R3:** 12 April candidates, 12-fold flow/regime development, and 27 entry $\times$ exit $\times$ cap cells (100% STRESS NO_GO).
   - **Reset R1:** Price Shock and Fakeout mechanisms formally retired as historical duplicates.
4. **PA-A Negative Result (Trajectory DPI Proof):** Deterministic closed-bar channel-state transitions contribute **zero orthogonal predictive information** beyond continuous ATR, EMA slope, Momentum, and Kaufman Efficiency Ratio (ER). By the generalized Data Processing Inequality on trajectory spaces, discretizing continuous price-geometry indicators into categorical labels strictly discards mutual information ($I(S_{t}; Y_{t:t+h}) \le I(\mathbf{X}_{[t-k, t]}; Y_{t:t+h})$) with conditional mutual information $I(\mathcal{T}_t; Y_{t:t+h} \mid \mathbf{X}_{[t-k, t]}) \equiv 0$.
5. **PA-B Negative Result (Common Parent Episode Population):** Predeclared second-entry policies (High2/Low2, breakout retest) do not constitute an independent predictive source. When evaluated across the **identical parent economic episode population** $\mathcal{E}$, second-entry policies suffer from severe right-tail censoring (systematically missing the largest trend runs), adverse selection into choppy consolidations, capital/waiting drag, and execution nonfill asymmetry.
6. **Subjective Floor-Trader Probabilities Unvalidated:** All numerical probability claims in `AipcCode/pa` (e.g., "80% range breakout failure", "55–60% second entry win rate", "60/40 rule") are textbook discretionary heuristics from floor trading lore. None are calibrated or validated for BTCUSDT perpetual futures under 4h–24h holding horizons and 22–44 bp roundtrip transaction friction.

### 2.2 Execution Architecture: What the Code Actually Executes

The system in `AipcCode/pa` does not implement an algorithmic trading engine. Its data and execution pipeline operates entirely via prompt construction and LLM inference:

```
[Raw K-lines]
      │
      ▼
┌───────────────────────────────┐
│ pa_agent/data/snapshot.py     │
│ Computes: EMA20, ATR14        │
└──────────────┬────────────────┘
               │
               ▼
┌───────────────────────────────┐
│ pa_agent/ai/prompt_assembler.py│
│ Formats ASCII Table:          │
│ seq | dt | O | H | L | C | V  │
│   | EMA20 | ATR14             │
└──────────────┬────────────────┘
               │
               ▼
┌───────────────────────────────┐
│ Stage 1: Market Diagnosis     │
│ Dispatches to DeepSeek LLM    │
│ Returns cycle_position JSON   │
└──────────────┬────────────────┘
               │
               ▼
┌───────────────────────────────┐
│ pa_agent/ai/router.py         │
│ Selects text files from       │
│ prompt_engineering/           │
└──────────────┬────────────────┘
               │
               ▼
┌───────────────────────────────┐
│ Stage 2: Trade Decision       │
│ Dispatches to DeepSeek LLM    │
│ Returns order trace JSON      │
└──────────────┬────────────────┘
               │
               ▼
┌───────────────────────────────┐
│ pa_agent/ai/decision_tree.py  │
│ Schema & DAG order validation │
│ (NO math / pattern code)      │
└───────────────────────────────┘
```

1. **Indicator Extraction:** `pa_agent/data/snapshot.py` takes raw K-lines from TradingView or MT5, extracts the latest $N$ closed bars, and calls `compute_indicators()`, which computes:
   - `EMA20`: 20-period Exponential Moving Average on closed prices.
   - `ATR14`: 14-period Average True Range on High, Low, Close.
2. **Text Serialization:** `pa_agent/ai/prompt_assembler.py` formats the $N$ closed bars into a text table containing exactly 9 columns: `序号 | 时间 | 开盘价 | 最高价 | 最低价 | 收盘价 | 成交量 | EMA20 | ATR14`.
3. **LLM Delegation:** The table is appended to prompt instructions containing `二元决策.txt` and routed strategy texts. The prompt is dispatched via HTTP to DeepSeek (`deepseek-v4-pro`).
4. **Validation Only:** `pa_agent/ai/decision_tree.py` inspects the returned JSON. Its functions (`validate_gate_result_consistency`, `validate_stage2_trace_consistency`) enforce string enumerations (`order_type` in `["不下单", "限价单", "突破单", "市价单"]`), check that `node_id` strings follow an ascending order (§3 $\to$ §11), and verify that if an order is placed, node `10.3` ("交易者方程") has `answer == "是"`.
5. **Absence of Quantitative Program Logic:** The codebase provides zero programmatic definitions for swings, channel boundaries, trendlines, wedges, or pullbacks. All pattern recognition is purely prompt-based subjective LLM inference.

## 4. Evaluation of PA-A: Deterministic Closed-Bar Channel-State Transitions

### 4.1 Proposition Definition

**PA-A Hypothesis:** Can deterministic closed-bar channel-state transitions (e.g., discrete transitions across the graph: `Spike` $\to$ `Tight Channel` $\to$ `Normal Channel` $\to$ `Broad Channel` $\to$ `Trading Range` $\to$ `Barbwire`) generate orthogonal predictive information beyond the standard continuous basis of ATR, EMA slope, Momentum, Kaufman Efficiency Ratio (ER), and existing regime features?

### 4.2 Continuous Feature Space Representation

Let $\mathbf{Z}_{[t-k, t]} = \{O_u, H_u, L_u, C_u, V_u\}_{u=t-k}^t$ denote the raw closed-bar OHLCV trajectory over a lookback window of length $k$.
From $\mathbf{Z}_{[t-k, t]}$, the continuous feature vector $\mathbf{X}_t \in \mathbb{R}^d$ is causally extracted:
$$\mathbf{X}_t = \left[ \frac{\Delta \text{EMA}_{20,t}}{\text{ATR}_{14,t}}, \quad \frac{\text{Close}_t - \text{Close}_{t-k}}{\text{ATR}_{14,t}}, \quad \frac{\text{ATR}_{14,t}}{\overline{\text{ATR}}_{50,t}}, \quad \text{ER}_{k,t}, \quad \frac{|\text{Close}_t - \text{EMA}_{20,t}|}{\text{ATR}_{14,t}}, \quad \text{OverlapFrac}_{k,t} \right]$$
where Kaufman Efficiency Ratio is:
$$\text{ER}_{k,t} = \frac{|\text{Close}_t - \text{Close}_{t-k}|}{\sum_{i=0}^{k-1} |\text{Close}_{t-i} - \text{Close}_{t-i-1}|} \in [0, 1]$$
and $\text{OverlapFrac}_{k,t}$ measures the proportion of shared bar range across consecutive bars:
$$\text{OverlapFrac}_{k,t} = \frac{1}{k-1}\sum_{i=0}^{k-2} \frac{\max(0, \min(H_{t-i}, H_{t-i-1}) - \max(L_{t-i}, L_{t-i-1}))}{\max(H_{t-i}, H_{t-i-1}) - \min(L_{t-i}, L_{t-i-1})}$$

The discrete channel states defined in `AipcCode/pa` (`prompt_engineering/文件13-窄通道与宽通道策略.txt` and `二元决策.txt` §3–§6) map deterministically to partitions of $\mathbf{X}_t$:
1. **Spike ($\mathcal{S}_1$):** Large directional impulse with minimal wicks:
   $$\mathcal{S}_1 \iff \left( \frac{|\text{Close}_t - \text{Close}_{t-k}|}{\text{ATR}_t} > \theta_{\text{impulse}} \right) \land \left( \text{ER}_{k,t} > 0.85 \right) \land \left( \frac{\text{ATR}_t}{\overline{\text{ATR}}_t} > 1.5 \right)$$
2. **Tight / Micro Channel ($\mathcal{S}_2$):** High slope, low pullback, low overlap:
   $$\mathcal{S}_2 \iff \left( \left|\frac{\Delta \text{EMA}_{20}}{\text{ATR}}\right| > \theta_{\text{slope}} \right) \land \left( \text{ER}_{k,t} \in [0.65, 0.85] \right) \land \left( \text{OverlapFrac}_{k,t} < 0.30 \right)$$
3. **Broad Channel ($\mathcal{S}_3$):** Moderate slope, deep pullbacks, substantial bar overlap:
   $$\mathcal{S}_3 \iff \left( 0 < \left|\frac{\Delta \text{EMA}_{20}}{\text{ATR}}\right| \le \theta_{\text{slope}} \right) \land \left( \text{ER}_{k,t} \in [0.35, 0.65] \right) \land \left( \text{OverlapFrac}_{k,t} \ge 0.30 \right)$$
4. **Trading Range ($\mathcal{S}_4$):** Zero slope, boundary rejections, two-way crossing:
   $$\mathcal{S}_4 \iff \left( \left|\frac{\Delta \text{EMA}_{20}}{\text{ATR}}\right| \approx 0 \right) \land \left( \text{ER}_{k,t} \in [0.20, 0.35] \right) \land \left( \text{EMA Crossings}_k \ge 3 \right)$$
5. **Barbwire ($\mathcal{S}_5$):** Severe compression, maximum overlap:
   $$\mathcal{S}_5 \iff \left( \text{ER}_{k,t} < 0.20 \right) \land \left( \text{OverlapFrac}_{k,t} > 0.70 \right) \land \left( \frac{\text{Range}_k}{\text{ATR}_t} < 0.50 \right)$$

### 4.3 Trajectory Data Processing Inequality (DPI) Proof

Let $Y_{t:t+h} = \{R_{t+1}, R_{t+2}, \dots, R_{t+h}\}$ denote the forward return path over the evaluation horizon $h \in [4\text{h}, 24\text{h}]$.
Let $\mathbf{X}_{[t-k, t]} = f(\mathbf{Z}_{[t-k, t]})$ be the continuous feature trajectory, and let $\mathcal{T}_t = (S_{t-m}, \dots, S_{t-1}, S_t) = g(\mathbf{X}_{[t-k, t]})$ denote the discrete channel state sequence or transition graph path.

#### Theorem (Information Bound on Deterministic Channel Transitions)
Under any joint distribution $\mathbb{P}(\mathbf{Z}_{[t-k, t]}, Y_{t:t+h})$, the discrete state transition sequence $\mathcal{T}_t$ satisfies:
1. $I(\mathcal{T}_t; Y_{t:t+h}) \le I(\mathbf{X}_{[t-k, t]}; Y_{t:t+h}) \le I(\mathbf{Z}_{[t-k, t]}; Y_{t:t+h})$
2. $I(\mathcal{T}_t; Y_{t:t+h} \mid \mathbf{X}_{[t-k, t]}) \equiv 0$

#### Proof
Consider the sequence of representations as a Markov chain. Since $\mathbf{X}_{[t-k, t]} = f(\mathbf{Z}_{[t-k, t]})$ is a deterministic function of the raw closed bars, and $\mathcal{T}_t = g(\mathbf{X}_{[t-k, t]})$ is a deterministic quantization and partition function of the continuous feature trajectory:
$$\mathbf{Z}_{[t-k, t]} \longrightarrow \mathbf{X}_{[t-k, t]} \longrightarrow \mathcal{T}_t \longrightarrow \widehat{Y}_{t:t+h}$$
Conditioned on $\mathbf{X}_{[t-k, t]}$, the discrete state sequence $\mathcal{T}_t$ is conditionally independent of future returns $Y_{t:t+h}$:
$$\mathbb{P}(Y_{t:t+h} \mid \mathbf{X}_{[t-k, t]}, \mathcal{T}_t) = \mathbb{P}(Y_{t:t+h} \mid \mathbf{X}_{[t-k, t]})$$
By the definition of conditional mutual information:
$$I(\mathcal{T}_t; Y_{t:t+h} \mid \mathbf{X}_{[t-k, t]}) = H(\mathcal{T}_t \mid \mathbf{X}_{[t-k, t]}) - H(\mathcal{T}_t \mid \mathbf{X}_{[t-k, t]}, Y_{t:t+h})$$
Because $\mathcal{T}_t$ is a deterministic function of $\mathbf{X}_{[t-k, t]}$, its conditional entropy $H(\mathcal{T}_t \mid \mathbf{X}_{[t-k, t]}) = 0$. Since entropy is non-negative, $H(\mathcal{T}_t \mid \mathbf{X}_{[t-k, t]}, Y_{t:t+h}) = 0$ as well. Thus:
$$I(\mathcal{T}_t; Y_{t:t+h} \mid \mathbf{X}_{[t-k, t]}) \equiv 0$$
Applying the chain rule for mutual information:
$$I(\mathbf{X}_{[t-k, t]}, \mathcal{T}_t; Y_{t:t+h}) = I(\mathbf{X}_{[t-k, t]}; Y_{t:t+h}) + I(\mathcal{T}_t; Y_{t:t+h} \mid \mathbf{X}_{[t-k, t]}) = I(\mathbf{X}_{[t-k, t]}; Y_{t:t+h})$$
And symmetrically:
$$I(\mathbf{X}_{[t-k, t]}, \mathcal{T}_t; Y_{t:t+h}) = I(\mathcal{T}_t; Y_{t:t+h}) + I(\mathbf{X}_{[t-k, t]}; Y_{t:t+h} \mid \mathcal{T}_t) \ge I(\mathcal{T}_t; Y_{t:t+h})$$
Therefore:
$$I(\mathcal{T}_t; Y_{t:t+h}) \le I(\mathbf{X}_{[t-k, t]}; Y_{t:t+h})$$
$\blacksquare$

### 4.4 Information Destruction via Discretization

Quantization of continuous features into categorical bins strictly discards metric information:
$$I(\mathbf{X}_t; Y_{t:t+h}) - I(S_t; Y_{t:t+h}) = H(\mathbf{X}_t \mid S_t) - H(\mathbf{X}_t \mid S_t, Y_{t:t+h}) \ge 0$$
This loss is zero if and only if future returns are piecewise constant over the partition cells of $\mathbb{R}^d$ (i.e., if the market exhibits perfect, discontinuous step-function regimes aligned with Brooks' thresholds).

In the B-line empirical record:
- **Codex R2 Flow/Regime Campaign (`3df7a9a490a0`):** Tested 6 discrete and continuous regime mechanisms across 12 folds (1,045,440 minutes). All 6 failed to achieve stable positive expectancy (`DEVELOPMENT_NO_GO`, promotions 0/6).
- **Gemini Goal-A & Goal-B (`a37721ea`, `b51a0019`):** 48 candidate configurations conditioned on trend, range, and volatility states all failed to clear the 44 bp stress fee hurdle.

**Conclusion on PA-A:** Deterministic closed-bar channel-state transitions contribute **strictly zero incremental predictive information** beyond the continuous feature trajectory $\mathbf{X}_{[t-k, t]}$. Discretizing price geometry into Al Brooks' categorical labels represents a cosmetic reparameterization of already-falsified continuous signals.

## 5. Evaluation of PA-B: First Eligible Entry vs Predeclared Second-Entry Policy

### 5.1 Common Parent Economic Episode Population Formalization

To prevent selection bias, survival filtering, and ex-post cherry picking, both entry policies must be evaluated across the **identical parent economic episode population** $\mathcal{E}$.

#### Probability Space and Filtration
Let $(\Omega, \mathcal{F}, (\mathcal{F}_t)_{t \ge 0}, \mathbb{P})$ be a filtered probability space generated by the market price and volume process.
- **Parent Alert Event ($\mathcal{E}_i$):** Defined at $\mathcal{F}$-stopping time $\tau_0(e_i)$ whenever an initial structural setup condition is satisfied on closed bars (e.g., price reaches a 72-hour range boundary, or completes an impulse excursion $\ge 2.0\text{ ATR}$, or touches the $\text{EMA}_{20}$ in a trend).
- **Episode Duration Window:** Each episode $e_i$ is tracked over a bounded horizon $[\tau_0(e_i), \tau_0(e_i) + H_{\max}]$ where $H_{\max} = 24\text{ hours}$.
- **Arm E1 (First Eligible Entry Policy $\pi_1$):**
  Executes immediately at stopping time $\tau_1(e_i) \ge \tau_0(e_i)$ upon the close of the first qualifying signal bar (e.g., High1, Low1, initial breakout close).
- **Arm E2 (Predeclared Second-Entry Policy $\pi_2$):**
  Mandates `NO_ACTION` at $\tau_1(e_i)$. Arm E2 enters only if a secondary confirmation/retest occurs at stopping time $\tau_2(e_i) \in (\tau_1(e_i), \tau_1(e_i) + K_{\max}]$ (e.g., High2, Low2, breakout retest). If no secondary pattern forms before invalidation or timeout $K_{\max}$, Arm E2 records a terminal `NO_ACTION` for episode $e_i$.

### 5.2 Mathematical Expected Return Operator Across $\mathcal{E}$

In naive technical analysis literature (`prompt_engineering/文件15-二次入场机会.txt`), Arm E2's win rate is evaluated conditionally only on the subset of episodes where a trade actually executed:
$$\mathbb{P}(\text{Win} \mid \text{Executed in E2}) = \frac{\sum_{i \in \mathcal{E}} \mathbf{1}_{\{\text{Trade}_i \land \text{Win}_i\}}}{\sum_{i \in \mathcal{E}} \mathbf{1}_{\{\text{Trade}_i\}}}$$
This calculation discards the unexecuted episodes, introducing severe survival conditioning.

The true unconditional economic return operator for policy $\pi$ across the complete parent population $\mathcal{E}$ is:
$$\mathbb{E}_{\mathcal{E}}[R(\pi)] = \frac{1}{|\mathcal{E}|} \sum_{i \in \mathcal{E}} R(\pi, e_i)$$

Decomposing both arms under realistic market friction:

$$\mathbb{E}_{\mathcal{E}}[R(\pi_1)] = \mathbb{P}(\text{Enter}_1) \left[ \mathbb{E}[R \mid \text{Enter}_1] - C_{\text{exec}} \right]$$

$$\mathbb{E}_{\mathcal{E}}[R(\pi_2)] = \mathbb{P}(\tau_2 \le K_{\max}) \left[ \mathbb{E}[R \mid \tau_2 \le K_{\max}] - C_{\text{exec}} \right] + \mathbb{P}(\tau_2 > K_{\max}) \cdot 0 - C_{\text{wait}} - C_{\text{funding}}$$

where:
- $C_{\text{exec}} \in [22\text{ bp}, 44\text{ bp}]$ is roundtrip execution friction (fee + spread + slippage).
- $C_{\text{wait}}$ is the capital opportunity cost of holding margin / pending order state.
- $C_{\text{funding}} = \sum_{k} \text{FundingRate}_k \cdot \mathbf{1}_{\{\tau_{\text{open}} \le t_k \le \tau_{\text{close}}\}}$ is the settled funding paid across 8-hour boundaries.

### 5.3 The Four Structural Penalties of Arm E2

#### 1. Right-Tail Censoring (The Missed-Trend Penalty)
Cryptocurrency return distributions are notoriously fat-tailed (leptokurtic). In Bitcoin, portfolio expectancy is heavily driven by the top 10–15% of outlier trends.
- In explosive trend episodes (Spike and Micro Channel regimes), price surges unidirectionally without producing a two-legged pullback ($P(\tau_2 \le K_{\max} \mid \text{Runaway Trend}) \approx 0$).
- Arm E1 enters at $\tau_1$ and captures the entire $+3.5\text{R}$ to $+5.0\text{R}$ run.
- Arm E2 remains flat awaiting a High2/Low2 that never materializes, recording return $= 0.0\text{R}$.
- Censoring the right tail severely suppresses $\mathbb{E}_{\mathcal{E}}[R(\pi_2)]$.

#### 2. Adverse Regime Selection
A secondary entry *requires* price to stall, reverse, and retest. Consequently:
$$\mathbb{P}(\text{Choppy Range} \mid \tau_2 \le K_{\max}) \gg \mathbb{P}(\text{Choppy Range} \mid \tau_1)$$
The episodes that successfully trigger Arm E2 are heavily pre-selected for decaying momentum, indecision, and mean-reverting environments. Arm E2 concentrates its trade allocation precisely in regimes where transaction friction (44 bp) dominates small expected price excursions.

#### 3. Execution Nonfill Asymmetry (Adverse Selection on Limit Retests)
In PA doctrine, second entries are frequently executed via limit orders at retest boundaries:
- **Favorable Retests (Winners):** If the breakout was genuine, aggressive buyers front-run the level; price bounces before touching the limit order $\to$ **Nonfill on winners**.
- **Toxic Retests (Losers):** If the breakout was false, institutional sell programs crash through the level; the limit order is filled with 100% probability at maximum adverse velocity $\to$ **100% fill on losers**.

#### 4. Historical Proof from B-Line Research
The second-entry policy was explicitly evaluated in the B-line corpus under identical parent populations:
- **Gemini Goal-B `W2_C01_WIDE_72H_FAILED_BREAKOUT_RECLAIM_12H` (`b51a0019`):** This strategy implemented the exact second-entry retest concept across 35 months (2021–2023, 167 executed trades). Despite achieving $+10.97\text{ bp}$ gross before fees, its performance under STRESS 44 bp was **$-33.10\text{ bp}$ mean net return** and **Profit Factor 0.62**.
- **v0.3.3 Entry Lag Audit (`32be2cf3ca4e` §8):** Proved that by the time secondary confirmation fires (`close > EMA7` and `close > prior.high`), price has already recovered **1.69 ATR** from the local extreme, leaving only **0.85 ATR** structural reward to the prior swing pivot against a required reward of 6.34 ATR for net RR 1.8.
- **Codex R3 Exit-Aware Campaign (`a69ccfdf`):** Tested Entry B (reacceptance) and Entry C (retest sweep) across 27 parameter cells. All 27 STRESS configurations failed to produce positive net returns.

**Conclusion on PA-B:** Predeclared second-entry is a **policy timing filter**, not an independent predictive source. When evaluated across the complete parent episode population $\mathcal{E}$, its nominal win-rate increase on completed trades is entirely eliminated by right-tail censoring, adverse regime selection, execution nonfills, and transaction friction.
