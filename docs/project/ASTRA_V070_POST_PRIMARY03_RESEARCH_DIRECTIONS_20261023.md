## 3. What Astra should investigate

The central question is:

**Is there any genuinely differentiated, source-feasible BTCUSDT 4–24h mechanism that can produce sufficient pre-outcome support and positive absolute after-cost value without relying on the same price/flow filters already tested?**

Astra should review literature, existing code/specifications and frozen research reports. It must distinguish public-paper findings from project-specific evidence and inference. It must not access new historical market-value payloads, fit a model, compute returns, register an experiment or consume a PRIMARY slot.

### Candidate families to assess, not to assume

1. **Untried price/volatility mechanism with an explicit economic interpretation.** The compression-conditioned expanding breakout B is already a proposed design, not a newly discovered family. Astra must compare it against existing expansion, breakout/retest, X_KER and failed-escape specifications. If it is mostly another thresholded momentum/volatility filter, reject it as insufficiently differentiated rather than automatically dispatching it.
2. **A mechanism requiring an independent observable.** Examples may include spot-perpetual basis/carry, cross-market lead-lag, or a truly causal derivatives-position/flow state. These are not currently authorized simply because they appear in prior reports. For each, state the exact source, instrument, native units, timestamp semantics, source rights, coverage requirement and the minimum new scope needed. If no admissible receiver-clock or source witness exists, stop at feasibility.
3. **A new low-capacity conditional-return model only if its information set is genuinely different.** Do not repackage PRIMARY-03 with a lower action threshold, more frequent origins, more features or a different model family. Any new model must state the independent economic hypothesis and why the new input/decision process can create value rather than only change turnover.

The list above is a challenge space, not a ranked execution queue. Astra must be free to reject all three.

- Whether the candidate stays within single-leg BTCUSDT 4–24h or requires an explicit scope expansion.

If these details cannot be made precise without new data access, return SOURCE_FEASIBILITY_REQUIRED or NO_NEW_STRATEGY.

## 5. ML/DL recommendation

Do not start with Transformer, TCN/GRU, offline RL, automated factor mining or a GBDT leaderboard.

A model family is not an economic mechanism. PRIMARY-03's result does not establish that Ridge is universally inadequate; it establishes that this particular frozen M0/M1 policy had too little active support to test its economic hypothesis.

Use this order only if a new mechanism survives the research review:

1. Freeze a low-capacity causal baseline and the economic target.
2. Prove sufficient support and complete common-denominator outcomes.
3. Require positive absolute after-cost value and incremental value versus the fixed control.
4. Only then ask whether a bounded nonlinear model addresses a named residual failure.
5. Require chronological evaluation and source/label completeness before considering deep sequence models.
6. Consider RL only with credible fill counterfactuals and a common-capital simulator.

Minute rows are not independent samples. A model trained on 2021 and assessed on exposed 2022–2023 is not clean out-of-sample validation.
