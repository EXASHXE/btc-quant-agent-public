## 3. Three capacity tiers; sample protocol and conservative storage arithmetic

- **Tier A CORE:** 1m bars (higher bars derived with causal end-of-period), Mark, Index, Premium, Funding and lawfully available OI/derivative metrics.
- **Tier B TRADES:** genuine archival trades/aggTrades separately identified. Never duplicate raw full Trades and derived aggTrades without a named use case.
- **Tier C L2:** historical continuous depth only where an actual official/rights-qualified archive exists and completeness is established. Future as-received L2 capture is a separate potential stage.
- Owner-reported ~724 GiB free is a **provisional** reserve, not 724 GiB approved to consume. Default planning safety free-space floor: retain >=25% of verified local filesystem capacity and >=100 GiB absolute free (whichever is larger), configurable only by owner after new measurement. Sampled occupied/temp working space must also respect filesystem and quota; never delete existing data to fit.
- **Evidence before estimate:** per venue×instrument×family select at most three lawful representative files/partitions (quiet/typical/high-activity via predefined outcome-blind calendar or source volume, not strategy returns). For each measure `compressed_bytes, expanded_bytes, parquet_zstd_bytes, rows/events, temp_peak_bytes, checksum/processing`, with source source/hash, date and observation region. Metadata-only estimate if bytes aren't authorized, label `UNMEASURED`.
- For verified coverage days `D`, sampled average bytes/day `b`, compute `D*b`, add proven manifest/schema overhead, bounded retry/temp staging, and 12-month forward growth at observed daily rate. Show conservative low/base/high or observed min/median/max only if truly measured samples support them. Do not invent P50/P90 from two/three tiny periods. Separate cumulative disk capacity from transfer time and USD charges.
- Never presume one shared BTC/ETH Spot/Perp/venue can represent another. Distinguish monthly+daily overlap, re-download avoidance via checksums, original compressed archive retention versus expanded staging (not both permanently), idempotent partition manifests and integrity checks.
- Provisional **qualitative ranges ONLY:** Tier A tens GiB, Tier B may be hundreds GiB to >1TiB, Tier C multi-TiB; these are NOT 8-product calibrated measurements or permission to consume disk. Existing 172.33GiB may overlap some future data and cannot be simply added blindly.
