# v0.6.5 — Controller B Execution-First Policy R5

**Owner preference:** this is a personal research project. Optimize **implementation throughput, reproducible feature/data availability, and credible strategy evidence**, not review count or governance paperwork. This policy applies to work routing, not to real-world data rights, protected outcomes or trading authority.

## Default loop
`Controller B → Codex or Antigravity → focused tests / runnable artifact → Controller B acceptance`.

- Use Codex/Agy for ordinary implementation, bug fixes, missing historical source QC, sample counting, regression fixtures, and docs.
- A single integration task should have one primary writer; run at most two tasks concurrently if paths do not overlap.
- For T0 docs: review actual paths, links, and diff only. For T1 routine code: targeted test/compile/lint. For T2 offline DEV source/clock evaluation: changed-invariant positive/negative checks and verified origin/family separation. For T3 real source/PIT admission, production cutover, private outcomes, TESTNET/LIVE, funds: separately authorized, scoped independent gates.
- Do **not** route each test pass, PR, or deterministic receipt through 1-A. The same frozen blob need not be re-audited for a new wrapper commit when exact identity is already proven.
- 2-R and 2-C are on-demand scientific specialists: 2-R proposes at most two genuinely differentiated mechanisms if new source/regime evidence exists; 2-C tests a precise material novelty/causal/financial claim. Neither belongs on a compulsory engineering acceptance chain.
- Limit routine corrective cycles; after a persistent source or economic impossibility, document a measurable STOP or switch to the next informative task.
- Keep original Owner files, active collectors, protected archive roots and uncommitted in-flight code intact. Do not silently `reset --hard`, `git clean`, or overwrite parallel agents' outputs.

**Current priority:** BLINE-R1 is delivered as a feature-only historical pipeline. BLINE-R2 requires (A) useful native historical archive expansion and (B) independent event sample/coverage assessment. More downloaded hours are not necessarily more independent opportunities. Preserve frozen R1 parameters and do not evaluate real outcomes without the existing Owner/P3 scope.
