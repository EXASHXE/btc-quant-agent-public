## 2. Wave 1: Canonical Market Event Envelope Harmonization

### Affected Modules:
- `scripts/market_data/forward_public_feed_r1/contracts.py`
- `scripts/integration/market_event_bridge_r2/bridge_engine.py`

### Motivation & Duplication Eliminated:
Prior to this wave, `bridge_engine.py` contained five distinct hand-written dictionary literals constructing `market-event-v1` compliant envelopes:
1. `depth_delta` dispatch (lines 139–158)
2. `mark_price` derived bar dispatch (lines 208–224)
3. `agg_trade` dispatch (lines 224–244)
4. `last_kline_1m` dispatch (lines 263–284)
5. `funding_settled` dispatch to Consumer B and Consumer C (lines 335–382)

Each dictionary replicated 16 keys, including `compute_sha256` hashing of the payload, `connection_epoch` stringification, and `reason_codes` defaults.

### Refactored Architecture:
1. Created `build_market_event_envelope(...)` factory function in `contracts.py`:
   - Computes canonical SHA-256 for the payload via `compute_sha256`.
   - Populates all required fields with standardized defaults.
   - Accepts an optional `book` dictionary parameter for depth deltas.
   - Preserves caller-supplied `connection_epoch` types (`int` or `str`) ensuring compatibility with strict consumers (Consumer C requires `int`, Consumer B accepts `str`).
2. Updated `bridge_engine.py` to use `build_market_event_envelope` for all event types.
3. Removed unused imports (`hashlib`, `json`) and eliminated redundant local `_sha256` aliases.

### Behavior Equivalence Proof:
Every output envelope generated by `bridge_engine.py` has identical keys, types, values, and SHA-256 payload hashes as previously verified by `tests/test_v06_market_event_bridge_r2*.py`.

## 3. Wave 2: Layer 1 Socket Probe Timeout Bounding

### Affected Modules:
- `scripts/market_data/forward_public_feed_r1/proxy_route.py`

### Motivation & Bottleneck Eliminated:
During proxy diagnostic and health check routines (`run_desensitized_network_diagnostic`), Layer 1 executes a local TCP socket probe (`probe_tcp_socket`) against configured proxy hosts and ports. In synthetic negative tests (e.g., closed local ports `127.0.0.1:9999`), each probe blocked for a fixed `timeout=2.0s`. Multiple negative test cases accumulated over 4.5 seconds of pure socket idle blocking.

### Refactored Architecture:
- Bounded Layer 1 TCP probe timeout:
  ```python
  tcp_probe_timeout = min(config.timeout_seconds, 0.4)
  tcp_ok = probe_tcp_socket(config.host, config.port, timeout=tcp_probe_timeout)
  ```
- Fast-fails closed within 400ms when a local port is closed or unreachable while respecting smaller user-configured timeouts.

### Behavior Equivalence Proof:
- Unresponsive or closed ports still return `False` and produce identical diagnostic receipts (`status: "FAILED"`, terminal code `PROXY_PORT_CLOSED`).
- Negative test suite runtime was reduced from ~4.5s to 1.47s with zero assertion changes.

## 4. Wave 3: Portable CI Harness Process-Level Memoization

### Affected Modules:
- `scripts/integration/market_event_bridge_r2/portable_ci_refs.py`

### Motivation & Overhead Eliminated:
`PortablePinnedSourceHarness` materializes upstream commits (`51cdd4e1...` for B and `91495e5b...` for C) into isolated temporary directories for hermetic test execution. In each test:
1. Subprocess `git cat-file -e` was invoked repeatedly to check commit existence.
2. Subprocess `git archive | tar -x` was invoked repeatedly per subpath.
3. Subprocess calls incurred cross-process overhead and triggered legacy `tarfile` deprecation warnings on Python 3.12+.

### Refactored Architecture:
1. Added process-level immutable caches:
   - `_GIT_ROOT_CACHE: Path | None`: memoizes the resolved git repository root.
   - `_COMMITS_AVAILABLE_CACHE: set[str]`: memoizes verified commit SHAs.
   - `_TAR_BYTES_CACHE: dict[tuple[str, str], bytes]`: memoizes raw archive tar bytes per `(commit_sha, subpath)`.
2. Extracted archives in-memory using `tarfile.open(fileobj=io.BytesIO(tar_bytes))` with `filter="data"` on Python 3.12+ (suppressing deprecation warnings).

### Behavior Equivalence Proof:
- The extracted directory content remains byte-for-byte identical, fully passing `_verify_checksums(target_dir, commit_sha)` against `PINNED_FILE_CHECKSUMS`.
- Test harness execution time was reduced from 3.80s to 2.60s without weakening any sandbox isolation invariants.
