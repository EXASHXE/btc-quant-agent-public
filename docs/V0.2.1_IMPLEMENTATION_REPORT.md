# BTC Quant Agent v0.2.1 实施与验收报告

## 结论

- 软件状态：`IMPLEMENTED_V0.2.1`
- 策略状态：`EXPERIMENTAL`
- 自动执行：默认关闭
- 盈利能力：未验证；本报告不构成胜率或收益承诺

v0.2.1 已完成需求文档定义的 Quant Correctness Fix。v0.2.2 的结构/区域增强与 v0.3.0
的 Walk-forward 研究没有混入本版本。

## 已完成修复

| 项目 | 实现结果 | 输出影响 |
| --- | --- | --- |
| 风险预算 | 总损失含止损、双边费用、双边滑点、不利 Funding；最小名义仓位不足时拒绝 | 高摩擦候选仓位缩小或变为 `WAIT` |
| 历史衍生品 | immutable store、CSV、backward as-of、字段级 max-age、禁用历史盘口 | 回测不再用当前快照或未来数据 |
| Pullback 区间 | 多空均要求价格位于 EMA25 ± ATR 容差 | 深度穿越 EMA 后反弹不再误判为标准回踩 |
| Funding/OI | Funding 使用方向拥挤上下文；OI 使用价格 × OI 联合解释 | 删除“Funding 有值即加分” |
| TTL | 到期时间锚定 15m 决策数据，结合最大信号年龄 | 延迟扫描不能延长信号寿命 |
| 动态失效 | 新 15m 收盘后检查结构失效位、Regime、4H、净 RR | ACTIVE 可转为 `INVALIDATED` 并记录原因码 |
| TIMEOUT | 只使用持仓截止之前最后完整 1m K 线 | 不再借用截止后的价格 |
| 接口 | `/performance?days=N`；读取前过期；CLI 支持衍生品 CSV | API 与 CLI 参数一致 |

## 验收证据

- 单元/回归测试：67 项通过。
- 点名风险测试：费用、滑点、Funding、预算上限、名义上限、最小名义仓位均通过。
- 因果测试：as-of 不使用未来快照；未来数据突变不改变过去 Pivot 输出。
- 确定性测试：同一快照重复 100 次，Signal JSON 完全一致。
- 覆盖率：Risk 100%、Regime 100%、Strategies 89%、Engine 94%，均超过文档门槛。
- 质量门：Ruff 与 Mypy 通过。

## 保留边界

默认配置仍为：

```toml
[execution]
mode = "disabled"
auto_execute = false
allow_live = false
```

本版本没有完成 OOS/Forward 统计 Gate，因此不得将 `validation_status` 改为
`VALIDATED_OOS` 或 `VALIDATED_FORWARD`，也不应启用真实自动下单。
