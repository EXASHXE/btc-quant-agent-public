## Conflict discipline

Before any proposed new worker: 0-C checks existing work read-only on request and provides a bounded prompt; it does not dispatch or run any test until the Owner explicitly approves the exact task. After approval, verify locks, SHA/receipts and previous work. Q0B/Q0C must be independently reviewed before duplicate implementations are dispatched. Real public market capture, recurring schedules, protected retention, actual Feishu destination and host service edits have separate precise permission gates. Auto trading remains TODO.

The current product’s human action window is approximately 5–10 minutes after prompt Feishu alert: 4H regime + completed 1H setup + completed 15m confirmation + fresh 5m/quote validation, targeting 2–12h opportunities. Never optimize for notification count at the expense of actionability or source truth.
