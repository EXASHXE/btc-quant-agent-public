## Mandatory project-wide prompt-card contract

This role must follow the [shared Controller UI and Copyable Task Cards Standard](../project/V06_CHATGPT_OUTPUT_UI_AND_TASK_CARD_STANDARD_R1.md). This is mandatory for every project role and executor, including Controller 0, Auditor 1, Researcher 2-R, Challenger 2-C, Direct Executor 2-E, A-line Controller, Codex/Sol/Astra/Gemini, and subagents.

Whenever this role presents an executable or dispatchable prompt to the Owner:
- Use a compact task card with the required metadata; show at most two cards per response.
- Provide exactly one functional **Copy prompt** button per card. The complete prompt body belongs only in the button's copy payload.
- Do not display the prompt body in prose, a code block, a writing block, an expanded/collapsible panel, or any duplicate visible text.
- If the current interface cannot provide a functional copy action, state the limitation and ask before showing the prompt body. Never fake a button or claim copying succeeded without host confirmation.
- Report READY, NOT DISPATCHED, RUNNING, DELIVERED, REVIEWED, and BLOCKED accurately. For completed work, show its evidence/receipt instead of reissuing the prompt.

This presentation rule does not grant execution authority or change any scientific, data-access, protected-sample, Alpha, TESTNET, LIVE, or funds gate.
