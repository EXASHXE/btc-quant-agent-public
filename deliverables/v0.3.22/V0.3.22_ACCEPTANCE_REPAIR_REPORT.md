## 3. Finding P0-A: Reference-Entry Timing Repair

### Diagnostic Root Cause
In commit `24d30c3`, reference entry was computed as `reference_time_ms = curr_slot` (using the 1m candle starting at `curr_slot`). Because `curr_slot` is the close timestamp of the 15m decision window, the candle starting at `curr_slot` is within the decision-processing interval and does not reflect a post-decision execution entry.

### Protocol Repair Semantics
The reference entry was repaired to strictly enforce the +60s execution protocol boundary:
- **Decision Window Close**: `decision_close_ms = curr_slot` (the close of the 15m decision slot).
- **Reference Entry Timestamp**: `reference_time_ms = decision_close_ms + 60_000` (the open timestamp of the first fully available 1m candle strictly after decision close).
- **Prohibition Enforced**: The reference candle is never the candle beginning at `decision_close_ms`.
- **Primary 60m Exit**: Close of the 60th 1m candle, with open time `reference_time_ms + 59 * 60_000` (closing at `reference_time_ms + 60 * 60_000`, which is `curr_slot + 61 * 60_000`).
- **Secondary 240m Exit**: Close of the 240th 1m candle, with open time `reference_time_ms + 239 * 60_000` (closing at `reference_time_ms + 240 * 60_000`, which is `curr_slot + 241 * 60_000`).
- **Return Formulas**:
  $$\text{return\_60m} = \frac{\text{future\_close\_60m} - \text{reference\_price}}{\text{reference\_price}}$$
  $$\text{return\_240m} = \frac{\text{future\_close\_240m} - \text{reference\_price}}{\text{reference\_price}}$$

### Pre-Repair vs. Post-Repair Reference Semantics Comparison

| Parameter | Pre-Repair (`24d30c3`) | Post-Repair (Current) | Protocol Compliance Note |
| :--- | :--- | :--- | :--- |
| `decision_close_ms` | Implicitly `curr_slot - 1` | `curr_slot` (exact 15m boundary) | Exact UTC slot boundary |
| `reference_time_ms` | `curr_slot` | `curr_slot + 60_000` | +60s strictly after decision close |
| Reference Candle Open | `curr_slot` | `curr_slot + 60_000` | Avoids decision-interval overlap |
| 60m Exit Candle Open | `curr_slot + 60 * 60_000` | `reference_time_ms + 59 * 60_000` | Exact 60-bar duration |
| 240m Exit Candle Open | `curr_slot + 240 * 60_000` | `reference_time_ms + 239 * 60_000` | Exact 240-bar duration |

## 4. Finding P0-B: Baseline Specification & Incremental Testing Repair

### Diagnostic Root Cause
In commit `24d30c3`, the baseline model was an unregularized bivariate OLS on raw `trailing_atr_15m` without returns, and the incremental test was a simplified t-statistic that failed when covariates were non-invertible. The frozen protocol required an empirical direction baseline including trailing returns and a dimensionless ATR ratio, evaluated via a nested likelihood-ratio (LR) test and signed coefficient z-statistic.

### Protocol Repair Semantics
1. **Target Variable**: Future 60m binary direction indicator:
   $$y_{\text{dir}} = \begin{cases} 1.0 & \text{if } \text{return\_60m} > 0.0 \\ 0.0 & \text{otherwise} \end{cases}$$
2. **Causal Baseline Feature Vector**: Populated strictly from candles closing at or before `decision_close_ms`:
   $$\mathbf{x}_{\text{base}} = [1.0, \, \text{trailing\_return\_15m}, \, \text{trailing\_return\_60m}, \, \text{trailing\_atr\_ratio\_15m}]$$
   - $\text{trailing\_return\_15m} = \frac{\text{decision\_close} - \text{close\_15m\_ago}}{\text{close\_15m\_ago}}$
   - $\text{trailing\_return\_60m} = \frac{\text{decision\_close} - \text{close\_60m\_ago}}{\text{close\_60m\_ago}}$
   - $\text{trailing\_atr\_ratio\_15m} = \frac{\text{atr\_15m}}{\text{decision\_close}}$ (dimensionless ratio)
3. **Fail-Closed Baseline Quality Guard**:
   If any baseline field is missing or `None`, `evaluate_feature_hypotheses` raises a `ValueError` immediately. Baseline fields are never silently replaced by zero.
4. **Deterministic L2-Regularized Logistic Regression**:
   - Newton-Raphson optimizer with backtracking line search.
   - Fixed regularization strength: $\lambda = 1.0$ (equivalent to $C = 1.0$, unpenalized intercept at index 0). No hyperparameter tuning or search.
   - Fits baseline model $\mathcal{M}_{\text{base}}$ on $\mathbf{x}_{\text{base}}$ yielding $\ln L_{\text{base}}$.
   - Fits full model $\mathcal{M}_{\text{full}}$ on $[\mathbf{x}_{\text{base}}, x_{\text{micro}}]$ yielding $\ln L_{\text{full}}$, coefficients $\boldsymbol{\beta}$, and covariance matrix $\mathbf{\Sigma} = (\mathbf{X}^T \mathbf{W} \mathbf{X} + \mathbf{\Lambda})^{-1}$.
5. **Incremental Information Diagnostics**:
   - **Nested Likelihood-Ratio (LR) Statistic**:
     $$\text{LR} = 2 \cdot (\ln L_{\text{full}} - \ln L_{\text{base}})$$
     $$p_{\text{LR}} = 1.0 - \text{erf}\left(\sqrt{\frac{\max(0.0, \text{LR})}{2.0}}\right)$$
   - **Signed Microstructure Coefficient z-Statistic**:
     $$z_{\text{micro}} = \frac{\beta_{\text{micro}}}{\sqrt{\mathbf{\Sigma}_{\text{micro},\text{micro}}}}$$
     $$p_z = 1.0 - \frac{1}{2} \left(1.0 + \text{erf}\left(\frac{z_{\text{micro}}}{\sqrt{2.0}}\right)\right) \quad (\text{predefined sign } +1)$$
   - Candidate eligibility requires passing both the primary Holm-Bonferroni FWER gate and the repaired incremental information test.
