D（derivatives）因无全期 point-in-time 数据而标记 `SKIPPED_NO_POINT_IN_TIME_DATA`；E（order book）同样跳过。

## 性能与可复现性

实际官方数据冷回放烟测：100k 为 1.448 秒（尚处 warm-up）、500k 为 81.821 秒、1m 为 186.857 秒。正式开发集 Run 0 + A/B/C + 报告总耗时 14:02，峰值 RSS 3,038,356 KiB。跨消融共享缓存只复用由相同特征参数和相同历史窗口得到的不可变特征；评分参数变化不改变特征，EMA 等特征参数变化会强制重算，并有等价性测试覆盖。
