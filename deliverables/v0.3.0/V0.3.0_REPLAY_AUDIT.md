# BTC Quant Agent v0.3.0 Replay 审计

## 因果与边界

- 决策只在已闭合 15m K 线后产生；共 178,179 个开发集决策点。
- 1h/4h 历史只推进到 `close_time_ms <= decision_time`，不读取未来 K 线。
- Entry 只能从信号生成后的下一根 1m K 线开始；同一 1m 同时触发 stop/target 时保守按 stop-first。
- Funding 只在实际持仓跨越结算时刻时计费，并使用该结算分钟的官方 mark price。
- 最终 holdout 未读取、未运行。
