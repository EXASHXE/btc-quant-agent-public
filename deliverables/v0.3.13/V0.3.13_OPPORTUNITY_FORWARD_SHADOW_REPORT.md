## Decision

campaign. It did not qualify a Direction family and did not touch execution. The
Derivatives collector's primary failure was also isolated and repaired: the shell used
a local HTTP proxy while the user systemd manager inherited no proxy environment, so
direct TCP attempts failed with `Errno 101 Network is unreachable` despite healthy DNS.

The collector is reported **DEGRADED**, not HEALTHY. A full systemd-context run proved
that the persistent route problem is fixed, but the first natural timer run after the
fix was partial because the `openInterest` request hit a TLS handshake timeout. All
other required fields succeeded. This remaining endpoint instability must be measured
over more scheduled slots.
