## Agent, shadow, and execution semantics

Agent-facing scan output now distinguishes Market State, Opportunity, Opportunity Research Status, unqualified Direction, counter-evidence, Tradeability, Risk, and Runtime Eligibility. An Agent may explain `legacy_pattern_side` but may not promote it to Direction.

Future terminology is split: Signal Shadow validates Alpha/Direction; Execution Shadow measures quote, fillability, latency, partial fill, slippage, and protective-order timing. The existing `shadow_trades` table retains legacy Signal Shadow semantics only.

Before any future Testnet phase, the engineering backlog requires MARK_PRICE trigger parity between backtest and venue, explicit bar-touch non-guarantee, partial-fill/fill-probability modeling, and volatility/liquidity-aware slippage. None of that substitutes for the missing Direction Alpha.
