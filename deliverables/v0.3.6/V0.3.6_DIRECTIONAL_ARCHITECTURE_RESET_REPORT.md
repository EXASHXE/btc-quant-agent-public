## Architecture decision

There is no supported route to a Direction Engine + Opportunity Layer prototype using the same frozen price-only primitives. The Opportunity Layer result is useful, but without an independently supported direction source it cannot become a trading strategy.

The next research phase should investigate a genuinely new feature family without implementing or mining it in v0.3.6:

1. Point-in-time derivatives collected forward (OI, basis, taker flow, long/short positioning), never fabricated or backfilled without genuine historical records.
2. Cross-asset or market-breadth state.
3. A separately preregistered higher-timeframe momentum/state family.

No reverse-the-failed-signal rule is authorized.
