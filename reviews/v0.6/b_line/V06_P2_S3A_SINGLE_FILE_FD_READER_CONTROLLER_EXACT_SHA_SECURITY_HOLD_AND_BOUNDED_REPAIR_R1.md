**F01 BLOCKER — owner root lexical-deny is circumventable by an alias in ANCESTOR path of fixture root.** At `fd_syscall_wrapper.py:70-92`, `assert_not_owner_data_root(candidate_path)` only compares strings/substring, not a proven resolved physical root or owner-issued FD boundary. Linux `O_NOFOLLOW` on such an open prevents following the *final component only*; symlinked *ancestor* components (e.g. `/tmp/alias_parent/data`) can be followed.
