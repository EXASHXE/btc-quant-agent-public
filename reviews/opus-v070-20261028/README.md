## What has deliberately NOT been published
No private account data, API credentials, raw market observations, unreleased protected forward outcomes, protected 2024+ historical results, FINAL_HOLDOUT, mutable DBs, logs, local file paths as download surrogates, or unverifiable Alpha claims. Summaries of isolated work are **not** full patch/code disclosure or live-readiness proof.

## How Opus should use this pack
Treat dated reports and experiments as historical evidence under their exact hypotheses. Evaluate strategies and system architecture from first principles; disagree with any prior review or roadmap if warranted. Mark missing information as UNKNOWN instead of inferring it from absence. The Owner seeks strategy ideas **and** credible ways to test them, not a request for another pre-approved implementation task.
