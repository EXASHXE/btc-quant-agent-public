## 3. Independent Arithmetic Derivations & Oracles

In accordance with Section 4.1, no golden uses the production function under test as its sole oracle. The test suite [`tests/helpers_v042_semantic_goldens.py`](file:///tests/helpers_v042_semantic_goldens.py) implements pure, independent reference calculations:

1. **Linear Perpetual Realized PnL**:
   $$\text{PnL}_{LONG} = q \cdot (P_{exit} - P_{entry})$$
   $$\text{PnL}_{SHORT} = -q \cdot (P_{exit} - P_{entry}) = q \cdot (P_{entry} - P_{exit})$$
   Computed via `decimal.Decimal` in `linear_realized_pnl`.

2. **Funding Settlement Cashflow**:
   $$\text{Cashflow}_{funding} = -q_{signed} \cdot P_{mark} \cdot R_{funding}$$
   - Positive rate ($R > 0$): Longs pay ($q_{signed} > 0 \implies \text{Cashflow} < 0$), Shorts receive ($q_{signed} < 0 \implies \text{Cashflow} > 0$).
   - Computed in `funding_cashflow`.

3. **Weighted Average Entry & Partial Close**:
   $$P_{entry, weighted} = \frac{\sum P_i \cdot q_i}{\sum q_i} = \frac{1 \cdot 100 + 2 \cdot 110}{3} = \frac{320}{3} \approx 106.6666667$$
   Partial close of 1.5 units at 120:
   $$\text{PnL}_{partial} = 1.5 \cdot \left(120 - \frac{320}{3}\right) = 20.00$$
   Remaining unrealized at intermediate mark 115:
   $$\text{Unrealized} = 1.5 \cdot \left(115 - \frac{320}{3}\right) = 12.50$$

4. **Preregistered Random Draw Primitive**:
   Independently transcribed in `preregistered_random_draws`:
   - Master PRNG: `random.Random(master_seed)` generates trial seed via `master.randrange(0, 2**63)`.
   - Trial PRNG: `random.Random(trial_seed).sample(ordered_opportunities, k)` followed by timestamp sorting.
   - Direction assignment: independent `trial.shuffle(directions)`.

## 4. Causal Event Ordering & Boundary Contract

The formal event boundary ordering is encoded as:
$$\text{market\_observation\_availability} \le \text{signal\_observation} \le \text{decision} \le \text{order} \le \text{fill} \le \text{terminal}$$

For any funding settlement event that exists:
- Events follow explicit timestamps: order/fill/funding ordering follows timestamps.
- If $t_{funding} = t_{fill}$, the tie rule `FUNDING_BEFORE_FILL` applies funding first to pre-fill inventory.
- No synthetic funding event or position in the timeline is implied when no funding event exists.

### Key Invariants
1. **`FUNDING_BEFORE_FILL`**: When funding timestamp ties with an order fill timestamp, funding is applied against the pre-fill position inventory.
2. **No Synthetic Funding**: Lifecycles without funding omit the funding event entirely (Case A positive control).
3. **Ambiguity Preservation**: OHLC extrema do not establish intrabar sequencing. If multiple fill/touch sequences produce identical OHLC, the state is strictly marked `AMBIGUOUS_NOT_TESTABLE`.
4. **No Suffix Leakage**: Information available strictly after the decision or fill timestamp cannot alter execution price or cost.
