## 2. AS-01: Atomic Replace / Rename Bypass Repair

### 2.1 Problem & Reproduction (Astra Probe)
The original A02 test guard intercepted file openings via `builtins.open`, `Path.open`, and several `Path` methods (`exists`, `stat`, `unlink`, `mkdir`), but did not intercept atomic replacement/rename primitives.
A production artifact writer such as `FormalBenchmarkSuite.write(path)` calls `_atomic_write_json()`, which uses `tempfile.mkstemp` followed by `os.replace(temporary, target)`.
Because `target` is a destination in `os.replace` rather than an argument to `open()`, a test specifying a protected operational file (e.g. `var/quant.db` or `final_holdout.json`) would atomically replace and overwrite the operational store without triggering any guard exception.
Similarly, moving a protected source file out to an unguarded temporary destination was not intercepted.

### 2.2 Implemented Guard Architecture
In [`tests/conftest.py`](file:///tests/conftest.py):
1. Wrapped all reachable stdlib atomic move/replacement primitives:
   - `os.replace(src, dst)`
   - `os.rename(src, dst)`
   - `Path.replace(path, target)`
   - `Path.rename(path, target)`
   *(Note: `shutil.move` internally delegates to `os.replace`, so it is automatically protected).*
2. Enforced strict two-path checking before any filesystem syscall is invoked:
   ```python
   def guarded_os_replace(src: object, dst: object, *args: Any, **kwargs: Any) -> Any:
       guard.check_path(src, "os.replace:source")
       guard.check_path(dst, "os.replace:destination")
       return original_os_replace(src, dst, *args, **kwargs)
   ```
   Both safe -> forbidden destination and forbidden source -> safe destination operations are blocked immediately.
3. Fail-loud sentinel: raises `ForbiddenTestAccess` identifying the exact operation and whether the source or destination violated the boundary (`{op}:source` vs `{op}:destination`).
4. Canonicalization: All path arguments are canonicalized via `os.path.realpath`, resolving any symlink aliases before comparison.
5. Invariance verification: Added unmutated sentinel byte verification helpers (`read_bytes_unguarded`, `write_bytes_unguarded`, `exists_unguarded`) allowing tests to verify that sentinel files remain strictly unmutated and destination paths are not created after a blocked attempt.

## 3. AS-02: SQLite URI Normalization & Localhost Authority Bypass Repair

### 3.1 Problem & Reproduction (Astra Probe)
The previous `_sqlite_candidate()` implementation used naïve string slicing:
```python
uri_path = database[5:].split("?", maxsplit=1)[0]
```
When passed an RFC 3986 / SQLite URI with authority, such as:
`file://localhost/tmp/protected.sqlite3?mode=ro`
the slicing retained `//localhost/tmp/protected.sqlite3`. On Unix/Linux systems, this was evaluated as a UNC / network-share path rather than the local filesystem path `/tmp/protected.sqlite3`.
Meanwhile, SQLite natively accepts `localhost` as the local file authority and opens `/tmp/protected.sqlite3`. Thus, the guard checked a different path from the one SQLite actually opened, allowing direct reads to registered operational SQLite stores.

### 3.2 Implemented Normalization Architecture
In [`tests/conftest.py`](file:///tests/conftest.py), `_sqlite_candidate()` was refactored using standard-library `urllib.parse.urlsplit` and `urllib.parse.unquote`:
```python
def _sqlite_candidate(database: object) -> object:
    if not isinstance(database, str) or not database.startswith("file:"):
        return database
    parsed = urllib.parse.urlsplit(database)
    hostname = (parsed.netloc or "").lower()
    if hostname in {"", "localhost"}:
        decoded_path = urllib.parse.unquote(parsed.path)
        if decoded_path in {"", ":memory:"}:
            return ":memory:"
        if (
            os.name == "nt"
            and len(decoded_path) >= 3
            and decoded_path[0] == "/"
            and decoded_path[1].isalpha()
            and decoded_path[2] == ":"
        ):
            decoded_path = decoded_path[1:]
        return decoded_path
    return urllib.parse.unquote(parsed.path)
```

### 3.3 Normalization Behavior Matrix
| Input Database URI | Resolved Candidate | Normalized Semantics |
| :--- | :--- | :--- |
| `/path/to/file.db` (plain string) | `/path/to/file.db` | Plain path preserved |
| `Path("/path/to/file.db")` | `Path("/path/to/file.db")` | PathLike object preserved |
| `file:relative.db` | `relative.db` | Relative file URI normalized |
| `file:///absolute/path/file.db` | `/absolute/path/file.db` | Standard absolute URI normalized |
| `file://localhost/absolute/path/file.db` | `/absolute/path/file.db` | Localhost authority resolved to local path |
| `file:///tmp/some%20dir/file.db` | `/tmp/some dir/file.db` | Percent-encoded directory decoded |
| `file:///absolute/path/file.db?mode=ro` | `/absolute/path/file.db` | Query parameter stripped for local path check |
| `file://localhost/absolute/path/file.db?mode=rw` | `/absolute/path/file.db` | Localhost + query normalized |
| `file:///absolute/path/file.db?immutable=1` | `/absolute/path/file.db` | Immutable flag normalized |
| `:memory:` | `:memory:` | In-memory DB allowed |
| `file::memory:` | `:memory:` | URI in-memory DB allowed |
| Non-local authority (`file://remote/...`) | `unquote(parsed.path)` | Fails closed on local path comparison; SQLite rejects invalid authority |
