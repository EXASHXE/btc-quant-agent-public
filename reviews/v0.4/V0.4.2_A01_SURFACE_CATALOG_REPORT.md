## 1. Inventory Counting Methodology

1. **Source modules**: Every Python file located under `src/btc_quant_agent/**/*.py` is enumerated exactly once. Caches, egg-info, tests, and temporary artifacts are excluded.
2. **Physical LOC**: Physical UTF-8 lines of code including comments, docstrings, and blank lines (`sum(1 for _ in file)`).
3. **Tests**: All Python files under `tests/**/*.py`. Test cases collected via `pytest --collect-only -q` under the repository hermetic test guard.
4. **CLI leaves**: AST expansion and inspection of `argparse._SubParsersAction` via `btc_quant_agent.cli.build_parser()`.
5. **API routes**: AST inspection of FastAPI route decorators (`@app.get`, `@app.post`, etc.) in `src/btc_quant_agent/api.py`.
6. **Cross-module dependencies**: Static AST import analysis (`ast.Import` and `ast.ImportFrom`) mapping imports across all 95 source files and 67 test files.

## 7. Historical Runner Dependency Blockers

Archival of historical runners (planned for D02–D04) is strictly gated on extracting shared helpers that active code or tests still import:

1. **`BLOCKER_01_FUNDING_BACKTEST`**: `src/btc_quant_agent/data/funding.py` directly imports `FundingEvent` from `src/btc_quant_agent/backtest.py`. Archival of `backtest.py` is blocked until `FundingEvent` is extracted to canonical contracts (`contracts/funding.py` or `economic/events.py`).
2. **`BLOCKER_02_CAUSAL_ENTRY_HELPERS`**: Five subsequent research modules (`breakout_edge_research.py`, `directional_architecture_research.py`, `funding_crowding_research.py`, `funding_stability_research.py`, `cross_asset_breadth_research.py`) directly import `IndexedOneMinuteSeries`, `bootstrap_directionality`, `_percentile`, and `match_controls` from `causal_entry_research.py`.
3. **`BLOCKER_03_BREAKOUT_SPEARMAN`**: `funding_crowding_research.py` imports `_spearman` rank correlation from `breakout_edge_research.py`.
4. **`BLOCKER_04_DIRECTIONAL_MOVEMENT_LABEL`**: `funding_crowding_research.py` imports `movement_label` from `directional_architecture_research.py`.
5. **`BLOCKER_05_FUNDING_CROWDING_HELPERS`**: Three modules (`funding_stability_research.py`, `cross_asset_breadth_research.py`, `spot_perp_flow_research.py`) import `opportunity_union`, `_cluster_bootstrap_median`, `_permutation_analysis`, `PRIMARY_HORIZONS`, and `StrictAfterPriceSeries` from `funding_crowding_research.py`.
6. **`BLOCKER_06_TEST_SUITE_IMPORTS`**: Sixty-four test cases across 12 test modules (`tests/test_*_research.py`) directly import historical audit routines and assert development-only execution. Archival requires maintaining compatibility shims or mapping tests to archived packages.
