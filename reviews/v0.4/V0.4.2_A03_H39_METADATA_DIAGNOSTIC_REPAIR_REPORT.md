## 1. Defect Analysis & Old Unsafe Call Chain

### Defect H5
In `src/btc_quant_agent/microstructure_research.py`, `H39ResearchEngine.evaluate_validation_status()` is marked as a deprecated, non-authoritative diagnostic. However, when inspecting partitions overlapping the post-validation-start period (`max_t >= val_start_ms`), it executed:
```python
# OLD UNSAFE CALL PATH:
evaluate_validation_status()
  └── self.build_observations_for_partition(p, start_ms=val_start_ms)
        ├── self.get_canonical_1m_candles(c_req_start, c_req_end, candle_client=candle_client)
        │     └── (loads future 1m klines across 60m and 240m target horizons)
        ├── loader.compute_features(curr_slot)
        └── H39Observation(..., outcome_row=H39OutcomeRow(...))
              └── (evaluates future_close_60m, future_close_240m, return_60m, return_240m)
```

This violated the core architectural invariant that non-authoritative diagnostic paths must never construct or evaluate forward outcomes.

---

## 2. New Metadata-Only Algorithm

The new implementation completely eliminates calls to `build_observations_for_partition`, `get_canonical_1m_candles`, and any outcome/candle constructors:

1. **Partition Discovery**: Glob for `microstructure-*.sqlite3` under `self.microstructure_root`.
2. **Metadata Range Inspection**: Query SQLite partition metadata using `MicrostructureResearchLoader.get_time_range()`, which issues only `SELECT MIN(event_time_ms), MAX(event_time_ms)` on `book_samples` and `agg_trades`.
3. **Temporal Filtering**: If `max_t < val_start_ms` or timestamps are null, skip partition.
4. **Metadata Recording**: Record partition metadata `{ "partition": p.name, "start_ms": min_t, "max_ms": max_t, "fresh_slots_evaluated": 0 }`.
5. **Fail-Closed Progress**: Return explicit metadata-only fields in `accumulation_progress` (`maturity_achieved: False`, `authoritative: False`, `eligible_slots_accumulated: None`, `coverage_ratio_accumulated: None`) with `status: FORWARD_DATA_INSUFFICIENT`.
