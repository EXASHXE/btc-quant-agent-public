## 3. Forbidden-root inventory

The autouse pytest guard resolves/canonicalizes paths before comparing them and blocks:

- repository `data/forward/**`, including derivative, opportunity, microstructure, and canonical
  1-minute-candle stores;
- repository `data/research/h39_validation/**`, including the blind ledger, backups, frozen
  snapshots, and exactly-once registry;
- repository `var/quant.db`;
- any resolved path whose component or filename stem is exactly `final_holdout` (hyphen and
  underscore normalized);
- additional fake operational roots/files registered by adversarial tests.

Committed protocol, clarification, campaign, and epoch files remain allowed as immutable static
configuration. Temporary pytest roots remain allowed.

## 4. Injection and guard design

### Test roots and clocks

- Affected H39 tests now provide complete temporary microstructure, opportunity, canonical-candle,
  ledger, registry, and snapshot paths through local factories or explicit keywords.
- Forward Doctor and chain-health tests provide temporary derivative, opportunity, and
  microstructure paths.
- `H39ResearchEngine` gained an explicit typed `canonical_candles_path`; its production default is
  unchanged.
- `forward_doctor` gained explicit typed chain-path arguments; production defaults are unchanged.
- `generate_all_v0325_deliverables` gained explicit typed derivative, canonical-candle, registry,
  and snapshot arguments, forwards the injected opportunity path, and forwards `now_ms` to chain
  health. Existing positional argument order through `now_ms` was preserved.
- Maturity/readiness/status tests now pass deterministic `as_of_ms` or `now_ms` values. Event,
  receipt, wall-clock, and monotonic domains were not globally monkeypatched.

### Filesystem, SQLite, network, and execution

`tests/conftest.py` installs an autouse guard around the narrow boundaries used by this project:

- `Path` existence/stat/listing/open/create/delete operations and built-in `open`, checked only
  against resolved forbidden paths;
- `sqlite3.connect`, including decoded `file:` URIs;
- unmocked `urllib.request.urlopen` and unmocked DNS resolution;
- signed Binance execution calls targeting production or testnet Binance hosts.

The sentinel exception derives directly from `BaseException` so broad production
`except Exception` handlers cannot convert a forbidden access into an apparently normal health
result. Synthetic `.test` transport tests remain possible only when their HTTP boundary is
explicitly mocked.

### H39 outcome spy

The opt-in `h39_outcome_access_spy` fails immediately if a metadata-only test calls any of:

- `H39ResearchEngine.load_outcomes_from_opportunity_shadow`;
- `H39ResearchEngine.get_canonical_1m_candles`;
- `H39ResearchEngine.build_observations_for_partition`.

It is active in the relevant readiness/legacy/Final-Holdout-safety tests, which also assert that
the spy remained clean. A dedicated adversarial test proves that the spy itself fails loudly.
This is a test boundary only; the A03 production diagnostic repair remains deferred.

## 5. Adversarial and behavioral proof

`tests/test_hermetic_runtime_guard.py` creates populated sentinel stores under a temporary fake
checkout, registers them as forbidden, accesses them through a symlink, and proves access fails on
the resolved target before the sentinel can be opened. Separate tests prove:

1. fake Forward and H39 operational roots are blocked;
2. runtime `var/quant.db` is blocked before SQLite connect;
3. Final Holdout is blocked before open;
4. an unmocked Binance public request is blocked;
5. Binance live and testnet order transports are blocked;
6. a default H39 engine cannot silently fall back to the repository operational root;
7. the H39 outcome spy blocks future-return/canonical-candle loading.

The existing synthetic empty/missing, immature, mature metadata, gap/integrity, corrupt/schema,
stale/fresh, mutation, and exactly-once-registry cases continue to execute their behavioral
assertions. No tests were skipped, xfailed, deleted, or weakened, and no statistical budget, seed,
or formal parameter was reduced.
