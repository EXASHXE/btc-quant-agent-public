## 3.5 Exact Event/PIT Clock and Timestamp Closure (Resolution of H41-H01)

Ambiguous expressions such as `event_time < or == decision boundary` and unexplained `C[t]` are permanently superseded. The following normative clock model governs all H41 calculations:

### Normative Clock and Timestamp Table

| Concept | Mathematical Definition | Operational Meaning |
|---|---|---|
| **Canonical Bar Interval** | `B_k = [T_k, T_{k+1})` where `T_{k+1} = T_k + 1h` | Hourly UTC interval. Open time is `T_k`; close time is `T_{k+1} - 1ms`. |
| **Bar Finalization Timestamp** | `t_finalize(B_k) = T_{k+1}` | Bar is immutable and publicly finalized at interval end `T_{k+1}`. |
| **Decision Boundary / Timestamp** | `t = T_{k+1}` | Hourly epoch at which features are evaluated and decisions are made. |
| **Relative Bar Index** | `B_j(t) = [t - (j+1)h, t - jh)` for `j >= 0` | `B_0(t) = [t-1h, t)` is the just-completed bar finalized at `t`. `B_1(t)` is the bar preceding `B_0(t)`. |
| **Feature Information Cutoff** | Strictly `<= t` | Features computed at `t` use exclusively bars `{B_0(t), B_1(t), ..., B_j(t)}`. Zero forward leakage. |
| **Reference Entry Timestamp** | `t_entry = t` | The decision occurs at `t`; entry is referenced to the start of bar `B_{entry}(t) = [t, t+1h)`. |
| **Reference Entry Price** | `P_entry(t) = Open(B_{entry}(t))` | Opening price of the bar beginning at `t`. Causally downstream of `B_0(t)` finalization. |
| **Reference Exit Timestamp** | `t_exit = t + h` | Exactly `h` hours after entry. |
| **Reference Exit Price** | `P_exit(t) = Open(B_{t+h})` (equiv. `Close(B_{t+h-1})`) | Clean `h`-hour event study mark. Evaluated at interval boundary `t+h`. |
| **Horizon Return** | `r_gross(t) = s * (P_exit(t) / P_entry(t) - 1)` | Fractional price return for side `s ∈ {-1, +1}` on equal entry notional. |
| **Right-Boundary Censoring** | `t + h <= T_{partition_end}` | If `t + h > T_{partition_end}`, event is strictly censored; no trade is emitted. |
| **Missing-Bar / Gap Policy** | Missing bar in `{B_0..B_W}` or horizon `{B_{entry}..B_{exit}}` | Generates `SOURCE_UNAVAILABLE` or `NO_EVENT`. No forward-filling or imputation. |
| **Duplicate / Conflict Policy** | Multiple records with same timestamp | Hard fail-closed; execution aborts with `SOURCE_CORRUPT`. |
| **Synchronized Eligibility** | `t_BTC == t_ETH == t` | Both asset bars must be finalized, non-missing, and valid at `t`. |

## 3.6 Family Formula Closures

### D1 Trend Continuation
- For lookback $W \in \{4, 12\}$ at decision boundary $t$:
  $$\text{score}_{D1}(t) = \log\left(\frac{\text{Close}(B_0(t))}{\text{Close}(B_W(t))}\right)$$
- Requires all bars $B_0(t), \dots, B_W(t)$ to be present and consecutive.
- $Q80$ is computed from $\{|\text{score}_{D1}(t)|\}$ across all valid training bars in `WF1_TRAIN` using standard linear interpolation (`numpy.quantile(method='linear')`).
- If $|\text{score}_{D1}(t)| \ge Q80$ and $\text{score}_{D1}(t) \ne 0$:
  - $\text{side} = +1$ if $\text{score}_{D1}(t) > 0$
  - $\text{side} = -1$ if $\text{score}_{D1}(t) < 0$
- If $|\text{score}_{D1}(t)| < Q80$ or $\text{score}_{D1}(t) == 0$: $\text{side} = 0$ (strict abstention).

### D2 Breakout Continuation
- For reference window $W \in \{24, 72\}$ at decision boundary $t$:
  - Test/signal bar: $B_0(t)$ (closed at $t$).
  - Reference range: $B_1(t), \dots, B_W(t)$ (strictly excludes $B_0(t)$).
  - Upper channel: $U_W = \max_{j=1}^W \text{High}(B_j(t))$
  - Lower channel: $L_W = \min_{j=1}^W \text{Low}(B_j(t))$
- Breakout rules:
  - $\text{Close}(B_0(t)) > U_W \implies \text{side} = +1$
  - $\text{Close}(B_0(t)) < L_W \implies \text{side} = -1$
  - Boundary equality ($\text{Close}(B_0(t)) == U_W$ or $L_W$) is NOT a breakout $\implies \text{side} = 0$.

### D3 Failed-Move Reversal
- For reference window $W \in \{24, 72\}$ at decision boundary $t$:
  - Close-back bar: $B_0(t)$ (closed at $t$).
  - Break bar: $B_1(t)$ (closed at $t-1h$).
  - Pre-break reference range: $B_2(t), \dots, B_{W+1}(t)$ (strictly excludes $B_0$ and $B_1$).
  - Upper bound: $U_W = \max_{j=2}^{W+1} \text{High}(B_j(t))$
  - Lower bound: $L_W = \min_{j=2}^{W+1} \text{Low}(B_j(t))$
- Reversal rules:
  - Up-break followed by close-back:
    $\text{Close}(B_1(t)) > U_W \quad \text{AND} \quad L_W < \text{Close}(B_0(t)) < U_W \implies \text{side} = -1 \quad (\text{SHORT})$
  - Down-break followed by close-back:
    $\text{Close}(B_1(t)) < L_W \quad \text{AND} \quad L_W < \text{Close}(B_0(t)) < U_W \implies \text{side} = +1 \quad (\text{LONG})$
  - Strict adjacency: Break must occur on $B_1$ and close-back on $B_0$. No delayed revival or multi-bar search is permitted.
  - Boundary equality is not inside the bounds $\implies \text{side} = 0$.

### D4 Cross-Asset Modifiers
- Modifier state evaluated at decision boundary $t$:
  $$\text{OTHER\_RET4\_SIGN}(t) = \text{sign}\left(\log\left(\frac{\text{Close}(B_0^{other}(t))}{\text{Close}(B_4^{other}(t))}\right)\right)$$
- Full Parent Inheritance: D4 RET4 modifiers MUST inherit the entire D1 RET4 parent event population (including the train-frozen Q80 absolute threshold).
- Partitioning:
  - If $\text{OTHER\_RET4\_SIGN}(t) == 0$ or synchronized other-asset source is missing: emit NO EVENT.
  - $\text{CONFIRM} \iff \text{parent\_side}(t) == \text{OTHER\_RET4\_SIGN}(t)$
  - $\text{DIVERGE} \iff \text{parent\_side}(t) == -\text{OTHER\_RET4\_SIGN}(t)$
- CONFIRM and DIVERGE are mutually exclusive and preserve the parent action side.
- Claim restriction: Evaluates conditional subgroup expectancy only. No claim of independent predictive information.

## 3.7 Testability Architecture and Taxonomy (Resolutions of H41-B02, H41-H03)

The protocol establishes a strict physical and logical boundary:
1. **Internal Source Processor**: Causally evaluates finalized OHLC bars to generate the binary event mask $A[i, u]$ for each candidate $i$ and canonical hour $u$.
2. **Designer-Visible Output**: Materializes `H41_TESTABILITY_RECEIPT_V1` containing strictly non-outcome diagnostics:
   - Candidate ID, source hashes, split range;
   - Event count $N_i = \sum_u A[i, u]$;
   - Occupied UTC calendar days $D_i$;
   - Non-overlapping event packing count;
   - Block concentration index $C_i = N_i^2 / \sum_b n_{i,b}^2$;
   - Synchronized asset availability rate.
   - Zero returns, zero signs, zero P&L, zero rankings.

### Discrete Testability State Taxonomy

| State | Definition | Eligibility for Outcome Inference |
|---|---|---|
| `SOURCE_UNAVAILABLE` | Source bytes/projection missing, invalid, or corrupted | Ineligible (Fail-Closed) |
| `BASIC_SUPPORT_UNAVAILABLE` | Candidate fails basic support floors ($N < 60$ or $D < 30$) | Ineligible (Excluded from testable set) |
| `INFERENCE_ADEQUACY_UNAVAILABLE` | Candidate fails method-adequacy check (extreme concentration or missingness) | Ineligible (Excluded from testable set) |
| `TESTABLE_EXPLORATORY` | Candidate passes all support and adequacy checks | Eligible for joint inference |
| `INFERENCE_UNAVAILABLE` | Numerical bootstrap failure, degenerate variance, or zero-replicate breakdown | Eligible slot failed during inference |
| `EDGE_FAIL` | Testable candidate evaluated, but simultaneous LCB $\le 0$ | Evaluated failure |
| `EDGE_PASS` | Testable candidate evaluated, simultaneous LCB $> 0$ | Eligible for Candidate Lock |

## 3.8 Economic Endpoint and Claim (Resolution of H41-H04)

- Primary numerical endpoint:
  $$\mu[i] = \frac{\sum_u A[i, u] \cdot \left(s_{i,u} \cdot \left(\frac{P_{exit,u}}{P_{entry,u}} - 1\right) - 0.0012\right)}{\sum_u A[i, u]}$$
- `FIXED_FRICTION_PROXY_BASE = 0.0012` (12 bps round-trip).
- `FIXED_FRICTION_PROXY_STRESS = 0.0024` (24 bps round-trip, diagnostic only).
- **Formal Scientific Claim**: The endpoint measures `equal-entry-notional, event-conditioned directional expectancy after a fixed friction proxy, before funding and portfolio constraints`.
- It does NOT measure executable strategy return, capital-normalized Sharpe, portfolio equity, or net-of-funding perpetual P&L. Those requirements are explicitly deferred to later Playbook qualification.

## 3.9 Joint Inference Contract (Resolution of H41-H02)

The revised protocol discards all ad-hoc menus and freezes one unified joint procedure:
- **Method Family**: `shared-clock, source-bundle, standardized single-step joint maximum inference`.
- **Clock & Resampling**: All $K$ candidates and both assets share the exact same sequence of canonical source hours $u \in \{1, \dots, T\}$. Resampling draws block indices from this unified time axis, completely preserving contemporaneous cross-candidate and cross-asset correlations.
- **Source Bundles**: Original event/outcome bundles stay attached to their source anchor hour. Horizon returns are never reconstructed across synthetic block joins.
- **Standardized Joint Statistic**:
  - Sample estimate: $\hat{\mu}_i = \sum_u Z[i, u] / \sum_u A[i, u]$.
  - Bootstrap replicate estimate: $\mu_i^{*(b)} = \sum_u w_b[u] Z[i, u] / \sum_u w_b[u] A[i, u]$.
  - Centering: $\text{center}_i = \hat{\mu}_i$.
  - Studentization: $T_i^{*(b)} = (\mu_i^{*(b)} - \hat{\mu}_i) / \widehat{SE}_i$.
  - Joint maximum: $\max T^{*(b)} = \max_{i \in \text{TESTABLE}} T_i^{*(b)}$.
  - Simultaneous critical value $c_{95}$: empirical 95th percentile of $\max T^*$.
  - Simultaneous lower bound: $\text{LCB}[i] = \hat{\mu}_i - c_{95} \cdot \widehat{SE}_i$.
- **Replicate Budget**: 10,000 joint draws. Deterministic seed family.
- **Pre-Freeze Block Validation**: Block length $L$ shall NOT be chosen arbitrarily. A dedicated outcome-free synthetic validation stage (`H41_R2_OUTCOME_FREE_INFERENCE_VALIDATION`) evaluates candidates $L \in \{48h, 72h, 120h\}$ against baseline $24h$.
