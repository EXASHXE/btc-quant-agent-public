# H41 synthetic / PIT / exact-SHA validation R1

## Decision

`H41_SYNTHETIC_PIT_EXACT_SHA_VALIDATION = FAIL` for implementation `a3235fbc39667ca2a624faebd3cf9ee8a4b442de` (parent `407dabc415ae8cae4210250e992941c8b9b25464`). ## Material defect: source and TRAIN-fit authority can be substituted

1. `src/btc_quant_agent/h41/science.py` `build_event_batch` (line 180) accepts a caller-supplied `q80_by_id` mapping. `train_q80` correctly computes a complete TRAIN Q80 when called, but the production event path does not require its result or bind it to the same source. On an identical synthetic 2,184-hour calibration completed-bar sequence, changing only caller Q80 from `0` to `1` changed the D1 event count from **2,181 to 0**. This is a causal scientific input substitution, not numerical tolerance.
2. `EventBatch` (line 158) is directly constructible from caller events. `src/btc_quant_agent/h41/testability.py` `make_testability_receipt` (line 53) unconditionally stamps `EXPECTED_SOURCE_ROOT` on that batch. A wholly synthetic 60-event, 30-day caller batch therefore produced a `TESTABLE_EXPLORATORY` receipt bearing the accepted real source root, without any verified source object.
3. `src/btc_quant_agent/h41/outcomes.py` `materialize_outcomes` (line 28) accepts any `OpenReferenceMarks` implementation. Changing only caller-supplied synthetic Open marks changed the outcomes for the same event batch; the marks are not tied to the source that supplied completed features or to the accepted projection. The separate interface correctly prevents reference Opens from entering `candidate_side`, but does not yet establish post-event source lineage.

`source.py` separately implements checksum-bound accepted archive parsing, but no production authority path connects its verified source instance to the event, Q80, receipt, and outcome inputs. No real H41 row was read to establish this counterexample. The exposed contract allows an accepted-root receipt and later inference input to represent caller-selected scientific values. Consequently exact-SHA synthetic/PIT validation cannot attest a source-bound production path.

## Minimum repair contract

- Introduce a narrow immutable verified source context created only after the accepted BTC/ETH archive checksum, full projection, membership, and joint-root checks pass. Label synthetic contexts distinctly so they cannot mint accepted real-source receipts.
- Derive and seal each D1 Q80 from the complete WF1_TRAIN clock of that context. Calibration event construction must consume only this bound fit; arbitrary caller threshold maps must not confer production authority.
- Bind event batches and testability receipts to that same context and recompute or attest events from its completed views. Directly constructed caller events must not acquire `EXPECTED_SOURCE_ROOT`.
- Resolve outcome entry/exit Opens from the same verified context after the event mask is committed. Preserve the existing typed feature/outcome separation.
- Add synthetic adversarial tests for changed Q80 on unchanged views, constructed event batches, foreign marks, mixed source contexts, and replay after source-byte mutation, while retaining all frozen formulas and H40 immutability.

This is a bounded repair of provenance and fit binding. It must not choose a new scientific threshold, modify the candidate ledger, read real H41 outcomes, or create a real Candidate Lock.
