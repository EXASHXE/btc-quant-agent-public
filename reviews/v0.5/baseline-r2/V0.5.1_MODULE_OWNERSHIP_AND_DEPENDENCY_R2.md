## 3. Identification of Architectural Tech Debt & High-Risk Patterns

The census reveals several prominent design hotspots and technical debt patterns that must be cataloged for post-playbook refactoring:

### 3.1 God Modules Requiring Future Decomposition
1. **`src/btc_quant_agent/microstructure_research.py` (6,621 LOC)**:
   - *Issue*: Massive multi-purpose file combining SQLite schema definitions, WebSocket streaming logic, orderbook replay, OFI/CVD calculation, deep audit scripts, test fixtures, and statistical regression.
   - *Risk*: High cognitive load, merge conflict hotspot, complex circular import potential.
   - *Action*: Strictly **DEFER_UNTIL_AFTER_FIRST_PLAYBOOK**. The module is not in the critical path for the 18 REGISTERED P1 slots.
2. **`src/btc_quant_agent/h40/lifecycle_authority.py` (6,521 LOC)**:
   - *Issue*: Contains extensive type definitions, transition guards, stage verifiers, and dozens of synthetic test monkeypatch helpers in a single compilation unit.
   - *Risk*: Large file size, but thoroughly tested and cryptographically sealed.
   - *Action*: **NO_ACTION / PRESERVE**. Stability of lifecycle governance is critical; refactoring carries catastrophic authority divergence risk.

### 3.2 Research Logic Entangled in Operations
- **`opportunity_forward.py` (1,176 LOC)**: Combines operational daemon loops with quantitative feature calculation (EMA slope, volatility band expansion).
- *Mitigation*: Forward shadow operates in isolation from historical H40 discovery. Entanglement does not affect P1 discovery correctness.

### 3.3 Full-History Loaders & Memory Scaling
- `h40/source_manifest.py` and `data/csvio.py` contain legacy routines that load entire multi-year CSV files into memory.
- *Mitigation*: H40 research loaders use memory-mapped Parquet queries with row-group pushdown (`pyarrow.dataset`), bypassing full-history memory bloat.

## 4. Architectural Boundaries and Invariants

1. **Firewall Invariant**: `h40/guards.py` is invoked at every data access and split boundary. Any code attempting to access `data/research/h39_validation/` or `CONFIRMATION_HOLDOUT` raises an immediate uncatchable `H40FirewallViolationError`.
2. **Authority Invariant**: `protocol_authority.py` derives all semantic roots via `canonical_sha256` from immutable preimages. No constant can be altered without breaking the root tree.
3. **Execution Invariant**: `execution/service.py` is permanently locked under `RESEARCH_DISABLED_V1`. Network execution paths require explicit, uncommitted operator unlock credentials.
