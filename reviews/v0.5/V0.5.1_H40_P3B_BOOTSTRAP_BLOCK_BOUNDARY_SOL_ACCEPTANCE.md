## 1. Gap adjudication

The executor STOP is accepted.

R1 freezes source-block sampling and replicate metric recomputation but does not uniquely define fixed-horizon outcome lookup at synthetic concatenation boundaries.

Using the next sampled block as a continuation market path would create artificial price jumps and can change labels, proxy returns, bootstrap vectors, corrected bounds, and candidate ranking.

## 2. Accepted interpretation

A bootstrap replicate resamples:

```text
source-anchored decision/outcome observation bundles
```

in 168-hour joint source-time blocks.

The synthetic concatenated sequence determines only:

```text
sample multiplicity
replicate order
final H-position trimming
```

It does not create new market time.

## 3. Fixed-horizon ownership

For each retained sampled decision at original source time t and fixed horizon h:

```text
P0(t)
C_h(t)
label(t,h)
r_net(t,h)
```

remain bound to the original source timeline and accepted source/split/purge authority.

The next synthetic block has zero authority over that trade's endpoint.

A source endpoint may lie beyond the 168-hour core when it is within the originally authorized outcome-support/purge interval.

Such support rows do not become sampled decision rows.

## 4. Trimming

After concatenating B block cores, only the first H sampled core-hour positions are retained.

A retained tail decision remains a complete sampled observation if its original source-bound horizon outcome exists.

A discarded position contributes nothing.

No last-h-hours deletion rule is introduced.
