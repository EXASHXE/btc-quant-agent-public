## Controller source review

### R8-01 shared SQLite recursive trigger invariant — PASS

`live_db.connection()` now explicitly enables `PRAGMA recursive_triggers=ON` and reads it back before yielding the connection. Failure to enable it raises `LIVE_RECURSIVE_TRIGGERS_REQUIRED`. Existing WAL, synchronous=FULL, foreign_keys=ON and busy_timeout behavior is preserved.

This closes the specific SQLite REPLACE implicit-delete bypass observed by B5 R7: REPLACE now causes the existing immutable delete trigger to participate.

### R8-02 initial insert completion fabrication — PASS

`trg_live_position_dispatch_blank_insert` allows only a blank-authority `PENDING` dispatch:

- analysis_completed=0;
- no dispatch/admission hashes;
- no frozen-case authority;
- retry_count=0;

Direct initial insertion of DONE/completed/admitted authority is rejected.
