## V7 adjudication

Finding: `B5-R8-V7-COLD_CONSTRUCTOR_COMPATIBILITY`.

Controller accepts the observation but reclassifies it from an R8 safety-semantic blocker to an inherited fail-closed startup availability / migration-concurrency debt.

Basis:
1. the event-column conditional ALTER path that produced `duplicate column name: account_id` is source-identical at the R7 parent and R8 target;
2. the WAL cold-start lock race was behaviorally reproduced on both parent and target;
3. the failed constructor raises before producing a usable initialized `PositionSupervisor`; no initialized supervisor with missing R8 guards was demonstrated;
4. follow-up target databases in which a peer constructor completed contained all eight R8 guards;
5. production `LiveV1Runtime.create()` constructs one `PositionSupervisor` per runtime instance rather than intentionally spawning concurrent constructors inside one runtime.

This does NOT prove multi-process cold-start robustness. Until operational readiness closes the debt, TESTNET deployment must use a serialized/single runtime initializer and must not rely on concurrent workers racing schema initialization.
