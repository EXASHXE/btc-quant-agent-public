## 3. Behavioral and Immutability Test Proofs (T1–T5)

Four dedicated adversarial tests were added to `tests/test_v050_r02_orchestration_guards.py`:

### T1 — `GET /signals/latest` is Storage-Read-Only
- **Test**: `test_r02r_t1_latest_signal_is_storage_read_only`
- **Proof**: An ACTIVE signal with an expired timestamp (`expires_at_ms = now - 30s`) was persisted into SQLite. The `/signals/latest` endpoint was invoked.
- **Assertions verified**:
  - Endpoint returns the signal successfully (`status == 'ACTIVE'`);
  - SQLite database state snapshot before and after invocation is strictly identical (zero row/state delta);
  - `signals.status` remains `'ACTIVE'`;
  - `signals.payload_json` is unchanged;
  - Zero new rows/events written across all tables;
  - `Repository.expire_signals` is not invoked by the GET handler.

### T2 — `GET /signals/{signal_id}` is Storage-Read-Only
- **Test**: `test_r02r_t2_specific_signal_is_storage_read_only`
- **Proof**: Same verification for `/signals/{signal_id}`, confirming storage immutability when querying a specific signal by ID.

### T3 — All Six Retained API Handlers Have No Mutation Path
- **Test**: `test_r02r_t3_all_retained_routes_have_no_repository_mutation`
- **Proof**: All 6 retained routes (`/health`, `/signals/latest`, `/signals/{id}`, `/signals/{id}/explanation`, `/performance`, `/execution/status`) were exercised and the database snapshot remained identical before and after; the test also installs a mutation sentinel for the test repository connection path.
- **Result**: All 6 routes passed with no persisted state delta.

### T4 — Explicit Mutating Workflows Still Own Expiry
- **Test**: `test_r02r_t4_explicit_operational_workflows_still_own_expiry`
- **Proof**:
  1. Direct call to `repo.expire_signals(now_ms)` mutates expired ACTIVE signals to `EXPIRED`.
  2. Operational CLI command `cli.main(["signal", "latest"])` explicitly triggers `expire_signals` and mutates expired ACTIVE signals to `EXPIRED`.
- **Conclusion**: Signal expiration semantics are preserved for deliberate operational workflows and have not been globally disabled.
