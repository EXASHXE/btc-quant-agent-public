## 2. Background and Purpose

A Git history metadata sanitation was executed to remove historical corporate email references (`REMOVED_CORPORATE_COMMIT_EMAIL`) across commit author, committer, and tagger metadata, replacing them with the modern GitHub ID-based noreply address (`76859917+EXASHXE@users.noreply.github.com`).

Because Git commit object IDs are cryptographic hashes over commit metadata (including author/committer email, timestamps, and parents), rewriting metadata produced new commit object IDs for the affected commits and all their descendants on `v0.5-refactor`, `v0.5-refactor-docs`, and `forward-evidence-health-lightweight`.

Under repository governance rules, no scientific protocol definitions or ledger rules were modified. However, executable authority structures in the H40 lifecycle that bound specific Git commit object IDs (e.g. historical scaffold lineage and governance amendment artifacts) required mechanical remapping to their sanitized commit identities.
