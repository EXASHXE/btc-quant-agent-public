# 2. Comprehensive Statistical Root Cause Analysis

We audited the statistical implementation to determine whether the 8–14% FWER inflation was:
- A. Monte Carlo noise from undersized $M=100$;
- B. A defect in the implementation;
- C. Invalid bootstrap / studentization methodology;
- D. A property of one or more synthetic DGPs;
- E. Some combination.

### Verdict: Root Cause is Combination C + B (Invalid Studentization & Methodological Defect)

The failure was not Monte Carlo noise ($M=500$ diagnostic simulations reproduced the exact 11.5% FWER). The root causes are:

1. **Failure of Studentization (Bootstrap-t Denominator Defect)**:
   In the rejected implementation (`run_joint_bootstrap`):
   ```python
   se_hat = np.std(mu_b, axis=1, ddof=1)
   T_b = (mu_b - center[:, None]) / se_hat[:, None]
   ```
   - In each Monte Carlo dataset, the original test statistic is $T_i = \widehat{\mu}_i / \widehat{SE}_i$, where $\widehat{SE}_i$ is estimated with finite degrees of freedom ($\approx 30$ blocks for $L=72h$). Due to denominator estimation variability, $T_i$ follows a Student-$t$ distribution with heavy tails. The 95th percentile of $\max_{i=1}^{20} T_i$ in Monte Carlo is **3.117**.
   - However, in the bootstrap, the implementation divided every replicate $\mu^*_{i, b}$ by the *exact same constant* $\widehat{SE}_i$. Because the denominator had zero variability across $b=1,\dots,B$, the bootstrap test statistic $T^*_{i, b}$ had thin Gaussian tails!
   - The 95th percentile of the maximum of 20 correlated Gaussians is only **2.707**!
   - Testing a heavy-tailed Student-$t$ statistic against a thin-tailed Gaussian critical value ($c_{95} = 2.707$) directly caused the $\sim 11.5\%$ empirical rejection rate under the null!

2. **Downwards Bias from Bartlett Covariance Taper on Overlapping Returns**:
   - For holding horizon $h=24$, the theoretical autocorrelation extends to lag 23.
   - The Moving Block Bootstrap (MBB) has an effective Bartlett spectral taper of $1 - k/L$.
   - For $L=72h$ and $h=24$, the taper introduces an analytical variance ratio of $1 - \frac{h^2 - 1}{3 L h} = 1 - \frac{575}{5184} \approx 0.889$.
   - This $\sim 11\%$ variance under-estimation ($\sim 5.5\%$ SE under-estimation) further inflates the sample test statistic $T_i$, pushing FWER higher.

3. **Power Curve Misconception and Fabricated Reporting**:
   - For candidate 1 ($h=24$), the return standard deviation is $\sqrt{24/4} \approx 2.45\times$ larger than for $h=4$. Over $T=2,184$ hours with $N \approx 400$ events, the standard error is $\widehat{SE} \approx 0.0028 = 28\text{ bps}$.
   - With $c_{95} \approx 3.0$, a candidate requires an empirical effect exceeding $3.0 \times 28\text{ bps} \approx 84\text{ bps}$ to reject the simultaneous null ($LCB > 0$).
   - A true effect of 20 bps yields $Z = (20 - 84)/28 \approx -2.28$, giving an empirical power of $\approx 5\%$.
   - The R1.1 specification explicitly anticipated this: *Power $<80\%$ at 20bp does NOT invalidate inference; candidates with valid FWER but power $<80\%$ are classified as `METHOD_POWER_LIMITED`.*
   - Rather than faithfully applying this taxonomy, the prior script hardcoded fabricated claims of $>76\%$ power.

4. **Class 12 Mixed Null / Non-Null Omission**:
   - The prior script defined Class 12 identically to Global Null (zero injected signal), because its FWER calculation checked `np.any(lcb[testable] > 0.0)` across all testable candidates. If true signal had been injected, true rejections would have been incorrectly counted as Type-I errors.

# 3. Exact Mathematical Formulation of the Repaired Inference Engine

We freeze the exact equations for the repaired **shared-clock, source-bundle, standardized single-step joint maximum bootstrap (Bootstrap-t with Künsch 1989 ratio-estimator block sums)**:

### 1. Sample Estimator $\widehat{\mu}_i$
For candidate $i$ across canonical hours $t \in \{0, \dots, T-1\}$:
$$\widehat{\mu}_i = \frac{\sum_{t=0}^{T-1} Z[i, t]}{\sum_{t=0}^{T-1} A[i, t]} = \frac{\sum_{t=0}^{T-1} A[i, t] Y[i, t]}{\sum_{t=0}^{T-1} A[i, t]}$$
where eligibility requires $N_i = \sum_t A[i, t] \ge 60$. Ineligible candidates fail closed ($LCB_i = -\infty$).

### 2. Original Sample Standard Error $\widehat{SE}_i$ (Künsch 1989 Moving Block Sums)
Let $S = T - L + 1$ denote the number of contiguous blocks of length $L$. For block start $j \in \{0, \dots, S-1\}$:
$$Z_{\text{block}}[i, j] = \sum_{u=0}^{L-1} Z[i, j + u], \quad A_{\text{block}}[i, j] = \sum_{u=0}^{L-1} A[i, j + u]$$
The influence block deviation is:
$$e_{\text{block}}[i, j] = Z_{\text{block}}[i, j] - \widehat{\mu}_i A_{\text{block}}[i, j]$$
The consistent moving block variance of the ratio estimator is:
$$\widehat{\text{Var}}(\widehat{\mu}_i) = \frac{1}{\left(\sum_t A[i, t]\right)^2} \frac{T}{L \cdot S} \sum_{j=0}^{S-1} \left( e_{\text{block}}[i, j] - \bar{e}_{\text{block}}[i] \right)^2$$
$$\widehat{SE}_i = \sqrt{\widehat{\text{Var}}(\widehat{\mu}_i)}$$

### 3. Joint Shared-Clock Block Resampling
For replicate $b \in \{1, \dots, B\}$, draw $k = \lceil T / L \rceil$ block starts:
$$s_{b, 1}, s_{b, 2}, \dots, s_{b, k} \overset{\text{iid}}{\sim} \text{Uniform}(\{0, 1, \dots, S-1\})$$
**Strict Invariant**: The exact same sequence $(s_{b, 1}, \dots, s_{b, k})$ is applied simultaneously across all $K=20$ candidates and both BTC and ETH source series.

### 4. Replicate Ratio Estimator $\mu^*_{i, b}$
$$Z^*_b[i] = \sum_{m=1}^k Z_{\text{block}}[i, s_{b, m}], \quad A^*_b[i] = \sum_{m=1}^k A_{\text{block}}[i, s_{b, m}]$$
$$\mu^*_{i, b} = \frac{Z^*_b[i]}{A^*_b[i]}$$

### 5. Finite-Sample Non-Circular Null Centering Rule $\text{center}_i$
Under uniform block selection over $\{0, \dots, S-1\}$:
$$E^*[Z^*_b[i]] = \frac{k}{S} \sum_{j=0}^{S-1} Z_{\text{block}}[i, j], \quad E^*[A^*_b[i]] = \frac{k}{S} \sum_{j=0}^{S-1} A_{\text{block}}[i, j]$$
$$\text{center}_i = \frac{\sum_{j=0}^{S-1} Z_{\text{block}}[i, j]}{\sum_{j=0}^{S-1} A_{\text{block}}[i, j]}$$
This completely eliminates non-circular boundary weighting bias.

### 6. Replicate Standard Error $\widehat{SE}^*_{i, b}$ (Bootstrap-t Studentization)
In bootstrap replicate $b$, the $k$ blocks are independent draws. The replicate influence deviations across blocks $m \in \{1, \dots, k\}$ are:
$$e^*_{b, m}[i] = Z_{\text{block}}[i, s_{b, m}] - \mu^*_{i, b} A_{\text{block}}[i, s_{b, m}]$$
Notice $\sum_{m=1}^k e^*_{b, m}[i] = 0$. The sample variance across the $k$ independent blocks is:
$$s^2_{e^*_b}[i] = \frac{1}{k - 1} \sum_{m=1}^k \left( e^*_{b, m}[i] \right)^2$$
$$\widehat{SE}^*_{i, b} = \frac{\sqrt{k}}{A^*_b[i]} \sqrt{ s^2_{e^*_b}[i] } = \frac{1}{A^*_b[i]} \sqrt{ \frac{k}{k - 1} \sum_{m=1}^k \left( Z_{\text{block}}[i, s_{b, m}] - \mu^*_{i, b} A_{\text{block}}[i, s_{b, m}] \right)^2 }$$

### 7. Studentized Joint Test Statistic and Simultaneous LCB
$$T^*_{i, b} = \frac{\mu^*_{i, b} - \text{center}_i}{\widehat{SE}^*_{i, b}}$$
$$\max_T^{(b)} = \max_{i \in \text{valid}} T^*_{i, b}$$
$$c_{95} = \text{percentile}_{95}\left( \max_T^{(1)}, \dots, \max_T^{(B)} \right)$$
$$LCB_i = \widehat{\mu}_i - c_{95} \cdot \widehat{SE}_i$$

Because both the sample test statistic $T_i = \widehat{\mu}_i / \widehat{SE}_i$ and the bootstrap test statistic $T^*_{i, b} = (\mu^*_{i, b} - \text{center}_i) / \widehat{SE}^*_{i, b}$ are studentized by their respective block degrees of freedom, the tails match exactly, eliminating the anti-conservative inflation.
