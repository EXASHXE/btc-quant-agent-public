## 1. Existing accepted authority

BASE §3.2 defines the forward statistical return:

```text
r_h(t) = log(C_h(t) / P0(t))
```

where:
- `P0(t)` is the linear-perpetual 1h candle open at decision time `t`;
- `C_h(t)` is the close of the last hourly bar in `[t, t+h)`.

BASE §3.2 also freezes the analytical round-trip friction proxy:

```text
c_rt = 0.0012
```

for the accepted H40 V1 configuration.

BASE §3.3 expresses MFE/MAE in simple fractional price-return units.

BASE §3.4 distinguishes fast proxy screening from canonical execution/accounting replay.

R1 §2.1 and R2 §2.2 require:

```text
x_i = r_net,i
```

where `r_net,i` is the cost-adjusted fractional return under the frozen 12 bps proxy, but they did not explicitly map the logarithmic forward return into the LONG/SHORT fractional P&L.

## 2. Exact per-trade proxy gross return

Let:

```text
a_i = +1 for LONG
a_i = -1 for SHORT
```

and let:

```text
q_i = C_h / P0 = exp(r_h)
```

The exact proxy gross fractional return is:

```text
r_gross,i = a_i * (q_i - 1)
          = a_i * (exp(r_h,i) - 1)
```

Equivalently:

```text
LONG:
r_gross = exp(r_h) - 1
        = C_h / P0 - 1

SHORT:
r_gross = 1 - exp(r_h)
        = 1 - C_h / P0
```

Implementation SHOULD use:

```python
math.expm1(r_h)
```

for numerical stability:

```python
gross = action_sign * math.expm1(r_h)
```

This is the fractional P&L of an unlevered linear-perpetual direction relative to entry notional under the analytical fixed-horizon proxy.

## 3. Exact proxy net return

The accepted round-trip friction proxy is deducted exactly once:

```text
r_net,i = r_gross,i - c_rt
```

Therefore:

```text
LONG:
r_net = exp(r_h) - 1 - c_rt

SHORT:
r_net = 1 - exp(r_h) - c_rt
```

For current H40 V1:

```text
c_rt = 0.0012
```

No leverage multiplier, margin scaling, compounding, clipping, liquidation rule, or funding term is added to this proxy formula.

Funding enters only the later canonical economic replay under authoritative settlement evidence.

---

## 4. Explicitly forbidden alternatives

The following are NOT authorized as `r_net`:

```text
LONG  = +r_h - c_rt
SHORT = -r_h - c_rt

a_i * r_h - c_rt

exp(a_i * r_h) - 1 - c_rt

any symmetric-log-return PnL

any canonical execution fill/fee/funding calculation substituted into Discovery proxy statistics

any favorable-path MFE/MAE-derived realized return
```

The statistical log return `r_h` remains an input transformation for labels and is not itself the proxy fractional P&L.

## 6. Net expectancy definition

For N accepted trades in the evaluated partition:

```text
NET_EXPECTANCY =
(1 / N) * sum_i r_net,i
```

where each `r_net,i` is computed exactly by this closure.

The same per-trade `r_net` values are the net-return series used by:

- R2 HAC / n_eff;
- moving-block bootstrap recomputation;
- within-family NET_EXPECTANCY max-statistic;
- marginal one-sided NET_EXPECTANCY p-value;
- adjusted NET_EXPECTANCY LCB;
- accepted proxy profit-factor calculations where those calculations consume net trade returns.

No second proxy P&L formula is allowed.
