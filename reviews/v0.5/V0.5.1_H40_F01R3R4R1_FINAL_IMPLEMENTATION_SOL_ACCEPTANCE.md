## 1. R4R1 final seal accepted

The remaining F01R3R4 issue was that committed-lineage verification could fall back from:

\`\`\`text
<run>/receipts/<hash>.json
\`\`\`

to the generic compatibility resolver \`_find_receipt_path()\`, which can locate legacy transition-key mirrors.

The final patch removes that fallback.

Committed-lineage membership now requires the exact authoritative content-addressed receipt path:

\`\`\`text
<run>/receipts/<expected_hash>.json
\`\`\`

If that exact file is absent, lineage restoration fails closed.

Legacy mirror files remain compatibility artifacts only and cannot establish committed lineage authority.
