## Content-addressed evidence contract

The resolver accepts only lowercase SHA-256 identities and reads `<root>/<first-two-hex>/<digest>.json`; it rejects symlink escape, traversal, missing objects, duplicate/extra/missing keys, noncanonical JSON bytes, nonfinite JSON, and semantic-hash mismatch. Every object has an exact `schema_id` (the frozen typed Discovery result uses `evidence_schema_id`) and exact key set. Numeric values requiring decimal representation are strings.
