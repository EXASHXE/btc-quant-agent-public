## Rolling OOS contract

Use chronological, non-overlapping OOS evaluation.

Minimum structure:
- at least 3 chronological OOS partitions where data permits;
- calibration/development data strictly precedes each OOS partition;
- no OOS outcome may alter thresholds, weights, policy action semantics, cost assumptions, or feature promotion;
- if available history cannot support 3 partitions, return DIAGNOSTIC_ONLY unless a hard FAIL gate is triggered.

## Release-gating metrics and thresholds

These thresholds are frozen now and may not be moved after OOS inspection.

### Integrity gates — mandatory PASS
Any violation => `TACTICAL_DECISION_QUALITY_FAIL`.

1. PIT / chronology / deterministic manifest integrity = PASS.
2. Transaction costs materially included in `net_R`.
3. No outcome-informed policy retuning.
4. No protected A-line outcome use.
5. Repeated identical input manifest produces identical result manifest.

### Evidence support
For full `TACTICAL_DECISION_QUALITY_PASS`:
- OOS actionable decision count >= 100;
- LONG actionable count >= 20 when LONG is an enabled action;
- SHORT actionable count >= 20 when SHORT is an enabled action;
- at least 3 OOS partitions with >= 20 actionable decisions in at least 2 partitions.

Insufficient support without a hard negative gate => `TACTICAL_DECISION_QUALITY_DIAGNOSTIC_ONLY`.

### Outcome quality — PASS band
For `TACTICAL_DECISION_QUALITY_PASS`:
- aggregate OOS `mean_net_R >= +0.05R`;
- aggregate OOS `median_net_R >= -0.05R`;
- at least 2/3 supported OOS partitions have `mean_net_R >= 0`;
- aggregate `stop_before_target <= 0.65` when target/stop outcomes are defined.

These are operational release heuristics, not statistical alpha claims.

### Hard negative gates
Any of the following with adequate support => `TACTICAL_DECISION_QUALITY_FAIL`:
- aggregate OOS `mean_net_R <= -0.10R` with >= 100 actionable decisions;
- aggregate OOS `median_net_R <= -0.20R` with >= 100 actionable decisions;
- at least 2 supported OOS partitions each have `mean_net_R <= -0.25R` and n >= 20;
- `stop_before_target > 0.70` with >= 100 target/stop-resolved decisions;
- deterministic replay reveals systematic cost omission that changes sign of aggregate net result.

Between PASS and hard-FAIL bands => `TACTICAL_DECISION_QUALITY_DIAGNOSTIC_ONLY`.
