### Detailed Analysis of S08 Blocker

1. **Frozen Semantics #21 Requirement:**
   *"Resolved authoritative evaluations are immutable; only pending rows may later resolve."*
2. **Current Implementation in `src/btc_quant_agent/market_watch/state.py` (lines 1773–1789):**
   ```python
   # 1. Natural key check: (feature_evidence_id, evaluation_profile_version)
   cur = conn.execute(
       """
       SELECT evaluation_id, evaluation_json FROM tactical_grid_shadow_evaluations_v1
       WHERE feature_evidence_id = ? AND evaluation_profile_version = ?
       """,
       (evaluation.feature_evidence_id, evaluation.evaluation_profile_version),
   )
   row = cur.fetchone()
   if row is not None:
       existing_id = str(row[0])
       if existing_id == evaluation.evaluation_id:
           return existing_id
       raise TacticalGridShadowEvaluationConflictError(
           f"B2B_EVALUATION_CONFLICT: Natural key ({evaluation.feature_evidence_id}, {evaluation.evaluation_profile_version}) "
           f"already exists with different evaluation_id: existing={existing_id}, new={evaluation.evaluation_id}"
       )
   ```
3. **Failure Mechanism in `GridShadowEvaluationManager` (lines 1080–1090):**
   - On initial evaluation before horizon close (e.g., 5 hours of 1m candles), `eval_res.eligibility_status` is `PENDING_HORIZON`.
   - Line 1080 calls `self.store.save_grid_shadow_evaluation(eval_res)`, persisting the pending evaluation into SQLite.
   - On subsequent execution after the 24-hour horizon closes, `get_grid_shadow_evaluation_by_feature_id` returns the existing row. Because its status is not `RESOLVED` or `NOT_ACTIVE_PAUSE`, the manager re-evaluates the episode using the full candle set.
   - `eval_res.eligibility_status` becomes `RESOLVED`, which alters the payload and produces a new `evaluation_id`.
   - Line 1080 calls `self.store.save_grid_shadow_evaluation(eval_res)`.
   - `save_grid_shadow_evaluation` finds the pre-existing pending row, sees `existing_id != evaluation.evaluation_id`, and unconditionally raises `TacticalGridShadowEvaluationConflictError`.
   - The error is caught at line 1088, returning `status: "ERROR"`. The pending row is never updated to `RESOLVED`.
