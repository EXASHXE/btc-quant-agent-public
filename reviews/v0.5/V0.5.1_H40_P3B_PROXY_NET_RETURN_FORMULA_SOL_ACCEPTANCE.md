## 2. Accepted formula

For accepted action sign:

```text
LONG  = +1
SHORT = -1
```

gross proxy fractional return is:

```text
r_gross = action_sign * (exp(r_h) - 1)
```

and proxy net return is:

```text
r_net = r_gross - c_rt
```

with current H40 V1:

```text
c_rt = 0.0012
```

Equivalently:

```text
LONG  = exp(r_h) - 1 - 0.0012
SHORT = 1 - exp(r_h) - 0.0012
```

Use `math.expm1(r_h)` for stable implementation.
