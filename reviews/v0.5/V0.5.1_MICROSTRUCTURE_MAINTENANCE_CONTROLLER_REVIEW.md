## 6. Static review of the H40 runtime hotspot

The slow-test table and code inspection identify a common authority-reconstruction path.

The production-authority test fixture repeatedly generates the canonical hourly timestamp population covering approximately 2021-01 through 2026-02 and then repeatedly reconstructs runtime split authority.

The production path performs, among other work:

```python
timestamps != sorted(set(timestamps))
set(timestamps)
set.intersection(...)
sorted(...)
generate_hourly_range(...)
set(expected_eligible)
per-partition generate_hourly_range(...)
membership filtering
repeated split reconstruction
```

Lifecycle tests intentionally perform repeated cold revalidation to prove source mutation/disappearance is detected. That cold validation must NOT be cached away.

However, there are two legitimate optimization surfaces:

1. **test fixture construction**
   - reuse immutable deterministic template data that is not itself under test;
   - retain fresh per-test mutable `cold_state` and monkeypatch boundaries.

2. **pure split-authority algorithms**
   - replace avoidable set/sort/full-range reconstruction with equivalent linear/bisect operations;
   - require exact before/after equality for split manifests, hashes, counts, partition timestamp hashes, exclusions, and failure behavior.

The key invariant is:

```text
do not cache or bypass cold validation across lifecycle transitions
```

Source disappearance/mutation tests must continue to exercise a real reconstruction on every authority consumption where the production contract requires it.
