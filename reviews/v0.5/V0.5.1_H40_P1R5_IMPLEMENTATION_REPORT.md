## 1. Executive Summary

This repair report documents the complete remediation of findings P1R4-F1 and P1R4-F2 identified in the Sol Independent Review (`reviews/v0.5/V0.5.1_H40_P1R4_SOL_INDEPENDENT_REVIEW.md`).

1. **P1R4-F1 Remediation (Production/Test Authority Boundary Closed)**:
   - Eliminated `authority_policy` parameter entirely from public production APIs:
     - `H40SplitManifest.materialize_authoritative(protocol_identity_hash, source_manifest, repo_root, ...)`
     - `H40SplitManifest.assert_authoritative(source_manifest, repo_root)`
   - Removed `H40AuthorityPolicy` from module exports and production controls.
   - Refined `H40CanonicalSourceSpec` to encode `production_authority_state: H40SourceStatus`:
     - `BTCUSDT_USD_M_1H`: `production_authority_state = NOT_TESTABLE` (fail-closed, lineage unestablished).
     - `ETHUSDT_USD_M_1H`: `production_authority_state = VERIFIED` (canonical artifact/checksum frozen).
   - Introduced strictly separated synthetic validator mechanics:
     - `materialize_synthetic_validator_split(...)`: generates splits with `is_authoritative = False` and `attestation.is_production_canonical = False`.
     - `assert_synthetic_validator_split(...)`: verifies partition logic, gap handling, and byte tampering on synthetic fixtures.
     - Synthetic validator splits are strictly and unconditionally rejected by `assert_authoritative(...)`.

2. **P1R4-F2 Remediation (Hermetic CI Invariant Restored)**:
   - Removed non-hermetic `test_positive_canonical_path_succeeds_only_with_canonical_spec` which attempted to copy untracked repository data and synthesize BTC files.
   - Made real-repo BTC artifact evaluation hermetic by asserting `receipt.reason_code in {INTERVAL_MISMATCH, SOURCE_MISSING}`.
   - Ensured all tests run hermetically in isolated `tmp_path` environments without assuming untracked data files exist.

3. **Invariants Preserved**:
   - Zero directional labels, zero forward returns, zero MFE/MAE.
   - Zero feature calculations, zero configuration search, zero backtests.
   - Confirmation holdout sealed, execution disabled, no alpha claims.
   - Protected H39 and Final Holdout surfaces unconditionally defended before filesystem access.

## 2. Technical Modifications

### 2.1 `src/btc_quant_agent/h40/source_manifest.py`
- Added `production_authority_state: H40SourceStatus` to `H40CanonicalSourceSpec`.
- In `get_canonical_source_spec`:
  - BTC: `allowed_role="PRIMARY_SPLIT_INPUT"`, `production_authority_state=H40SourceStatus.NOT_TESTABLE`.
  - ETH: `allowed_role="PRIMARY_SPLIT_INPUT"`, `production_authority_state=H40SourceStatus.VERIFIED`.
- In `assert_canonical_source_record`:
  - Validates `record.product == spec.product` (`PRODUCT_MISMATCH`).
  - Validates `record.cadence == spec.cadence` (`INTERVAL_MISMATCH`).
  - Validates `record.locator == spec.locator` (`SOURCE_UNVERIFIED`).
  - Asserts `spec.production_authority_state == H40SourceStatus.VERIFIED`, failing closed with `SOURCE_UNVERIFIED` for BTC (`NOT_TESTABLE`).
  - Validates `archive_set_sha256` and `reference_file_sha256` (`SOURCE_HASH_MISMATCH`).
- Removed `H40AuthorityPolicy` class.

### 2.2 `src/btc_quant_agent/h40/split_manifest.py`
- In `H40SplitManifest.materialize_authoritative`:
  - Removed `authority_policy` parameter.
  - Unconditionally calls `assert_canonical_source_record` for BTC and ETH.
  - Sets `is_production_canonical = True`.
- In `H40SplitManifest.assert_authoritative`:
  - Strictly requires `self.is_authoritative is True` and `self.attestation.is_production_canonical is True`.
  - Unconditionally calls `assert_canonical_source_record` for BTC and ETH.
- Added `H40SplitManifest.materialize_synthetic_validator_split`:
  - Test-only constructor returning `is_authoritative = False` and `attestation.is_production_canonical = False`.
- Added `H40SplitManifest.assert_synthetic_validator_split`:
  - Verifies partition reconstruction and disk byte integrity on synthetic fixtures without granting production authority.

### 2.3 `src/btc_quant_agent/h40/__init__.py`
- Removed `H40AuthorityPolicy` from imports and `__all__`.

### 2.4 `tests/test_v051_h40_p1_scaffold.py`
- Removed `H40AuthorityPolicy` imports and call sites.
- Routed low-level validator mechanics tests to `materialize_synthetic_validator_split` and `assert_synthetic_validator_split`.
- Updated `test_real_repo_btc_artifact_yields_not_testable_and_fails_closed` to accept `SOURCE_MISSING` alongside `INTERVAL_MISMATCH`.
- Replaced non-hermetic positive test with 12 mandatory adversarial tests verifying:
  1. No policy parameter accepted by production split APIs.
  2. Synthetic 1h BTC JSON at canonical locator cannot acquire production authority.
  3. Caller-computed BTC SHA cannot acquire production authority.
  4. Canonical source spec explicitly encodes `production_authority_state`.
  5. ETH canonical checks remain strictly enforced.
  6. Arbitrary locators remain rejected.
  7. Offline forged receipts/attestations remain rejected.
  8. Cold file/timestamp mutations remain rejected.
  9. Persisted split rehash attacks remain rejected.
  10. Synthetic validator output is strictly non-authoritative and rejected by `assert_authoritative`.
  11. Scaffold runs hermetically in isolated directories without repo data.
  12. Protected H39 / Final Holdout surfaces remain unconditionally defended.
