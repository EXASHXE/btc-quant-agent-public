## 3. Deep-Audit Root Cause Analysis and Repair

### 3.1. Root Cause
In commit `3a9b746`, the cache-eligibility predicate in `MicrostructureStore.status()` evaluated:
```python
cache_eligible = (
    not deep_integrity
    or not is_finalized
    or (is_finalized and isinstance(cached_entry, dict) and cached_entry["stats"].get("integrity") is True ...)
)
```
For active (non-finalized) partitions, `not is_finalized` was always `True`. As a result, when an ordinary status call (`deep_integrity=False`) ran and populated the cache, a subsequent explicit audit (`deep_integrity=True`) treated the active partition cache as eligible and reused the cached entry. This completely bypassed the database connection and the active-partition `PRAGMA quick_check`.

Furthermore, `status_performance["active_quick_check_executed"]` was populated as:
```python
"active_quick_check_executed": bool(deep_integrity)
```
This reported `True` based on caller intent rather than proving actual execution of `PRAGMA quick_check`.

### 3.2. Repair
1. **Strict Active Partition Cache Predicate**:
   Active partitions cannot hit the stats cache when `deep_integrity=True`:
   ```python
   cache_eligible = (
       (not is_finalized and not deep_integrity)
       or (
           is_finalized
           and isinstance(cached_entry, dict)
           and isinstance(cached_entry.get("stats"), dict)
           and cached_entry["stats"].get("integrity") is True
           and (not deep_integrity or attestation.get("verified") is True)
       )
   )
   ```
2. **Actual Execution Tracking**:
   Introduced `active_quick_checks_executed = 0`. When iterating partitions:
   ```python
   if deep_integrity:
       cur_integrity = connection.execute("PRAGMA quick_check").fetchone()[0] == "ok"
       if not is_finalized:
           active_quick_checks_executed += 1
   else:
       cur_integrity = True
   ```
3. **Observability**:
   `status_performance` diagnostic block now sets:
   ```python
   "active_quick_check_executed": active_quick_checks_executed > 0,
   "active_partition_integrity_mode": (
       "DEEP_QUICK_CHECK" if deep_integrity else "LIGHTWEIGHT_STATUS_READS"
   ),
   ```
