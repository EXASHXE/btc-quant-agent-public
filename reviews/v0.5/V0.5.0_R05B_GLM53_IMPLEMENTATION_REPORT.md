## 3. Defect and Repair Shape

Before the repair, the CANDIDATE bundle builder accepted caller-supplied `input_references` (and their `open_time_ms` values) as the material window, so a candidate could pick an earlier, direction-flipping window (e.g. a momentum window ending three bars earlier) and the resulting bundle would hash cleanly, pass cold replay, and preserve internal consistency throughout.

The repair makes the required material window **reconstructed**, never chosen:

- The verifier rebuilds the required input set from (a) the full frozen candle dataset, (b) the signal decision timestamp, (c) the authoritative `SignalProducerContract` semantics, and (d) fixed rules. Caller selections are demoted to assertions against the reconstruction.
- Two pure functions own the semantics (bundle construction and cold validation share them):
  - `resolve_material_input_policy(contract)` — `economic/signal_producer.py:125`
  - `select_required_material_candles(contract, candles, signal_timestamp_ms)` — `economic/signal_producer.py:196`
- Builder and validator both reconstruct through one shared helper, `_expected_input_refs(...)` — `economic/replay_bundle.py:175`. There is no second, candidate-owned hash: the reconstruction feeds the single existing `input_set_sha256`/preimage pipeline.
- The generation contract's selector fields (`material_input_required_bars`, `material_input_selector_type`, `material_input_selector_sha256`, `expected_preimage_sha256`, `material_input_open_times_ms`, `min_lookback_bars`) are overwritten from the reconstructed set (`economic/replay_bundle.py:424-433`), never from caller choice.

## 4. Selector Policy Table by Supported Rule

| Supported rule | Required window reconstruction | Fail-closed behavior |
| --- | --- | --- |
| `MOMENTUM_THRESHOLD` | Exactly `lookback_bars` contiguous eligible rows ending at the decision timestamp | Only `min_lookback_bars` present (no `lookback_bars`) → ambiguous-selection error; both present and unequal → error; `lookback_bars <= 0` → error |
| `RETURN_SIGN` | Exactly the latest 1 eligible candle | Any other cardinality → error |
| `PRICE_BREAKOUT` | Exactly the latest 1 eligible candle | Any other cardinality → error |
| `SYNTHETIC_FIXED_DIRECTION` | Exactly the latest 1 eligible candle | Any other cardinality → error; `N >= 1` forced |
| `RANDOM_MATCHED_OPPORTUNITY` | Not redesigned — benchmark role keeps its own reconstruction | Existing RANDOM semantics unchanged |

Eligibility (all rules): `closed is True`; `available_at_ms` non-None; `available_at_ms <= signal_timestamp_ms`; `close_time_ms <= signal_timestamp_ms`. Contiguity for `N > 1`: `next.open_time_ms == previous.close_time_ms + 1` (Binance convention). Gaps, duplicated open times, insufficient rows, and mixed symbol/interval all fail closed.

## 5. Proof That Candidate Refs Are Assertions Only

- Builder (`economic/replay_bundle.py:353-409`): after reconstruction via `_expected_input_refs`, caller-provided `input_references` are compared for exact equality with the reconstruction. Divergence raises `caller-selected material window for {signal_id} does not equal the authoritative required input window ...` or `caller-provided input_references for {signal_id} do not exactly equal ...` — the caller's rows never enter the bundle.
- Cold validator (`economic/replay_bundle.py:712-738`): independently rebuilds the required window from the persisted frozen dataset, the persisted decision timestamp, and the authoritative contract, then compares the persisted references exactly (`persisted input references for {signal_id} do not exactly equal the ...`). It additionally re-derives and checks `material_input_open_times_ms`, `expected_preimage_sha256`, `min_lookback_bars`, and the selector triple (`selector_type` / `required_bars` / `selector_sha256`) one by one. A candidate that re-hashes every outer artifact (`bundle_sha256`, `input_set_sha256`, preimage) still fails the cold reconstruction (T2).
- Full-repository negative search on the final HEAD: `CALLER_AUTHORITY` — 0 matches.

## 6. Astra Receipts

Fixture: five contiguous Binance candles (start `1_800_000_000_000`, cadence 900_000 ms, `close_time_ms = open_time_ms + cadence - 1`, decision timestamp at the fifth close); `MOMENTUM_THRESHOLD` with `lookback_bars = 2`, `threshold_return_bps = 150`. T1 asserts the economic consequence with the exact producer formula `(last close - first open) / first open` against the threshold:

| Window | Result | Disposition |
| --- | --- | --- |
| `[2,3]` (latest authoritative window, rows c2,c3) | return `+2.0% > 1.5%` → **LONG** | accepted at build and cold-replayable; persisted `material_input_open_times_ms` equals the reconstruction (T1.1) |
| `[0,3]` (earlier non-contiguous window) | return `-1.92% < -1.5%` → **SHORT** — the direction flip the repair closes | build rejected (`EXPECTED_WINDOW_MATCH`); direct producer replay is first rejected by the `N=2` contiguity rule (T1.2) |
| `[0,1,3]` (extra-row selection) | fail closed | build rejected (`EXPECTED_WINDOW_MATCH`); pure-function rejection covered separately (T1.3, T6, T8) |

Additional adversarial receipts (all in `tests/test_v050_r05b_material_input_selector_authority.py`):

| Attack | Disposition |
| --- | --- |
| Full rehash: refs replaced + `input_set_sha256`/`bundle_sha256` recomputed | cold reconstruction still rejects (T2) |
| Omit / extend / substitute window rows | rejected (T3-T5) |
| Out-of-order / duplicated open times | builder window assertion + cold `must be strictly increasing` (T6) |
| Future rows included in selection | excluded by the availability rule (T7) |
| Gap between required rows | pure-function fail-closed, no registry needed (T8) |
| Mixed symbol / mixed interval | fail closed (T9) |
| Ambiguous lookback (`min_lookback_bars` only; `lookback_bars=0`; negative; unequal pair) | fail closed (T10) |
| `RETURN_SIGN` / `PRICE_BREAKOUT` exact-one semantics + contradictory lookback | fail closed (T11) |
| Caller omits refs entirely | builder auto-constructs the authoritative window itself (T12) |
| Persisted generation-contract forgery (6 parametrized fields) | cold validator rejects every forged field (T13) |
