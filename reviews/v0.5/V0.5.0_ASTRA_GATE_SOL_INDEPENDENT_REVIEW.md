## Confirmed findings

### AG-03 — HIGH — mutable producer parameters under cached identity

`SignalProducerContract` is a frozen dataclass but `parameters` is a mutable `dict`. `contract_hash` is computed once in `__post_init__`; `SignalProducerRegistry` stores and returns the same object; `get_contract()` compares only the cached hash. `CanonicalRuleSignalProducer.replay_signal()` consumes the current mutable mapping. Therefore in-process mutation can change effective producer semantics while protocol and contract hashes remain unchanged.

This is a real authority-root defect. The first repair must make producer contract semantics deeply immutable, reject conflicting registrations, and revalidate current semantic content against the declared identity at authority lookups/replay boundaries.

### AG-02 — HIGH — candidate controls material-input selection

`build_formal_replay_input_bundle()` accepts candidate-supplied candle open-times/input references, verifies that referenced rows exist, are closed/available, and hashes the selected rows. `CanonicalRuleSignalProducer.replay_signal()` enforces only ordering, availability, preimage equality, and a minimum lookback. It does not independently reconstruct which rows the preregistered producer contract requires for a given decision time.

Thus a self-consistent subset can be selected and rehashed while omitting material history. The defect is selection authority, not hashing integrity.

Repair requires deterministic, preregistered selector semantics for every promotable producer contract and reconstruction of the required references from frozen dataset + decision boundary. Contracts whose complete material-input set cannot be independently reconstructed must fail closed for new promotion.

### AG-01 — HIGH — funding event source is candidate-owned

The protocol/comparison binds the funding model, but the concrete `funding_events` sequence is supplied by the formal job. `execute_bound_run()` hashes that sequence into the run identity; `execution_replay_inputs()` persists the same events; cold replay reloads those same persisted events and confirms their hash. This proves self-consistency but not independent funding-source authority.

A candidate can therefore substitute rates/events, regenerate all dependent identities, and remain internally replayable. Repair must bind an independent funding dataset/coverage authority into preregistration and verify exact event coverage during cold replay, including a trustworthy representation of a no-settlement interval. Another candidate-owned hash is insufficient.

### AG-04 — MEDIUM — `/health` writes forward SQLite state

`QuantService.health()` constructs `ForwardDerivativeStore("data/forward/BTCUSDT/derivatives.sqlite3")`. Its constructor creates parent directories, opens/initializes SQLite and creates/migrates schema. Therefore the real GET `/health` is not behaviorally read-only when the forward store is absent or requires initialization.

Repair requires a read-only status path that reports a missing/uninitialized store without creating or migrating it.

## Why prior parity/CI did not catch this

R04 cross-checkout parity proves R01–R04 did not change the accepted formal behavior. It cannot prove that inherited behavior was sound. The three HIGH findings all exploit roots that both baseline and R04 candidate treat identically. The 1006-test suite strongly covers submitted-derived forgeries but did not cover upstream self-consistent authority-root substitution.

## Repair dependency order

Do not repair all three HIGHs in one uncontrolled rewrite. Use dependency-ordered narrow repairs:

```text
R05A  producer-contract deep immutability + health read-only
  ↓
R05B  deterministic material-input selector authority
  ↓
R05C  independent funding dataset / coverage authority
  ↓
full Python 3.11/3.12/3.13 gate
  ↓
independent Astra re-gate
```

R05A precedes R05B because selector semantics will live in or be bound by producer contracts and must first have trustworthy immutable identity. R05C is independent but is the largest schema/authority change and should be isolated.
