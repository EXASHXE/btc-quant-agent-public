## 7. Current official source feasibility observations

### Binance

The official Binance public-data repository supports daily/monthly public market
archives, including USD-M futures native klines and checksums. This remains the
lowest-friction path for outcome-blind multi-asset OHLCV universe feasibility.

Binance USD-M REST historical open-interest statistics explicitly documents only
the latest 30 days as available from that endpoint. Therefore deep OI history
must not be assumed from the REST API and requires separate archive/source
verification.

### Bybit

Current official V5 documentation exposes:

- historical kline;
- index-price kline;
- mark-price kline;
- premium-index kline;
- historical open interest;
- historical funding rates.

The open-interest endpoint states queries may extend back to symbol launch,
subject to actual endpoint/data availability. This makes Bybit a strong
feasibility candidate for multi-asset derivatives and OI/funding research, but
the feasibility task must verify real historical depth, continuity and PIT
semantics rather than infer them from endpoint existence.

### OKX

Current official V5 documentation exposes:

- market/history candles;
- index candles;
- mark price;
- funding-rate history;
- open interest.

Exact deep historical OI/funding coverage and reconstructable PIT semantics must
be independently verified. OKX is therefore a source/replication candidate, not
yet the selected H42 primary venue.
