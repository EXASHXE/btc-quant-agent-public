## 1. Close R3R2-SOL-01 / R3R2-SOL-02 / R3R2-SOL-06: One Canonical Relative Hourly-Bar Index and Exact Active Formulas

### 1.1 Canonical relative bar index (replaces all mixed open/close-time notation)

For an hourly UTC decision boundary `t`, define for integer `j >= 0`:

```text
B_j(t) = the canonical 1h candle for the interval [t-(j+1)h, t-jh)
open_time(B_j) = t-(j+1)h
```

`B_0(t)` is the just-completed hourly bar immediately preceding the decision boundary.

A bar `B_j(t)` is usable iff:

```text
closed == true
close_time_ms < t
product matches
hourly interval identity is exact
no duplicate exists for that interval
```

For consecutive-window contracts, every required hourly interval must exist exactly once. Any missing, duplicated, or misaligned bar → `PIT_UNAVAILABLE` → `NO_TRADE`.

Define for every usable bar:

```text
C_j = close(B_j)
H_j = high(B_j)
L_j = low(B_j)
```

**Every** active candle-derived formula in this section uses this index. The conflicting R3R2 wording `C_X(t-W) = close of bar with open time t-W` is **deleted and superseded**.

### 1.2 D1 exact repair (closes R3R2-SOL-01)

For `W in {4, 12}`:

```text
s_D1_W(t) = log(C_0 / C_W)
```

This is exactly W one-hour intervals between close endpoints: `C_0` is the close of the just-completed bar, `C_W` is the close of bar `B_W`, so the return spans exactly W hourly intervals.

```text
Requires all bars B_0..B_W complete and consecutive.
s == 0 -> NO_TRADE
invalid endpoint/window -> PIT_UNAVAILABLE -> NO_TRADE
```

### 1.3 D4 return endpoint repair (closes R3R2-SOL-01)

For any D4 window `W`:

```text
r_X(t, W) = log(C_X,0 / C_X,W)
```

using synchronized indexed bars for BTC and ETH (`B_0..B_W` for both products, consecutive). Require the needed consecutive bars for both products; missing either product's bar set → `NO_TRADE` (`PIT_UNAVAILABLE`). All already-frozen D4 sign/target-relative semantics are preserved unchanged.

### 1.4 D2 exact Donchian repair (closes R3R2-SOL-01/02)

For `W in {24, 72}`:

```text
signal/test bar          = B_0
prior reference range    = B_1 .. B_W      # exactly W bars; B_0 excluded
U_W = max(H_1 .. H_W)
L_W = min(L_1 .. L_W)

C_0 > U_W  -> raw_score = +1
C_0 < L_W  -> raw_score = -1
otherwise  -> raw_score = 0 -> NO_TRADE
```

- Boundary equality is **not** a break (`C_0 == U_W` or `C_0 == L_W` → `NO_TRADE`).
- Require exactly the consecutive set `B_0..B_W`.
- The R3R2 minimum-bar rule `(W/24)*6` is **deleted and superseded**: the Donchian reference is exactly `W` consecutive hourly bars, no fractional rule.
- The test bar must never participate in its own Donchian prior range (corrected).

### 1.5 D3 exact two-bar failed-break repair (closes R3R2-SOL-02)

For `W in {24, 72}`:

```text
close-back bar = B_0
break bar      = B_1
prior range    = B_2 .. B_(W+1)      # exactly W bars preceding the break bar
U_W = max(H_2 .. H_(W+1))
L_W = min(L_2 .. L_(W+1))
```

Break:

```text
up_break   = C_1 > U_W
down_break = C_1 < L_W
```

Strict close-back **inside both bounds**:

```text
inside_back = L_W < C_0 < U_W
```

Output:

```text
up_break   and inside_back -> raw_score = -1   # SHORT reversal
down_break and inside_back -> raw_score = +1   # LONG reversal
otherwise                   -> raw_score = 0 -> NO_TRADE
```

- No search for an older break is allowed; no stale pattern state exists. The only authorized sequence is immediately adjacent `B_1 -> B_0`.
- Boundary equality is not inside (`C_0 == U_W` or `C_0 == L_W` is not a close-back).
- Require complete consecutive `B_0..B_(W+1)`.

### 1.6 R_VOL_RANGE_V1_24H exact raw scalar repair (closes R3R2-SOL-06)

Use exactly 24 one-hour log returns:

```text
z_j = log(C_j / C_(j+1))     for j = 0..23
mean_z = arithmetic mean(z_0 .. z_23)
RV_24 = sqrt( sum((z_j - mean_z)^2) / 23 )     # sample standard deviation, ddof = 1
```

- Requires complete consecutive bars `B_0..B_24` (25 close endpoints).
- NaN/Infinity in any input → `PIT_UNAVAILABLE` → `NO_TRADE`.
- This replaces the R3R2 "24 closes / 23 returns" wording.
- R3R1 percentile state boundaries and MID-only pass rule are preserved unchanged: `REGIME_VOL_LOW [0,0.40)`, `REGIME_VOL_MID [0.40,0.60)`, `REGIME_VOL_HIGH [0.60,1.0]`, lower-bound-owns-equality, only `REGIME_VOL_MID` passes.

### 1.7 O_RANGE_EXPANSION_V1_24H exact raw scalar repair (closes R3R2-SOL-06)

Define true range from indexed bars:

```text
TR_j = max(
  H_j - L_j,
  abs(H_j - C_(j+1)),
  abs(L_j - C_(j+1))
)
```

Then:

```text
E_24(t) = TR_0 / mean(TR_1 .. TR_24)
```

- Requires complete consecutive bars `B_0..B_25`, because `TR_24` needs `C_25` (its predecessor close).
- Denominator must be finite and `> 0`; otherwise `PIT_UNAVAILABLE` → `NO_TRADE`.
- R3R1 percentile states and ELIGIBLE-only proceed rule preserved: `O_NONE [0,0.60)`, `O_WATCH [0.60,0.80)`, `O_ELIGIBLE [0.80,1.0]`, lower-bound-owns-equality, only `O_ELIGIBLE` proceeds.

## 2. Close R3R2-SOL-03: Orientation-Preserving, Mathematically Unique Platt Fit

Preserve:

```text
p_up = sigmoid(a * raw_score + b)
```

Calibration MUST NOT invert the authorized direction hypothesis. The Platt fit is frozen as the **unique finite minimizer of binary logistic negative log likelihood** over the candidate's calibration population (Section 3) subject to:

```text
a >= 0
b unrestricted
no regularization
```

Fail-closed rules (any of these ⇒ calibration invalid → the configuration fails closed for that fold):

```text
- no unique finite constrained optimum exists  -> invalid
- the optimum lies at a == 0                    -> invalid (a constant mapping cannot
                                                    create one-sided trades)
- one-class target                              -> invalid
- constant raw_score                            -> invalid
- complete/quasi separation with no finite unique optimum -> invalid
- numerical implementation failure to reach the unique finite optimum -> invalid
- never replace a failed Platt fit with a different model
```

This makes Platt **monotone nondecreasing** in the already-frozen bullish raw-score orientation (`larger raw_score => more bullish`), matching isotonic's monotonicity. The frozen contract is the mathematical constrained-objective definition (unique finite constrained MLE with `a >= 0`), **not** a library-specific optimizer; no optimizer hyperparameter or search degree of freedom exists. The intercept `b` is unrestricted and fitted.

## 3. Close R3R2-SOL-04: Candidate-Specific Fitting Populations

For a single-family D1/D2/D3/D4 without a secondary filter, F is **vacuous** (always passes).

### 3.2 Calibration population

A calibration observation exists iff A..F pass **and** the horizon label is non-neutral:

```text
y = 1  for LONG_LABEL
y = 0  for SHORT_LABEL
NEUTRAL_LABEL excluded from probability calibration only
```

Accepted-trade precision still includes neutral realized outcomes as incorrect (BASE 3.2 preserved).

### 3.3 D5 quantile reference population (non-circular)

```text
D5 reference sample at training time t = historical rows that pass:
    A..E
    valid last-settled funding
    (NOT required: D5 veto-pass F)
Use only rows with base_side != 0.
Reference scalar = abs(funding * base_side) = abs(funding)    (side-aware query
    a(t) = funding * base_side; upper-tail crowding-reversal veto preserved from R3R2)
```

For calibration/validation, the D5 reference is the frozen chronological-training reference exactly as R3R2 intended (Section 3 / R3R2 Section 3).

### 3.4 Geometry population

Geometry training observations must pass A..F. Therefore pair/D5 geometry reflects the actual candidate condition (post-filter) rather than vetoed rows. No calibration/validation realization may enter a fold's geometry fit.

## 5. Close R3R2-SOL-07: Exact Empirical Mid-Rank and Quantile Domain

### 5.1 Exact empirical mid-rank (replaces the mislabeled tie formula)

```text
n_lt = count(s < x for s in S)
n_eq = count(s == x for s in S)
p(x) = (n_lt + 0.5 * n_eq) / N
```

All equal values therefore receive the same true mid-rank. The previous R3R2 formula (`strictly-lesser/N + 0.5/N if any tie`) is **superseded**; it was not the true mid-rank when multiple observations equal `x`.

### 5.2 Nearest-rank quantile domain

```text
for 0 < p <= 1:
  Q(p) = sorted(S)[ceil(p * N) - 1]
```

- No interpolation.
- `Q(0)` is **outside the authorized quantile domain** and must not be called. H40 active D5 only calls `Q(0.8)` and `Q(0.9)` (upper-tail mass q = 0.20 and 0.10).
- Preserve minimum `N = 60`, NaN/Infinity rejection, expanding-lagged training reference, and frozen train-reference use in calibration/validation (R3R2 Section 3).

## 6. Close R3R2-SOL-09: Probability-Diagnostic Population After the Ternary-to-Binary Repair

`p_up` is conditional on the non-neutral binary calibration population. ECE/Brier/Brier-skill use the same target semantics.

```text
probability_diagnostic_population = rows passing candidate A..F
                                    AND realized label in {LONG_LABEL, SHORT_LABEL}

y = 1  LONG_LABEL
y = 0  SHORT_LABEL
```

Neutral outcomes are excluded from probability diagnostics only; they remain incorrect outcomes in accepted-trade precision exactly as BASE requires.

Base-rate predictor:

```text
p_base = mean(y) over the allowed calibration population used to fit the calibrator
```

`p_base` is frozen with the calibrator and used unchanged when computing later Brier skill on an authorized evaluation population.

```text
BS_model = mean((p_up - y)^2)
BS_base  = mean((p_base - y)^2)
Brier skill = 1 - BS_model / BS_base
```

If `BS_base <= 0` or undefined → the probability diagnostic fails closed.

ECE retains the BASE adaptive-bin requirement and minimum 20 observations/bin, but bins/targets are formed only from this same binary diagnostic population. No neutral label is used to invent a third probability class. BASE's ECE threshold (`<= 0.05`) and positive-Brier-skill gate are unchanged.
