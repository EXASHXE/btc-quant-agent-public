## 2. Accepted mapping

For each candidate/partition/metric bootstrap evaluation:

```python
rng = np.random.Generator(np.random.PCG64(seed))
starts = rng.integers(
    low=0,
    high=H - 168 + 1,
    size=(10000, B),
    dtype=np.int64,
    endpoint=False,
)
```

with:

```text
B = ceil(H/168)
```

This is one and only one integer-sampling call.

No RNG state may be consumed first.

Rows are replicate order; columns are block-draw order.

## 3. Rejected alternatives

Not accepted:
- one draw call per replicate;
- Generator.choice;
- random_raw rejection sampling;
- float scaling;
- modulo mapping;
- RandomState/default_rng shorthand;
- reseeding per replicate.

Mathematical uniformity alone is insufficient; deterministic mapping is now part of the replay contract.
