## Accepted findings

### BLOCKER 1 — exact frozen runner SHA is not enforced at execution
The runner captures pre/post git HEAD but does not require the initial HEAD to equal the Controller-frozen runner SHA. A stable but wrong HEAD can therefore pass identity checks.

Required repair:
- introduce an exact authorized execution SHA constant or equivalent immutable authority input;
- before cache read or network access, require current HEAD == authorized exact runner SHA;
- require committed runner SHA256 and accepted normalizer SHA256 to match frozen values;
- require validation script working tree cleanliness;
- repair creates a new commit and therefore a new exact SHA to freeze/review.

### HIGH 2 — cache sidecar is not cryptographically bound to embedded payload identity/content
A matching sidecar can be accepted without proving the embedded identity and payload/source set are the same authority object.

Required repair:
- runner-side cache verification must bind sidecar identity, embedded identity, source URL/digest set and payload content digest;
- any mismatch must fail closed or rebuild before replay;
- accepted normalizer bytes remain unchanged.

### HIGH 3 — preflight context/warm-up coverage is first-step-centric
The current checks do not prove the entire decision window has required 1h/4h/derivative/funding/reference context. Scanner degradation or missing snapshots later in the window can change the actionable set without failing the authority run.

Required repair:
- audit required inputs across every decision step before outcome aggregation;
- reject missing/degraded target or context snapshots, derivative/funding/basis coverage gaps, ordinary warm-up failures and decision omissions;
- record actual per-step audit counts.

### HIGH 4 — authority input manifest is incomplete
The replay manifest excludes context-only references and existing series digests do not bind all decision-relevant fields/content.

Required repair:
- runner generates a complete authority input manifest over targets + context-only references;
- hash all decision-consumed candle fields and derivative/funding/basis content, not counts only;
- two deterministic replays must compare this complete authority manifest in addition to replay outputs;
- reference symbols remain excluded from outcome aggregation.

### HIGH 5 — evidence/failure publication is incomplete
Source/cache proof and authentic target 1m authority are not fully emitted; several exception paths can escape without complete failure evidence; final authority artifacts are written before the final identity assertion.

Required repair:
- committed runner emits source/cache proof, full target/reference input authority, authentic target 1m proof and PIT/context audit;
- unify fail-closed exception handling for dataset build, smoke, 1m coverage, replay and identity failures;
- publish final authority artifacts only after successful post-execution identity verification.

The existing test proves a local mock stayed unused, not that the historical construction session performed zero protected network/archive access. The hard-coded counter is not historical telemetry.
